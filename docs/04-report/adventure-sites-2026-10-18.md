# 국가별 던전·적대 거점 구현

작성일: 2026-10-18

## 반영 내용

- 신규 지도 생성에 국가별 공백지 배치를 연결했다. 기존 지도에는 지도 도구 → 던전 위치 → 공백지 자동 배치로 추가한다.
- 정착지와 다른 표식의 논리 좌표 간격을 검사한다. 수도·도시에는 일반 마을의 1.5배 여백을 둔다. 국가 경계를 넘어 인접한 정착지도 검사하며, 부족한 공간은 강제 배치하지 않고 결과에 표시한다.
- 17개 테마, 14개 몬스터 유형, 31종 대표 몬스터 레퍼런스를 추가했다. 오크 약탈단·고블린 적대 취락, 미쳐버린 마법사의 탑, 언더월드 통로를 포함한다.
- 테마에 맞는 대표 개체와 CR을 결정적으로 선택하고 고위험 개체는 낮은 가중치를 둔다. 언더월드 통로는 20~80개체의 출몰지로 설정한다. 적대성은 해당 세력의 창작 설정이며 종족 전체를 적대적으로 취급하지 않는다.
- 던전 목록에 테마·유형·대표 몬스터·CR·추정 개체 수·공략 상태·원본 PDF 페이지를 표시한다. 30개 단위 페이지, 간격·자동 거점 상한 설정, 공략 완료·잠금, 자동 거점 재생성을 추가했다.
- 수동·레거시 표식, 잠금 및 던전 창에서 수정한 거점은 전용 재생성에서 보존한다. 재생성은 임시 결과를 만든 뒤 교체하여 실패 시 기존 표식·노트를 유지한다. 레거시 전체 표식 재생성에는 기존 잠금 정책이 적용된다.
- 선택적 Marker.adventure를 기존 표식 JSON에 저장하므로 `.map` 및 `.fpb` mapPayload에서 보존된다. 잘못된 추가 메타데이터는 가져오기에서 제거하되 기존 표식은 유지한다.
- 설계 문서·README·라이선스 고지를 업데이트했다. 원본 스탯 블록 전체는 복제하지 않고 개체의 이름·유형·CR·페이지를 참고한다.

## 검증

- 전체 Vitest: 50개 파일, 637개 테스트 통과.
- TypeScript `--noEmit`: 통과.
- 변경 TypeScript Biome 검사: 통과.
- Vite 프로덕션 빌드: 통과. 기존 레거시 script/public CSS 및 큰 청크 경고는 유지된다.
- 14개 타입·테마 매핑, 국가별 배치, 도시/마을의 서로 다른 반경, 다른 표식/신규 거점 간 거리, 물·미소유 땅·지도 가장자리 제외, 결정성·입력 순서 독립성, 부족 공간 보고, 중복 없는 추가, 기존 마커 생성기 연결·비활성화·잠금, `.fpb` mapPayload 왕복을 검증했다.
- jsdom으로 자동 배치, 목록의 CR/출처, 공략·잠금 보존, 공간 부족, 재생성 실패 시 원본 보존을 검증했다. 실제 브라우저 화면·모바일·3D 시각 검증과 Playwright E2E는 수행하지 않았다.

## 범위와 주의점

CR은 대표 몬스터 한 개체의 값이며 거점 전체의 난이도가 아니다. 추정 개체 수는 혼합 세력을 포함할 수 있다. NPC의 서사 레벨/티어와 별개이고, 자동 조우 밸런스나 완전한 전투 스탯·웨이브 구성은 제공하지 않는다.

공식 SRD 5.2.1에서 29종, SRD 5.1에서 휴머노이드 Orc·Goblin 2종을 참고하며 판본을 표시한다. 몬스터 전체 데이터베이스가 아니다. 테마·번역 이름·거주 수·적대 행동은 앱 창작이다.

거리 검증은 지도 논리 좌표 기준이며 화면 픽셀/km 보증이 아니다. 기존 수동/레거시 던전은 이동하거나 임의 CR을 붙이지 않는다. 토지나 여백이 충분하지 않은 국가에는 목표 수보다 적게 생성될 수 있다.

층·방·실내 구조 생성은 이번 기능에 포함하지 않는다. 기존 Watabou 외부 링크를 유지했다. 생성 설정은 현재 세션에 적용하며 생성된 위치·메타데이터는 파일에 저장한다.

로컬 코드·빌드만 반영했다. GitHub push 및 공개 사이트 배포는 하지 않았다.
