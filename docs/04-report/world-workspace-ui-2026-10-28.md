# 세계와 NPC UI 개편 결과

승인된 [Figma 시안](https://www.figma.com/design/ieZzhJvWLAXHAU6ia3zTWU?node-id=2-41)을 기존 Vanilla TypeScript/CSS 앱에 반영했다. 새 런타임 의존성이나 저장 모델 변경은 없다.

- 왼쪽 탐색 범위, 위쪽 NPC·보물·종교 목차, 본문 목록/상세를 구분했다.
- 기존 편집 폼·초안 검증을 사용하면서 읽기 요약, 명시적 편집·취소·적용, 선택한 항목의 지도 이동을 제공한다.
- 세계 설정의 임시 입력은 적용 전 월드를 바꾸지 않는다. 판본 변경의 기존 확인 및 수동 기록 보존 동작을 유지한다.
- 검색·정렬·페이지 이동·내보내기, 초상화, SRD 참고, 국가 역사와 총본산 표시를 보존했다.
- 760px 이하에서는 카테고리를 접고 목록/상세를 전환한다. 상세 진입 시 제목으로 키보드 초점을 이동한다.

검증: campaign-world, editor-drafts, headquarters-details, map-load-lifecycle, ui-language의 5개 파일 50개 테스트와 TypeScript/프로덕션 빌드 통과. 변경 전부터 있던 레거시 스크립트/번들 크기 경고는 남아 있다. 전체 린트 및 Playwright E2E는 실행하지 않았다.

실제 브라우저에서 데스크톱 3영역, 종교 목차, 편집 초안 입력 후 취소, 선택 국가의 설정 활성화·건국 경과 적용과 재열기, 390px iframe의 모바일 목록→상세→목록 및 카테고리 펼치기를 확인했다. 모바일 검증용 임시 HTML은 제거했다. 실제 Google Drive 계정 연결/업로드는 이 UI 변경의 검증 범위에 포함하지 않는다.
