# 지상·수중·지저 수동 지도 구현 결과

## 제공 기능

- 상단 지상/수중/지저 전환, 동일 지도 위치·확대 유지. 기존 3D는 추가 보기에서 제공.
- 도시·영지/세력권·타원형 지형·연결 지점의 클릭 배치, 상세 편집·이동·삭제.
- 깊이·주민·인구·메모, 독립 세력의 이름·색·설명과 장소 소속 관리.
- 동일 공간의 점선 경로, 다른 공간 사이 통로와 도착지 전환.
- FPB와 기존 Drive 사본 저장 경로에 추가 공간 데이터 포함. 기존 파일은 빈 추가 공간으로 호환.
- 지상 재생성 시 수동 기록/초안 보존. 다른 프로젝트 열기는 그 파일의 데이터로 교체.
- 장소·세력·연결 초안의 로컬 복구와 적용 전 내보내기 경고.
- 모바일 배치 중 편집창 축소, 한국어/영어 UI.

## 범위 제한

첫 단계는 수동 작도다. 자동 해저/공동 생성, 여러 깊이별 보기, 폴리곤 경계 편집, 자동 NPC/국가·교역·외교 연동은 후속 단계다. 현재 생성기의 바다 윤곽선을 실제 수심으로 해석하지 않는다. 지상 실루엣은 좌표 참고용이며 실제 동굴이나 해저 지형이 아니다. 패스파인더 규칙 데이터는 추가하지 않았다.

`.map`은 지상 원본 형식이므로 추가 공간 기록을 저장하지 않는다. 상단 FPB/Drive 저장을 사용한다. 기능을 지원하지 않는 구버전 앱에서 재저장하면 추가 기록이 누락될 수 있다.

## 검증

- 관련 단위 테스트 통과(공간 모델·렌더링, 프로젝트 검증, 초안 복구, 기존 PlanetBuilder 및 언어 처리).
- 타입 검사·프로덕션 빌드 통과.
- 전체 1037개 중 1036개 통과. `project-codec.test.ts / accepts the inclusive byte limit`는 앞선 작업에서 변경 전 원본에서도 재현된 기존 실패로 구분한다.
- 실제 Chromium에서 수중/지저 도시, 세력 소속, 공간 간 통로 이동, 확대 유지, FPB 다운로드·재열기 및 1920/390px 화면 폭의 넘침 없음 확인. Google 인증/Drive 서버 자체는 이번 변경으로 재검증하지 않았으며 동일 FPB 저장 경로를 사용한다.

- 추가 Chromium 검사: 지상 재생성에서 수동 기록/초안 유지, 새로고침 후 IndexedDB 초안 복구, 모바일에서 지형 배치와 수정까지 통과. 핵심 공간 편집 흐름에서는 브라우저 오류 없음.
- IO/3D 컨트롤러/공간 모델·렌더러 관련 61개 테스트도 통과. 추가 보기에서 기존 3D 캔버스 진입을 확인했으나, 이 환경에서 `fonts.gstatic.com`이 `ERR_TUNNEL_CONNECTION_FAILED`로 차단되어 외부 폰트/텍스처를 포함한 3D 정상 렌더링 전체는 검증하지 못했다.
- 3D 텍스처·이미지 준비 중의 임시 SVG가 화면과 문서 너비에 영향을 주지 않도록 별도 잘린 고정 컨테이너에 격리하고 정리한다.

공개 Sites 배포는 이 세션에 도구가 제공되지 않아 수행하지 않았다.
