# 도시 상세 및 공개 NPC 티어 보완

## 원인과 범위

공개 사이트는 이전 NPC 생성기와 CR 전용 목록·상세 UI를 사용했다. 최신 작업 소스의 레벨·티어 기능은 공개되지 않은 상태였다. 이번에는 도시 상세 기능과 필요한 NPC 진행도 코드를 선택적으로 이식한다. 저장·복구 및 그 밖의 미출시 기능 전체를 함께 공개하지 않는다.

## 도시 상세

- 기존 도시 편집 창에 실제 소속 국가·수도·영지·항구 정보를 표시한다.
- 소속 NPC를 레벨 우선으로 나열하며 인물 상세 편집 창과 연결한다.
- 연혁은 실제 역사 자료가 아닌 시드 기반 창작임을 명시한다.
- D3 Delaunay/Voronoi 필지를 축소해 건물을 배치한다. 외곽 건물은 반경 32 이내로 제한하고 중앙 시장·간선도로·수로 공간을 비워 둔다.
- 조감도와 시장·주거지·성문 전투 지도는 동일한 배치를 사용한다. 전투 지도는 32×22칸, 칸당 5ft의 도식적 구역 지도다. 실제 도시 면적·인구에 비례하는 측량도를 제공하는 것은 아니다.
- 전투 지도는 지붕 대신 바닥·문·간단한 가구를 표시한다. 자동 전투/이동 판정이나 VTT 동적 벽 데이터는 포함하지 않는다.
- PNG/SVG 출력, 격자 표시, 재현 가능한 시드, 무작위 시드를 지원한다.
- 생성 시드·연혁은 `Burg.settlement` 선택 필드에 보관한다. 지리 좌표를 바꾸지 않으며 FPB의 기존 지도 페이로드 직렬화를 이용한다.

## NPC

- 평민의 분수 CR은 레벨이 아니다. 기존 기본 SRD 참고 능력치와 레벨 기반 간이 전투 프로필도 구분한다.
- 자동 주요 인물: 마을 T1=1~4, 도시 T2=5~8, 국가 T3=9~12, 대륙 T4=13~16. 국가 성격별 직업 가중치는 기존 NPC 진행도 생성기를 재사용한다.
- T5=17~20, 에픽=21+는 수동 지정만 지원한다. 레벨 20 초과 전투 수치를 임의로 외삽하지 않는다.
- 기존 NPC의 ID·이름·비밀·메모를 보존한다. 진행도가 없는 기존 인물은 진행도만 부여하고 필요한 국가·대륙 인물을 추가한다.
- 명시적 티어 재분배도 직접 수정한 인물은 유지한다. 새 인물로 전체 교체하지 않는다.
- 공개용 진행도·필드 검증을 보완하고 수동 편집 및 JSON 왕복을 검사한다.

## ChatGPT 이미지 연동

이번 구현은 도시의 공개 정보만 포함한 요청문 복사와 ChatGPT 외부 링크다. 사용자가 요청문 및 도시 SVG/PNG를 직접 자신의 ChatGPT에 전달한다. NPC 비밀·GM 메모·API 키는 전달하거나 저장하지 않는다. 자동 OAuth, API 호출, 생성 이미지 가져오기를 완료했다고 표시하지 않는다.

공식 문서 확인: [Sign in with ChatGPT](https://developers.openai.com/siwc/quickstart), [Models and inference](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference), [GPT Image 2](https://developers.openai.com/api/docs/models/gpt-image-2).

공식 계정 연결 흐름에는 별도 권한과 등록이 필요하다. ChatGPT 요금제 기반 호출은 계정별 모델과 지원되는 Responses API 범위를 확인해야 하며 이 프로젝트에서 GPT Image 2 이미지 생성을 사용할 수 있다고 검증한 것은 아니다. 이를 후속 인증·모델 가용성 검증 과제로 남긴다.

## 검증

- 최신 작업 소스: 66개 파일, 795개 단위 테스트 통과.
- 공개 기존 소스: 외부 호환 설정으로 291개 회귀 테스트 통과.
- 공개용 NPC UI/직렬화/티어/에픽/분수 CR/재생성 검사 6개 통과.
- 양쪽 타입 검사, 최신 작업 TypeScript Biome 검사 및 프로덕션 빌드 통과.
- 조감도·시장·성문 SVG를 PNG로 래스터화하고 비어 있지 않음·불투명 픽셀 검사 통과. 조감도·시장 이미지를 직접 열어 확인하고 외곽 건물·도로 여백을 수정했다.
- 실제 브라우저 화면·모바일 겹침·브라우저 Canvas PNG 다운로드는 미검증. DOM 테스트·SVG 래스터 확인을 실제 브라우저 검증으로 간주하지 않는다. 자동 Playwright 미실행.
- 새 프로덕션 의존성 없음. GitHub 푸시 미실행.
