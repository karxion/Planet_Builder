# 표식 그룹·던전 위치·자원 크기 변경 보고서

작업일: 2026-10-11

## 반영 내용

- 화면에서 겹치는 도시·마을 아이콘, 자원 토큰, 표식을 함께 묶어 대표 아이콘과 수량으로 표시한다.
- 그룹을 누르면 항목을 세로 목록으로 나열하고, 각 항목에서 원래 정착지/표식/자원 편집기로 이동한다. Enter/Space 열기, Escape 닫기, 바깥 클릭 닫기를 연결했다.
- 그룹의 범위를 제한해 연쇄 겹침이 대륙 전체를 하나로 합치지 않게 했다. 배지는 다른 배지와 단독 아이콘을 피하며, 이동한 배지는 원래 중심과 연결선을 표시한다.
- 확대·축소·이동·레이어 변경·아이콘 편집 시 120ms 유휴 후 화면 좌표를 다시 계산한다. 지형 아이콘은 변경하지 않았다.
- 드래그 편집과 지도 배치 모드에서는 그룹 표시를 해제해 도구가 지도 클릭을 받을 수 있게 했다. 안개 레이어 아래에 그룹을 표시한다.
- 실제 엔티티 좌표는 바꾸지 않는다. 저장용 복제 SVG에서는 일시적인 그룹/숨김 상태를 제거한다. 현재 화면 PNG에는 그룹을 유지하고 전체 SVG/3D 텍스처에는 원본 위치를 사용한다.
- 자원 기본 크기를 14에서 7로 변경했다. 기존 토큰은 버전 2로 한 번만 마이그레이션하며, 다시 열 때 추가로 축소되지 않는다. 배치 간격을 별도로 보존하고 크기 조절값은 실제 표시 크기와 일치시켰다.
- 지도 도구의 도구 탭에 `던전 위치`를 추가했다. 던전 목록, 위치 이동, 편집, 지도 표시, 수동 배치, Watabou 던전 링크를 제공한다. 동굴을 던전으로 오인하지 않게 분리했다.
- 수동 던전 배치는 기존 생성기 데이터/노트 저장 경로를 사용한다. 숫자 기반 기존 던전 시드는 유지하고, 문자열 시드는 안전한 숫자 시드로 변환한다. 새 던전 노트는 외부 iframe을 자동 실행하지 않는다.
- 선택된 다섯 Watabou 생성기의 통합 범위, 이용 조건, 외부 연결/가져오기/독립 엔진 구현 단계를 [상세 지도 생성기 기획서](../01-plan/local-map-generators.plan.md)에 정리했다. 다섯 생성기의 완전 통합은 이번 변경의 구현 범위가 아니다.

## 자동 검증

| 검증 | 결과 |
|---|---|
| TypeScript `tsc --noEmit` | 통과 |
| Vitest | 26개 파일, 227개 테스트 통과 |
| 이번 변경의 TypeScript 13개 파일 Biome 검사 | 통과 |
| Vite 프로덕션 빌드 | 통과 |
| `git diff --check` | 통과. 기존 Windows 줄바꿈 경고만 발생 |

추가 테스트는 겹침/분리, 큰 아이콘, 좌표/항목 보존, 그룹 반경 제한, 배지 충돌 회피, SVG 렌더러의 클릭/키보드 이벤트 전달, 안개 레이어 순서, 저장 정리, 자원 크기 단회 마이그레이션, 배치 간격 보존, 던전 분류/시드/URL 안전성을 검증한다.

기존 비모듈 스크립트, 큰 번들, 출력 폴더 관련 Vite 경고는 이번 변경에서 해결하지 않았다.

## 실제 브라우저 확인과 제한

- 실행 중인 `http://127.0.0.1:5173/Fantasy-Planet-Builder/`에서 화면을 직접 캡처하고 확인했다.
- DOM 속성으로 자원 `data-size=7`, `data-token-version=2`, 던전 도구 버튼 등록을 확인했다.
- 1440×900 화면에서 지도·축소된 자원 토큰·그룹 배지를 확인했고, 그룹이 과도하게 커지는 초기 결과를 보고 범위와 배지 크기를 조정했다.
- 1920×1080 뷰포트 캡처도 시도했다. 브라우저 제어의 시간 초과/포커스 문제가 반복되어 리사이즈 직후와 안정화 상태의 일관된 자동 검증은 완료하지 못했다.
- 그룹 열기, 항목 편집, 던전 목록/배치의 실제 클릭 검증은 브라우저 제어 시간 초과로 완료하지 못했다. 단위 테스트의 이벤트 검증을 실제 브라우저 클릭 성공으로 간주하지 않는다.
- 기존 초기 생성 중 `drawCoordinates → round(null)` 오류 로그가 간헐적으로 남아 있다. 이후 지도는 표시되지만 이번 변경에 포함된 오류는 아니며 별도 수정이 필요하다.
- 자동 Playwright E2E 실행은 저장소 지침에 따라 수행하지 않았다.

## 남은 확인

1. 포커스가 정상인 실제 브라우저에서 그룹 열기/닫기, 도시·표식·자원 편집 진입을 확인한다.
2. 던전 수동 배치 후 목록 갱신, 지도 이동, 이름 변경, `.fpb` 저장·복원과 외부 링크를 확인한다.
3. 확대·축소와 레이어 전환, 3D 전환, 현재 PNG/전체 SVG 출력에서 표시 정책을 비교한다.
4. 1920×1080 및 작은 창에서 그룹 팝업/던전 목록의 배치와 스크롤을 확인한다.
