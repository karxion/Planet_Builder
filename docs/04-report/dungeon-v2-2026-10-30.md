# 던전 v2 구현 및 사용 가이드

기존 단층 던전 위에 다층 제작·개별 부품 배치·GM 기믹 운영을 추가했다. 새 거점은 기본 3층 미리보기로 열리며, 저장된 v1 던전은 기존 편집기로 열고 ‘다층 던전 v2’에서 보존 변환을 선택한다. 단순히 열거나 미리보기를 취소해도 저장 데이터가 바뀌지 않는다.

## 제작된 개별 이미지

[32종 구성표](../02-design/dungeon-assets.catalog.md)의 D01~D32를 각각 이미지 생성 도구로 제작했다. 서로 다른 물체를 한 장의 완성 지도나 스프라이트 시트로 대체하지 않았다. 입체 부품 22종은 같은 물체의 조감도/탑다운을 한 마스터의 양쪽에 두고, 평면 부품 10종은 탑다운 한 시점을 사용한다. 문의 탑다운이 입면처럼 보이는 샘플은 다시 생성해 교정했다.

- 원본 32개: `assets/dungeon-originals/` (사이트 빌드에는 미포함)
- 배포 PNG 32개: `public/assets/dungeon/` (각 축 약 2/3, 원본에서 한 번 축소)
- [이미지 manifest](../../src/data/dungeon-asset-manifest.json): 양쪽 크기/SHA-256, 상대 원본 경로, 시점별 crop/anchor
- [부품 정의](../../src/data/dungeon-assets.ts): 점유 칸, 허용 회전, 연결 면, 힌지, 환경/레이어 및 기본 통행·시야 속성

모든 부품은 팔레트에서 배치할 수 있다. 생성기는 바닥·가구·보상·함정·계단 등에 해당 부품을 사용한다. 벽 경계는 지형 격자에서 그리며, D03~D05는 개별 벽 부품으로도 배치한다. 상태별 별도 PNG 포즈까지 32종에 중복 집계하지 않았다. 현재 문/장치의 열림·비활성 상태는 공유 이미지의 표시와 별도의 통행 데이터로 표현한다. 문짝만 움직이는 정밀 애니메이션과 파손 상태별 추가 그림은 후속 제작 항목이다.

## 권장 사용 순서

1. 세계 지도에서 던전 거점을 열고 기본 3층을 검토한 뒤 **적용**한다. v1이면 보존 변환을 먼저 적용한다.
2. **속성 → 층 설정**에서 컨셉·구조·환경과 실제 격자 크기를 정한다. 컨셉 자유 문장은 설명으로 보존하며, 지형 변화는 구조/환경/숫자 선택을 사용한다. 층 이름·고도·메모만 바꾸는 버튼도 별도로 제공한다.
3. **설정·층 지형 재생성 미리보기**에서 변경 결과를 보고 적용한다. 배치만 바꾸려면 **배치만 재생성**을 사용한다. 작은 층은 공간에 맞춰 요청보다 적은 방을 생성할 수 있다.
4. 보존할 층/방/부품을 잠근다. 직접 이동·편집한 부품은 수동 보호 대상으로 남기며, 자동 재생성을 다시 허용하려면 보호 설정을 해제한다. 다른 장치가 참조하는 대상과 계단 접속구는 재생성에서 보존된다.
5. **개별 에셋 배치**에서 부품, 방 안의 좌표, 회전 및 선택적인 기믹 템플릿을 정한다. 이미지와 판정 템플릿은 독립적이다. 전체 점유가 벽·다른 부품·접속구와 겹치면 적용하지 않는다.
6. 지도에서 장치를 선택해 영향 범위·열쇠·연결 대상·경비를 지정하고 징후 표시/발동/해제 등을 미리보기 후 적용한다. 경보 경비가 들어갈 빈 공간이 부족하면 미도착 상태를 유지한다. 자동 피해·내성 판정은 수행하지 않는 GM 보조 방식이다.
7. 층을 삽입하면 일반 계단을 재연결한다. 특수 연결이 있는 삽입/삭제는 먼저 연결을 정리한다. 층 순서 변경은 고도나 물리 좌표를 바꾸지 않는다. 입구/목표 층을 삭제하려면 참조를 먼저 다른 방으로 옮긴다.
8. **전투지도**에서 출력 프레임을 소/중/대형 또는 수동으로 정한다. PNG는 한 변 최대 **3000px**이며, 테스트한 64×36층 전체도는 3000×1687px로 출력됐다.
9. 방·층·장치를 공개한 뒤 **GM 체크 해제 → 내보내기**를 사용한다. 숨긴 데이터는 CSS로만 감추지 않고 공개 데이터에서 제거하며 이미지 정의에도 포함하지 않는다. 플레이어 공유에는 공개 SVG/PNG/JSON을 사용한다. FPB는 GM 전체 프로젝트다.
10. 일괄 PNG는 층별 파일과 JSON 목록을 다운로드한다. 브라우저가 여러 파일 다운로드를 물을 수 있다. 복제의 기본은 현재 지형/배치를 복사하고 라운드·열쇠·장치 운영 상태를 초기화하는 방식이며, 진행 포함도 선택할 수 있다.

## 검증과 후속 범위

관련 21개 파일의 175개 테스트가 통과했고, 이후 플레이어 진단 노출 회귀 1개를 추가해 변경 구간 4개 파일의 29개 테스트를 재확인했다. TypeScript/Vite 빌드와 변경 파일 Biome 검사도 통과했다. 24개 시드에서 층 재생성을 3회씩 반복하는 회귀 검사로 보호된 배치물과 새 배치물의 ID 충돌을 방지한다. 원본/배포 PNG 32개의 해시·크기·시점 crop 및 PNG 시그니처도 검사한다. 저장소 Playwright E2E 모음은 실행하지 않았다.

별도 Chromium 브라우저 점검에서 신규 생성·미리보기 취소·층 삽입의 비대상 동일성·잠긴 층을 둔 다른 층 재생성·개별 함정/영향 범위·GM 발동·3000px PNG·공개 SVG 이미지 내장·FPB 저장/재열기의 던전 전체 JSON 동일성을 확인했다. 390px 화면의 dialog 너비와 scrollWidth는 모두 388px로 가로 넘침이 없었다. 관련 브라우저 오류는 없었다. 실제 iOS/Android 기기 검증은 남아 있다.

현재 경로 검사는 일반 지상 이동과 단조 열쇠/장치 해제에 대한 검사다. 몬스터의 원본 크기·비행·수영·능력, 모든 대형 개체의 통로 통과를 자동 해석하지 않는다. 임의 구조 배치는 GM 경고를 검토한 뒤 적용할 수 있다. 시야/조명·유체 시뮬레이션, 소모/재잠금 퍼즐 해법, 실시간 공동 편집, VTT 전용 벽 파일 및 NPC/퀘스트 상세 연동은 기존 설계의 후속 확장 항목이다. 새 프로덕션 의존성은 추가하지 않았다.
