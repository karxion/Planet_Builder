# 기존 저장본의 행성 기본 이름 보완

원인: 구형 기본 문구의 자동 이름 보완이 최초 설치와 새 지도 생성에만 적용됐다. 기존 로컬 설정과 FPB 자동 복구를 불러오면 ‘새로운 판타지 행성’이 다시 적용됐다.

수정: 초기 설정, FPB 열기·복구, 구형 MAP 열기에서 알려진 기본 문구만 보완한다. FPB 내부 MAP에 실제 이름이 있으면 보존하며, 없으면 저장한 시드로 선택 언어의 이름을 만든다. 실제 자동 이름과 수동 이름은 재열기에서 다시 추첨하지 않는다. 이름 보완 후 복구 캐시를 갱신해 이전 blob을 재사용하지 않는다. 설정 초안은 다른 필드와 직접 작성한 이름을 보존하며 기본 문구만 새 이름에 맞춘다. 지형·NPC·아이템·세계 공간은 재생성하지 않는다.

검증: 관련 Vitest 7개 파일 155개 통과, TypeScript·Vite 빌드 통과. 독립 localhost에서 기본 문구를 이름으로 적용·자동 저장한 뒤 다시 열어 실제 렐름 이름으로 복원됨을 확인했다. 설정과 지도 제목 동기화, 이름 무작위 생성 버튼도 확인했다. Playwright E2E와 전체 lint는 실행하지 않았다.
