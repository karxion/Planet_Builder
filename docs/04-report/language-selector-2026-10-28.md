# 세계와 NPC 언어 선택기 후속 수정

사용자가 재차 보고한 한글 잘림에 대응했다. 최신 배포본의 조사 환경에서는 잘림이 재현되지 않았지만 `appearance:auto`가 지정한 줄 높이를 `normal`로 처리하는 것을 확인했다. 네이티브 외형, 세로 padding과 고정 height 의존성을 제거했다. 최소 높이44px, 가로104px, 줄 높이21px과 별도의 CSS 화살표를 사용한다. 기본 CSS와 세계 작업공간 CSS를 함께 수정하고 두 파일의 캐시 키를 갱신했다.

실제 브라우저의 1764×877 데스크톱 및 390×844 모바일 화면에서 한국어와 English 표시·선택 전환을 확인했다. 계산 스타일은 appearance:none, line-height:21px, padding:0px 28px 0px 12px, 내부 높이42px(테두리 포함44px)이다. `npm run build`의 타입 검사와 Vite 빌드를 통과했다. CSS 표시 수정이므로 별도 단위 테스트나 Playwright E2E는 추가·실행하지 않았다.

FPB 세계 데이터·선택 언어의 저장 정책·편집 초안에는 변경이 없다.
