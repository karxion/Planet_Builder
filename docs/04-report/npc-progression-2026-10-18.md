# NPC 레벨 차등 및 국가 성향 구현 결과

검증일: 2026-10-18

## 반영 내용

- 마을 주요 인물과 일반 경비/길잡이: 1~4레벨.
- 도시 영주와 주요 전문가: 5~10레벨. 귀족은 해당 티어 상단 3개 레벨에서 생성한다.
- 국가 수도: 11~16레벨 대귀족과 핵심 전문가 각 1명 추가.
- FMG의 대륙별 가장 큰 도시에 17~20레벨 전설적 인물 1명 배치. 국가·대륙은 인물의 활동 범위이며 해당 인물의 거주 도시는 별도로 기록한다.
- 평민, 상인, 여관 주인은 도시에서도 비모험가로 유지한다. 추가 보완 후 화면에는 레벨 대신 커머너 CR을 표시한다.
- 국가 성향별 직업 가중치: 군사(전사/팔라딘), 마법(마법사/소서러/워락), 신정(클레릭/팔라딘), 자연(드루이드/레인저), 상업(바드/로그), 균형형.
- 국가 성향 초기값은 정부 형식과 이름의 명시적 키워드에서 추론한다. 세계·NPC에서 국가 선택 후 성향을 바꿀 수 있다. 자동 생성 인물만 변경되며 직접 편집한 NPC는 유지된다. 종교·문화 지도 데이터는 추가하지 않았다.
- NPC 상세에서 직업, 레벨, 지위, 활동 범위를 편집한다. GM의 수동 레벨 설정은 자동 배치 티어 상한과 달리 1~20 범위에서 허용한다. 비모험가의 내부 level=1은 저장 호환용이며 화면에서는 CR로 다룬다.
- 레벨 기반 간이 HP·AC·능력치·숙련·명중·주문 DC를 추가했다. 기존 SRD 기본 참고 능력치는 접을 수 있는 별도 영역에 두어 CR과 레벨을 혼동하지 않게 했다.
- JSON 내보내기는 기존 `statBlock` 필드를 유지하고 용도 표기와 `combatProfile`을 추가했다. FPB에는 국가 설정과 NPC 성장 정보가 함께 저장된다.
- 이전 FPB는 이름·서사·메모·수정 여부를 보존하면서 성장 정보를 보완하고 새 주요 인물을 최초 1회 추가한다. 새 도시 추가와 일부 재생성 시 대륙 인물이 자동 중복되지 않도록 확인한다. 직접 편집한 인물을 보존하기 때문에 GM이 설정한 고레벨 인물의 총수는 자동 배치 제한을 넘을 수 있다.

## 규칙 범위

[D&D 2024 기본 규칙의 티어](https://www.dndbeyond.com/sources/dnd/br-2024/creating-a-character)는 1~4, 5~10, 11~16, 17~20레벨이다. 정착지 규모와 국가 성향에 따른 NPC 배치는 공식 규칙이 아닌 이 앱의 세계 생성 정책이다.

간이 프로필은 완성된 PC 시트나 공식 NPC 스탯 블록이 아니다. 클래스별 히트 다이스/고정 HP 증가와 숙련 진행을 참고하되 능력치 성장과 AC는 앱의 간이 가정을 사용한다. 공격 피해, 주문 목록, 서브클래스, 특기와 전체 클래스 액션은 아직 제공하지 않는다. CR을 레벨로 환산하지 않는다.

## 검증 결과

- Vitest: 커머너 추가 보완까지 42개 파일, 540개 테스트 통과. 신규 테스트 총 56개는 티어 경계, 성향별 분포, 인물 수, 결정성, 중복 방지, 이전 데이터 보완, 런타임 검증과 jsdom UI 상호작용을 포함한다.
- FPB 왕복 테스트에 국가 성향 저장 검증을 추가했다.
- TypeScript 및 변경 파일 Biome 검사 통과.
- Vite 프로덕션 빌드 통과. 기존 classic script/CSS/outDir/청크 크기 경고는 남아 있다.
- 최초 전체 실행에서 이전 리뷰와 같은 기존 생성기 테스트 2개가 5초 타임아웃을 초과했다. 제한이나 대상을 변경하지 않은 전체 재실행은 통과했다.
- UI 편집/설정 동작은 jsdom에서 검증했다. 실제 브라우저 화면, 지도 GPU 렌더링과 모바일 배치는 이번 작업에서 확인하지 않았다. 저장소 지침에 따라 Playwright E2E를 자동 실행하지 않았다.
- GitHub 커밋/푸시와 공개 사이트 재배포는 수행하지 않았다. 이전 리뷰 변경 및 기존 QA 이미지도 보존했다.

## 커머너 추가 보완

[공식 2024 커머너](https://www.dndbeyond.com/sources/dnd/br-2024/creature-stat-blocks/#Commoner)는 CR 0이다. 요청된 1/8·1/4·1/2는 캐릭터 레벨과 별도의 도전 지수로 구현했다. 분수 CR 커머너는 앱의 변형이며 추정 CR이라고 표시한다.

- 자동 배정: CR 0 70%, 1/8 20%, 1/4 8%, 1/2 2%. 시드와 NPC ID로 결정한다.
- 커머너 상세에는 CR 선택기를 제공하고 레벨/티어 표시는 숨긴다. 목록에는 선택한 CR이 표시된다.
- 등급별 간이 HP·AC·명중·평균 근접 타격 피해와 XP가 달라진다. 기존 공식 SRD 참고 능력치는 변경하지 않는다.
- 기존 자동 생성 커머너는 CR을 보완하며 직접 수정한 이전 커머너는 CR 0을 부여한다. 이름·서사·메모는 보존한다. 수동 CR 설정은 재생성 및 국가 성향 변경 시 유지한다.
- FPB 왕복과 JSON의 `combatProfile`에 선택 CR과 변형 수치를 반영한다. 모험가 클래스로 바꾸면 커머너 CR을 제거한다.
- 이 보완으로 회귀 테스트 14개를 추가했다. 전체 540개 테스트, TypeScript, Biome 및 프로덕션 빌드가 통과했다. 실제 브라우저 화면 검증과 재배포는 수행하지 않았다.
