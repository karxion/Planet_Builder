# 세계관 매직 아이템 관리

## 구현

- 상단 `세계·NPC` 바로 뒤에 `아이템` 버튼을 둔다. 아이템 목록·레퍼런스는 클릭 시 지연 로드한다. 큰 화면의 넓은 브랜드 여백을 줄이고, 모바일에서는 도구 행의 가로 스크롤로 겹침을 방지한다.
- `CampaignWorld.itemLibrary?: ItemLibrary`는 선택 필드로 추가한다. 기존 `.fpb`와 호환되며 새 항목·이미지·소유주·보상 출처·삭제 기록을 캠페인과 함께 직렬화한다.
- 기존 보물의 원본 ID를 등록부 ID에 매핑하여 중복 등록하지 않는다. 보물 원본이 없는 판에서는 국가(베리 레어 이상), 수도(레어 이상 유니크), 던전 보상 후보를 SRD 옵션에서 결정론적으로 생성한다. 자동 항목의 삭제 기록은 다시 열기·동기화 시 유지한다.
- 소유주는 미지정/NPC/행정 단위/직접 입력으로 구분한다. 던전 보상 출처는 현재 소유주와 독립적이다. NPC·행정 ID와 표시 이름을 보존하며 누락된 대상은 명시한다. 던전은 표식 인덱스와 셀을 함께 기록해 인덱스 재사용 시 다른 던전으로 조용히 옮겨지지 않게 한다.
- 목록 검색·희귀도/소유 분류·페이지 이동, 아이템 추가·수정·삭제, 레퍼런스 판본·하위형 선택, 원문 표시와 PDF 페이지 링크, JSON 내보내기를 제공한다. 소유주 검색은 표시 후보를 100개로 제한하되 현재 선택은 유지한다.
- 이미지 수동 연결을 `mountImageHandoff`로 추출해 NPC와 아이템에서 공유한다. 실제 ChatGPT 로그인/API 연동은 하지 않는다. 아이템 이름·유형·희귀도·외형만 요청문에 넣고 소유주·던전·역사·GM 메모는 제외한다. 동일한 JPEG 재인코딩·크기 제한·URL/SVG 차단을 적용한다.
- 이미지 변경은 즉시 적용하지만 텍스트는 변경 저장 후 적용한다. 텍스트 초안은 항목 전환·창 닫기·다시 열기 동안 메모리에 유지하고 새로고침 시 경고한다. 프로젝트 파일에는 적용된 값만 포함한다.

## 검증

- 최신 작업 전체: 74개 파일·838개 테스트 통과. 타입 검사·프로덕션 빌드 통과.
- 공개 소스 회귀: 34개 파일·303개 테스트 통과. 별도 호환 환경에서 공개 NPC/이미지/아이템 편집기 22개 테스트 통과. 공개 소스 타입 검사·공식 배포 빌드 통과.
- 결정론적 생성, 중복·삭제 복구 방지, 기존 보물 등록, 표식 인덱스 재사용, 누락된 소유주, 안전한 이미지·입력 검증, 압축 프로젝트 왕복, 소유주/던전 분리, 폼 초안 및 이미지 보존, HTML 삽입 차단을 검사했다.
- 실제 공개 화면에서 상단 버튼 배치, 아이템 창 열기, 검색 결과 34개에서 1개로 필터링, 이미지 요청문 펼치기·복사 완료 표시를 확인했다.
- 기존 전역 CSS로 선택 상자의 글자가 잘리고 유니크 체크박스가 숨겨지는 문제를 발견해 전용 스타일과 회귀 테스트로 수정했다. 던전 선택 항목은 동명 던전을 구별하도록 표식 ID와 좌표를 표시한다.
- 데스크톱 1280×720 및 모바일 크기 390×844에서 화면을 직접 확인했다. 모바일 크기에서 보이는 입력·선택·버튼의 수평 화면 넘침은 0개였다. 검증용 화면 크기는 종료 전에 복구했다.
- 화면 기록: [데스크톱](assets/world-items/items-desktop.png), [모바일 크기](assets/world-items/items-mobile.png).
- 실제 모바일 기기의 터치 조작과 실제 이미지 생성·첨부, 사용자 데이터에 대한 저장·삭제는 브라우저에서 실행하지 않았다. 이미지·저장·삭제 흐름은 자동 테스트로 검사했다. Playwright E2E 전체 실행은 하지 않았다.

## 범위와 제한

- 던전 보상 출처는 설정·추적용 연결이다. 내부 던전의 상자 칸에 배치하거나 획득 시 소유주를 자동으로 이전하는 기능은 포함하지 않는다.
- 기존 세계관 보물은 출처 기록으로 유지한다. 등록부에서 변경한 현재 소유주를 원본 국가·도시의 역사 기록으로 역전파하지 않는다.
- 기존 SRD 5.1/5.2.1 카탈로그를 공개판에 이식하고 CC BY 4.0 고지를 추가했다. 새로운 생산 의존성을 추가하거나 상용 규칙서·위키를 무단 수집하지 않았다.
- 새로고침 후 미적용 아이템 초안을 복구하는 기능은 아직 없다. 변경 저장한 아이템과 이미지는 `.fpb` 및 기존 프로젝트 저장 흐름에 포함된다.
- 최신 로컬의 미공개 던전·보안·복구 기능 전체를 공개판에 덮어쓰지 않았다. 사용자 GitHub에는 별도 푸시하지 않는다.
