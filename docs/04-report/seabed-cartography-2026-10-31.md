# 해저 지형을 지도 기호로 표시

사용자가 지상의 산·숲처럼 작고 반복되는 지도 기호를 요청했으므로, 이전의 큰 PNG 지형 그림과 수심 숫자 배지 방식은 기본 지도에서 제거했다. 첨부된 지상 지도 참고처럼 선과 옅은 음영으로 구성한 SVG 지형 기호 16종을 지도 본문에 직접 배치한다. 이전 PNG 원본·제작 기록은 보존한다. 최초에는 로컬에서만 검토했고, 이후 사용자가 이 버전의 GitHub 커밋과 기존 공개 사이트 반영을 요청했다. 같은 소스의 고정 커밋을 단일 소스 배포 절차로 전달한다.

## 최종 표시

- 대륙붕·사면·평원·해구·해령·산호초·대륙대·협곡·열곡·해산·평정해산·선상지·구릉·해연·단열대·사구를 서로 다른 작은 윤곽 기호로 구분한다. 지도 좌표 기준 최대 24×14 크기이며 확대·축소에 따라 지도와 함께 움직인다.
- 저장된 지형 셀에만 반복 배치한다. 실제 셀 중심을 쓰고 도시와 이름표의 공간을 피하며 지도 데이터·도시 좌표를 이동하지 않는다. 표시용 별도 시드로 재현하고 희귀 지형도 대표한다.
- 숫자 배지와 지도 위 수심 키를 제거했다. 클릭/Enter/Space와 마우스 안내의 정확한 수심 조회는 유지한다. 공간 편집의 해저·세력 탭에는 지도와 같은 기호 범례와 현재 수심 범위를 제공한다.
- 해저의 기본 바다색을 옅게 하고 세력권 채움 농도를 낮춰 작은 선 기호를 읽을 수 있게 했다. 지형 아이콘 레이어·영역색·경계의 기존 개별 제어를 유지한다. 기존 도시·자원·기록은 유지한다.
- 저장·복구 형식이나 지형 생성값을 변경하지 않는다. 기존 지도는 재생성 없이 새 렌더러를 사용한다. PNG/SVG 내보내기에도 같은 기호를 포함한다.

## 검증 및 로컬 확인

- 관련 5파일 29개 단위 테스트 통과. 실제 저장 셀/수심 조회, 세계 불변, 전 지형 대표, 반복 배치 재현, 작은 벡터 기호와 숫자 배지 부재, 레이어 숨김과 범례를 확인했다.
- 타입 검사·Vite 빌드 통과. 기존 레거시 스크립트/청크 경고는 남아 있다. Playwright E2E는 실행하지 않았다.
- localhost4195의 에르미리아에서 16종 기호 422개, 구형 지형 PNG 0개·수심 숫자 0개, 해연 기호 선택 시 10,800m 상세와 콘솔 오류 없음을 확인했다.
- 실제 SVG 내보내기에서 기호 정의16개·표시422개와 구형 PNG 지형/수심 키 부재를 확인했다. 실제 PNG는 현재 지도의 비율을 유지한 3000×1688이다.
- 확인 주소: `http://127.0.0.1:4195/Fantasy-Planet-Builder/`. 사용자 확인을 위해 수중 지도 탭과 서버를 유지한다.
- 작업 폴더 증빙: `.codex/seabed-relief/cartographic-map-2026-10-31.png`, `cartographic-export.svg`, `cartographic-export.png`.

핵심 구현은 `src/renderers/seabed-glyphs.ts`, `src/renderers/seabed-relief.ts`에 있다. 이 보고서는 이전 `seabed-relief-icons-2026-10-30.md`의 기본 표시 방향을 대체한다.
