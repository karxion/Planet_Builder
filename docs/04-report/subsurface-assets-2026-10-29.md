# 지저·해저 전용 이미지 모듈 1차 제작

2026-10-29 사용자 요청으로 설계 목록의 **1차 우선 24종**을 실제 투명 PNG로 제작했다. 확장 40종은 이번 제작 범위에 포함하지 않는다. 앱의 지도 배치·도시 이름·NPC·아이템 생성 연결과 별개로, 이 문서는 이미지 원본과 배포물의 제작 근거를 기록한다.

## 산출물과 출처

- 생성 방식: Codex 내장 `image_gen` 도구. 신규 개별 오브젝트 호출 24회, UT05의 시점 구역 여백 수정 1회. CLI/API 대체 생성은 사용하지 않았다.
- 원본: `assets/subsurface-originals/{id}.png` 24개. 첫 UT05 구도 원본도 `ut05-framing-draft.png`로 보존한다.
- 배포: `public/assets/subsurface/{id}.png` 24개. 소문자 ID 파일명과 실제 SHA-256을 `src/data/subsurface-image-manifest.json`에 기록했다.
- 최종 프롬프트 세트: `assets/subsurface-originals/generation-spec.json`. 공통 프롬프트와 각 오브젝트 subject를 결합한다. ST01 최초 프롬프트와 UT05 여백 편집 지시는 같은 파일의 `promptOverridesAndEdits`에 기록했다.
- 재현용 축소 도구: `assets/subsurface-originals/prepare.py <local-generation-paths.json>`. 사용자가 요청한 배포 크기 약 2/3의 정적 축소와 알파 검수에 Pillow를 사용했으며, 그림을 새로 합성하거나 벡터 대체물로 만들지 않았다. 로컬 생성 경로 목록은 저장소 외부의 작업 자료로 보존하고 배포하지 않는다.

## 형식과 검수

모든 최종 원본은 1774×887 RGBA PNG이며 배포본은 1182×591이다. 원본과 배포본 모두 실제 알파 채널을 보존한다. 왼쪽 절반은 지역지도용 조감도, 오른쪽 절반은 같은 물체의 상부 시점이다. 각각의 오브젝트는 별도 파일이며 여러 종류를 한 아틀라스로 모아 생성하지 않았다. 장식 배지·글자·격자·완성 지도 배경을 넣지 않았다.

24종 전체를 직접 시각 검수하고 각 절반에 유효한 피사체가 있는지, 완전히 불투명한 배경이 아닌지, 실제 파일 크기와 SHA가 manifest에 맞는지 확인했다. `qa.json`에는 투명 픽셀 비율과 알파 64 초과 부분의 시점별 경계 상자를 기록한다. UT05의 왼쪽 버섯이 처음에는 중앙 절반 구역을 넘어가 내장 도구로 구도만 수정했고 기존 초안은 보존했다.

이 PNG는 시각 모듈이다. 오른쪽 시점에는 물체의 형태를 알기 위한 입면 표현이 일부 남아 있으므로 정밀한 수직 정투영 치수·통행·충돌 판정 자료로 간주하지 않는다. 광물 생산량이나 채굴 확률, 벽·다리의 게임 규칙은 그림에서 추정하지 않는다. 앱 통합에서는 우선 왼쪽 조감도 절반을 지역 표식으로 사용한다.
