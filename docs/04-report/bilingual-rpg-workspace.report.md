# 한영 전환 및 RPG 작업 공간 개선

## 구현

- 상단, 세계·NPC 창, 클라우드 창, 기존 설정 메뉴에 한국어 / English 선택기를 추가했다. 기본값은 한국어이며 브라우저에 선택을 저장한다.
- 명시적 번역 사전으로 주요 지도 메뉴, 레이어, 편집 도구, 설정, 공통 대화상자, 상태 알림, NPC 규칙을 전환한다. 외부 자동 번역 서비스는 사용하지 않는다.
- 지도 SVG, 세계 이름, NPC 이름·직업·서사, 사용자 메모와 입력값은 번역 대상에서 제외했다.
- 동적 UI에도 번역을 적용하고 기존 이벤트 연결과 선택 항목의 내부 값을 보존한다. 지형 편집 모드, 스타일 저장 상태, 삭제 단축키는 표시 문구와 내부 상태를 분리했다.
- 차콜 표면, 금색 테두리, 녹색 선택 상태와 세리프 제목으로 RPG 지도 제작 작업 공간을 구성했다. 기존 지도 도구와 NPC 능력치 표에도 동일한 스타일을 적용했다.
- 모바일에서는 두 줄 도구 모음을 사용하며 3D 캔버스가 실제 헤더 높이를 따른다. 지도 도구 진입 버튼, 포커스 표시, 아이콘 툴팁을 보강했다.
- 스타일 선택기의 오래된 분류 제거 대상 ID를 실제 요소 ID로 바로잡았다.

## 실제 브라우저 검증

기존 개발 서버의 실제 앱에서 수행했다.

| 검증 | 결과 |
| --- | --- |
| 한국어 ↔ 영어 전환 및 새로고침 후 설정 유지 | 통과 |
| 레이어 표시 전환 후 SVG 지도 이름 및 option 내부 값 보존 | 통과 |
| 미저장 행성 이름과 NPC 이름·메모·규칙 템플릿 보존 | 통과 |
| NPC 창 내부 언어 선택과 영어 규칙 표시 | 통과 |
| 기본 스타일 덮어쓰기 방지 및 한국어 오류 표시 | 통과 |
| 클라우드 미설정 안내의 한영 전환 | 통과 |
| 1440×900 / 1920×1080 / 390×844 화면 확인 | 통과 |
| NPC 창 가로 넘침 및 언어·닫기 버튼 겹침 검사 | 없음 |
| 모바일 3D 캔버스 390×744, 데스크톱 1920×1022 | 정상 |
| 행성 이미지 픽셀 검사 | 모바일 249색, 데스크톱 183색으로 비어 있지 않음 |
| 행성 드래그 회전 전후 이미지 검사 | 픽셀 변화 확인 |

NPC 입력 보존 검사는 저장하지 않고 원래 입력값으로 복원했다. UI 검증을 위해 세계를 재생성하거나 NPC를 삭제하지 않았다.

## 자동 검증

- TypeScript 타입 검사 통과.
- Vitest 16개 파일, 181개 테스트 통과.
- 변경한 TypeScript UI 파일 5개 Biome 검사 통과.
- Vite 프로덕션 빌드 통과. 원본의 레거시 스크립트 번들링 및 큰 청크 경고는 남아 있다.
- 저장소 지침에 따라 이번 작업에서는 Playwright E2E 러너를 실행하지 않았다. 위 화면 검증은 앱 내 실제 브라우저에서 수행했다.

## 제한

- 사전에 등록되지 않은 고급 원본 편집기 문구는 영어로 표시된다. 전체 원본 UI의 모든 문장을 완역한 상태는 아니다.
- 기존 세계의 고유명사와 서사 데이터는 언어 전환으로 변경하지 않는다.
- 실제 클라우드 인증·저장은 환경이 설정되지 않아 이번 작업에서 검증하지 않았다.
