# 해저 지형학 보완 결과

후속: 사용자 제공 PDF를 검수한 [현재 반영 기록](./subsurface-pdf-review-2026-10-28.md)이 있다. 아래 접속 실패는 초기 구현 당시의 상태이며, 이후 제공된 PDF의 열람 상태와 구분한다.

## 지도 업데이트

- 사용자 기준에 따라 대륙붕/급한 사면/완만한 대륙대/심해평원을 구분했다.
- 협곡과 하단 선상지, 대양의 중앙해령과 축부 열곡, 활동성 주변부 해구와 국지적 해연을 생성한다.
- 고립 해산/평정해산과 심해 구릉·단열대의 형태를 추가했다. 해령·해산은 바닥 대비 높이와 정상 수심을 별도로 기록한다.
- 존재하는 지형만 범례에 표시하고 분류 설명, 주요 지형 툴팁, 거주지 위치의 해저 분류/바닥 수심을 제공한다.
- 기존 0~6 코드의 저장 지형은 유지한다. 명시적 재생성 시 새 0~15 코드 및 지형 메타데이터를 적용한다.

## 검증

- Vitest 5개 파일 52개 테스트 통과: seabed, underwater, underground 생성기와 세계 공간 모델/렌더러.
- 수심 범위, 육지 보존, 생성 재현성, 해령 상대 높이와 열곡 함몰, 1000m 이상 해산 및 평정 정상의 동일 수심, 기존 저장 파일 복원 및 손상 데이터 거부를 확인했다.
- 변경 TypeScript 파일 Biome 검사와 프로덕션 빌드 통과. 기존 레거시 스크립트/번들 크기 경고는 유지한다.
- Chromium 수동 점검에서 새 지형·범례 표시, 세력권 보기 전환, 종족/외교/도시 편집, PNG 3000px, FPB 저장·재열기 시 동일 데이터, 재생성 편집 보존, 모바일 편집창을 확인했다. 앱 예외는 관측되지 않았다.

## 미완료: 논문/기관 자료 대조

실제 HTTP 접속 6건은 모두 403이었다. NOAA/IHO/USGS 원문과 Crossref 논문 메타데이터를 읽지 못했으며, 검증한 논문 출처로 기재하지 않았다. 현재 구현은 사용자 제공 기준과 일반 지형학 지식을 반영한 형태 합성이다. 추가 지형 선상지·구릉·단열대의 논문 대조는 미완료다.

[실제 수집 기록](./seabed-source-attempt.json), [설계와 자료 확인 상태](../02-design/seabed-geomorphology-v2.md), `scripts/collect-seabed-sources.ts`에 재개에 필요한 내용을 남겼다. 도메인 접근 초안은 저장했으나 미적용이다. 사용자가 클라우드 환경 설정에서 검토/저장 후 게시하면 실제 자료 조회를 이어서 진행해야 한다. 기존 수중 세력·지저 기능과 공개 사이트 배포는 별도다.
