# 표식 설명 한·영 표시 및 비문 문자 깨짐 수정

## 원인

- 원본 석상·비석 생성기가 보충 평면 유니코드 문자를 `split("")`로 나눠 서로 짝이 맞지 않는 서로게이트를 생성했다. 지원 글꼴이 없는 고대 문자도 사용해 대체 문자·네모가 나타났다.
- 자동 생성된 표식 설명은 영어 문자열로 저장됐으며 일반 UI 번역기가 `notesHeader`와 `notesBody`를 의도적으로 제외하고 있었다.

## 수정

- 고대 문자 무작위 조합을 제거하고 읽을 수 있는 비문 해독 상태 문장을 사용한다. 비문 내용의 가짜 번역을 만들지는 않는다.
- 기존 지도에서 정확히 일치하는 원본 자동 비문 블록만 표시 시 보정한다. 디스크 파일과 원본 `notes` 데이터는 변경하지 않는다.
- 자동 생성 표식의 제목 어휘·설명 템플릿을 한국어로 표시한다. 영어 선택 시 동일한 원본에서 영어 설명을 표시하며 열린 설명창도 즉시 갱신한다.
- 사용자 작성 고유명·자유 메모·미확인 문장은 임의로 번역하거나 덮어쓰지 않는다. 영어로 지정된 고유명과 SRD 규칙 원문 전체를 기계 번역하는 기능은 아니다.
- 설명 렌더링은 DOMPurify 정화 후 텍스트 노드만 번역한다. 사용자 HTML 문자열을 번역 결과에 직접 결합하지 않는다. 공개판에도 이전에 승인된 DOMPurify `3.4.17`을 적용한다.
- 표식 도움말·편집창 제목·유형명을 언어 선택에 연결한다. 번역된 유형을 수정해도 내부 생성기 ID는 보존하며 사용자 정의 유형도 유지한다. 표식 목록은 한국어와 원본 유형 ID 모두로 검색한다.
- 기록 편집창에는 번역된 내용을 표시하되 실제 편집이 없는 열기·포커스 이동은 원문을 덮어쓰지 않는다. 실제 편집은 사용자 메모로 보존한다. AI 기록 요청문의 출력 언어도 현재 언어에 맞춘다.
- 설명창의 한글 글꼴, 14px 본문, 줄간격, 대비, 최대 너비·높이 및 줄바꿈을 정리한다. 레거시 스크립트 캐시 버전을 갱신한다.

## 자동 검증

- 최신 작업: 77개 파일·879개 테스트 통과, TypeScript 검사·Vite 빌드 통과.
- 공개 소스: 호환 테스트 설정에서 기존 34개 파일·303개 회귀 테스트와 추가 UI 7개 파일·66개 테스트 통과. 공개 소스 TypeScript 검사 통과.
- 공개 소스 자체 기본 테스트 명령은 기존 전역 DOM 스텁 설정이 빠져 실패했다. 같은 소스에 기존 호환 설정과 스텁을 적용한 위 검사는 통과했다. 이 제한을 테스트 통과로 숨기지 않는다.
- 깨진 비문 보정·보정의 멱등성·사용자 메모 보존·안전한 HTML 처리·가시적 설명의 언어 전환·생성 설명 30종·분류 ID 보존·기록 편집 원문 보존을 검사했다.
- 실제 미리보기에서 비석 설명과 하단 도움말의 한국어·영어 전환을 확인했다. 이 과정에서 레거시 Node 전용 `listen`에 `window`를 전달하는 오류를 발견해 표준 이벤트 등록·해제로 수정하고 회귀 테스트를 추가했다.
