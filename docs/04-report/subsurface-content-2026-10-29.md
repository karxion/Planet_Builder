# 해저·지저 도시/주민/전용 에셋 적용

설계안만 존재했던 전용 에셋 24종을 실제 투명 PNG로 제작해 지역지도에 배치했다. 24개 오브젝트 각각의 원본과 축소본·프롬프트·SHA를 보존하며, 확장 40종은 이번 범위에 포함하지 않는다. 지역지도는 왼쪽 조감도를 사용한다. 오른쪽 상부 시점을 정밀 정투영/전투 충돌 정보로 주장하지 않는다. 이미지 생성·여백/알파 검수는 별도 제작 보고서에 기록한다.

도시의 단순 도형에 전용 주택/벽/문 PNG를 연결하고 자연물·자원 장식과 관문을 배치했다. 도시 고유 이름과 영역명을 세로로 분리하고 도시 텍스트를 먼저 배치하여 같은 위치의 영역명이 가리는 문제를 수정했다. PNG 내보내기는 새 로컬 이미지도 인라인한다.

도시마다 NPC4명·아이템3종을 생성한다. 해저·지저를 선택한 상태에서 상단 세계·NPC/아이템을 열면 해당 공간의 도시 목록으로 한정한다. 교역 NPC는 해당 도시의 아이템을 열고, 의뢰·정보 NPC는 교류 내용을 제공한다. 사용자 편집과 초안/복구·FPB 저장을 지원한다. 기존 파일은 지형을 재생성하지 않고 누락된 기록만 보완한다. 수정한 기록의 도시는 공간 재생성에서도 보존한다. 새로운 경제 생산량·실거래 차감·AI 대화 API를 도입한 것은 아니다.

최종 관련 단위 테스트 15개 파일 189개 및 타입 검사·Vite 빌드를 통과했다. PNG 24종의 시그니처/RGBA/크기/원본·배포 SHA/2⁄3 비율, 지도 및 지상 공간의 PNG 분리, 도시 이름, 전용 목록 분리·교역·편집·초안, 저장·복원과 기존 회귀를 포함한다. 구형 파일의 자동 보완은 변경 알림을 보내 복구 저장이 이전 blob을 재사용하지 않게 한다. Playwright E2E는 실행하지 않았다. 기존 비모듈 스크립트 및 큰 chunk 경고는 남아 있다.

독립 localhost 테스트 프로젝트에서 해저 도시명/이미지·NPC48명/아이템36종, 지저 도시명/이미지·NPC72명/아이템54종을 확인했다. 해저 교역을 선택하면 해당 도시의 아이템3개로 좁혀졌고, 지상에서는 기존 세계와 NPC 목록(2288명)이 열렸다. 사용자 공개 프로젝트의 지도/데이터는 재생성하지 않았다.
