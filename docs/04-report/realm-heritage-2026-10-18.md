# 국가 보물·도시 상징품·종교 구현

검증일: 2026-10-18

## 구현 결과

- 모든 실제 국가에 최소 1개 베리 레어 또는 레젠더리 보물을 생성한다. 영토 비중과 건국 경과 연수가 클수록 목표 수량이 늘며 최대 12개다. 건국 경과 기본값은 시드로 생성하고 보물/종교 탭에서 수정한다.
- 수도와 일부 도시에 유니크 상징품을 생성한다. 성능 희귀도는 레어~레젠더리이고, 유니크는 상징적 유일성 태그다. 상징성·RP 영향·효능 개요·유래·GM 메모를 각각 편집한다.
- 종교에 상징 설명, D&D 9성향, 신격 이름, 소신격/중신격/대신격, 교리와 총본산 위치를 제공한다. 국가마다 최소 1개, 최대 3개 종교를 생성한다. 성향에 맞는 교리 문구를 사용한다.
- 세계·NPC 창에 NPC/보물/종교 탭을 추가했다. 행정 필터, 검색, 30개 단위 페이지 이동, 상세 편집, 지도에서 보기와 JSON 내보내기를 제공한다.
- 총본산은 기존 RPG 기념물 에셋과 연결선, 흰색 외곽선 라벨로 지도에 개별 표시한다. 클릭/키보드로 종교 상세를 열며 지도 표시를 켜고 끌 수 있다. 정착지·자원·지형·라벨이 렌더링된 후 빈 공간에 표시 오프셋을 계산한다.
- 신앙 데이터는 새 `CampaignWorld.heritage`에 저장한다. 기존 FMG 문화·종교 셀 구획과 군사/경제 관련 문화·종교 데이터를 복원하지 않는다. 기존 행정 체계를 유지한다.
- 이전 FPB에는 최초 복원 시 데이터를 보완한다. 수정된 기록은 덮어쓰지 않는다. 영토/역사 증가 시 부족한 보물을 보충하지만 연수가 줄어도 기존 보물은 삭제하지 않는다. 삭제된 정착지의 총본산은 목록에서 재지정할 수 있다.
- FPB는 모든 새 기록을 저장한다. 파생 총본산 SVG는 `.map` payload에서 제외하고 복원 시 다시 그린다. 레거시 `.map`만으로는 보물/종교 편집 기록을 보존하지 못하므로 전체 프로젝트 저장은 `.fpb`를 사용한다.

## 규칙 경계

[공식 D&D 2024 아이템 희귀도](https://www.dndbeyond.com/sources/dnd/br-2024/magic-items)를 참고하되, 유니크 태그·보물 수량·건국 역사·신격 3등급은 요청에 따른 앱의 세계관 정책이다. [9성향](https://www.dndbeyond.com/sources/dnd/br-2024/creating-a-character)은 공식 분류를 사용한다.

생성 아이템과 신격은 창작 서사 프리셋이다. 완성된 공식 아이템 스탯 블록이나 신격 전투 수치는 제공하지 않는다. 효능의 구체적 횟수·DC·피해량과 RP의 실제 판정은 GM이 정한다. 종교 목록과 총본산 표기는 제공하지만 종교 영토 확장/인구 시뮬레이션은 구현하지 않는다.

## 검증

- Vitest 전체: 44개 파일, 563개 테스트 통과. 이번 기능에서 23개 테스트를 추가했다.
- 국가 보물의 하한/등급과 면적·역사별 증가, 도시 유니크/희귀도, 결정성, 9성향·신격 등급, 이전 데이터 보완, 편집 보존, 런타임 검증 및 FPB 왕복을 검증했다.
- jsdom에서 탭 전환, 역사 수정, 보물/종교 폼 저장, 총본산 변경·표시 토글과 지도 선택 이벤트를 확인했다.
- 총본산 SVG의 개수, 중복 렌더링 방지, 연결선, 접근성, 클릭/키보드 동작, 정착지/표식 간 간격 및 HTML을 해석하지 않는 텍스트 처리를 테스트했다.
- TypeScript, 변경 파일 Biome 및 Vite 프로덕션 빌드 통과. 기존 classic script/CSS/outDir/청크 크기 경고는 남아 있다.
- 실제 브라우저 화면·모바일 배치와 매우 밀집된 지도에서의 시각적 품질은 미검증이다. 빈 공간이 부족한 표식은 `data-unresolved`로 표시하므로 실지도에서 확인이 필요하다. 저장소 지침에 따라 Playwright E2E는 자동 실행하지 않았다.
- GitHub 커밋/푸시 및 공개 사이트 재배포는 수행하지 않았다. 기존 리뷰 변경과 QA 이미지도 보존했다.
