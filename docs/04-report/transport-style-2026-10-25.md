# 강·도로 가독성 개선

## 변경

| 구분 | 표기 |
| --- | --- |
| 강 | 푸른 물색 #278fc4, 불투명도 1 |
| 간선도로 | 갈색 실선, 굵기 1.1, 둥근 끝·모서리 |
| 소로 | 회갈색 점선 1/1.8, 굵기 0.35 |
| 어두운 프리셋 도로 | 물길과 구별되는 밝은 황갈색 계열 |

간선도로는 기존 엔진의 수도 연결 `roads`, 소로는 정착지 연결 `trails`를 사용한다. 국가별 도로 유지·보수 책임이나 관리 주체를 시뮬레이션하는 새 데이터는 추가하지 않는다.

기본 스타일 프리셋 12개에 적용한다. 이전 지도는 초기화 및 `map:loaded`, `map:generated` 이벤트에서 한 번 전환한다. SVG 그룹별 버전 속성을 저장하여 이미 전환한 지도의 수동 스타일 수정을 존중한다. 도로 경로, 국가 경계, 항로 및 레이어 표시 상태는 유지한다.

CSS 강제 덮어쓰기를 사용하지 않고 SVG 속성을 변경하므로 기존 스타일 편집기와 저장·출력·3D 텍스처용 SVG 직렬화 경로를 공유한다. 실제 이미지 출력과 3D 화면에서의 확인은 별도 검증이 필요하다.

## 검증

- 최신 작업 소스 전체: 62개 파일, 776개 단위 테스트 통과.
- 신규 17개 테스트: 12개 프리셋, 색상·굵기·패턴, 한 번만 전환, 수동 편집 및 직렬화 보존, 이벤트별 지도 교체, 누락된 그룹 처리.
- 최신 작업 및 공개용 소스 타입 검사 통과. 변경 TypeScript Biome 검사, 최신 Vite 빌드 통과.
- 공개용 프리셋 12개 검사와 기존 소스 291개 회귀 테스트 통과. 공개용 회귀 테스트는 전역 호환 외부 설정으로 실행하며 기본 테스트 설정은 변경하지 않음.
- 실제 브라우저 화면, PNG·SVG 결과 및 3D 시각 검증은 미완료. 자동 Playwright는 실행하지 않음.
- 새 의존성 없음. 기존 레거시 스크립트·대형 번들 경고 유지.
