# 지상·해저·지저 공통 던전 생성

기존 자동 던전은 지상의 육지 셀·국가만 입력으로 사용했다. 같은 던전/내부 지도 저장 구조를 유지하며, 해저 바닥과 지저의 층별 바닥을 별도 배치 입력으로 연결했다.

- 기존 표식의 누락된 `space`는 지상이다. 새 해저/지저 표식에는 `space`, 지저에는 `levelId`를 저장한다. `cell`은 기존 편집기 호환을 위해 실제 좌표와 가장 가까운 지상 pack 셀을 유지하며, 배치·소속 판정에는 해당 세계의 셀을 사용한다.
- 해저는 수심이 있는 셀과 수중 세력권, 지저는 각 층의 공동·터널·공동 세계 육지와 거주지 세력 분포를 사용한다. 지저 암반·호수·용암과 지도 사방8% 가장자리는 자동 후보에서 제외한다. 정착지/거점 간격은 기존 설정을 사용하며 부족한 공간은 강제로 완화하지 않는다.
- 해저/지저를 명시적으로 생성하면 던전도 함께 생성한다. 터널형 지저는 3개 층을 각각 생성하고 공동 세계는 단일 내부 세계에 생성한다. 기존 지도를 여는 것만으로 재배치하지 않는다. 기존 지도에는 공간 편집 → 던전 위치 → 공백지 자동 배치를 사용할 수 있다.
- 지도와 던전 목록은 현재 공간·지저 층만 표시한다. 공간 편집창에 던전 위치 진입을 추가했다. 표식 레이어를 따르고 실제 좌표에 아이콘을 표시하며 클릭/Enter/Space로 기존 다층 던전 편집기를 연다. 새 해저 v2 내부 지도는 침수 환경을 기본으로 하고 기존 내부 지도는 다시 추첨하지 않는다. 수동 배치/위치 보기/표식 편집/내부 지도/잠금/공략 상태 기능을 유지한다.
- 재생성은 현재 공간·층의 미수정 자동 거점만 교체한다. 다른 공간과 수동·수정·잠금·내부 지도·편집 초안이 있는 기록/노트는 보존한다. 지상 표식 일괄 재생성도 해저/지저 표식을 제거하지 않는다. 생성은 복사본에서 준비해 실패 시 기존 던전/노트를 교체하지 않는다.
- MAP의 기존 표식 JSON과 FPB 스키마1을 유지한다. 내부 지도는 기존 `interior`에 저장되며 복제 시 공간/층도 유지된다. 지상 아이템 보상 출처 목록에 해저/지저 던전이 섞이지 않게 했다.

## 검증

- 전체124파일1277개 단위 테스트 통과. 후속 공동 세계·초기화 회귀 추가 후 관련4파일23개 통과. 최종 타입 검사/Vite 빌드 통과. Playwright E2E와 전체 lint는 실행하지 않았다.
- 새 탭 초기화 전에 `pack.markers`가 없는 경우 발생한 오류를 수정하고 회귀 검사를 추가했다.
- 독립 localhost4196에서 테디니아의 해저26개, 얕은 지저12개, 중층11개, 심층10개 자동 배치·층별 서로 다른ID·목록 분리를 확인했다. 해저 목록과 지저 지도 아이콘에서 3층 v2 미리보기/적용을 확인했고 해저 환경이 `flooded`임을 확인했다.
- 실제 FPB 저장 파일의 압축을 해제해 표식 JSON의 지상53개(일반 표식 포함), 해저26개, 지저12/11/10개와 해저/심층의 저장된 v2 내부 지도2개를 확인했다. 새 탭 자동 복구 후 같은 행성/심층10개 표시를 확인했다. 파일 선택 도구의 CDP 시간 초과로 수동 FPB 재열기의 브라우저 검증은 완료하지 못했다.
- 단위 검증은 유효 바닥·내해 제외·세계 불변·공간 독립·ID중복 없음·반복 채우기 중복 없음·내부 지도/노트 보호·층별 표시·침수 기본값·복제 소속 보존을 포함한다.
