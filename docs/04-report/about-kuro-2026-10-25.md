# 정보 탭 정리

## 범위

- 원작: Azgaar's Fantasy Map Generator, Azgaar (Max Haniyeu).
- 개조·확장: KURO. 원작 기반의 비공식 파생 프로젝트임을 명시.
- 자유로운 앱·지도 이용과 피드백 환영 안내. 연락처: karxion@gmail.com.
- 원작 MIT 및 D&D SRD 라이선스 안내 유지. 기존 원작 홍보 영역을 참고 자료로 정리.
- 정보 탭에만 적용되는 CSS로 본문 대비, 링크 색상·밑줄, 키보드 포커스와 줄바꿈 개선.
- 한국어 기본 문구와 영어 번역 지원. 고유명·이메일은 자동 번역에서 제외.

## 검증

- 최신 작업 소스: 59개 파일, 759개 단위 테스트 통과.
- 최신 작업 소스: 타입 검사, 변경 TypeScript Biome 검사, Vite 프로덕션 빌드 통과.
- 공개용 기존 소스: 외부 테스트 설정으로 32개 파일, 291개 테스트 통과. 기존 기본 테스트 설정의 전역 객체 누락은 배포 범위 밖으로 유지.
- 공개용 HTML/CSS: 정보 탭 전용 5개 테스트 통과. 출처, 이메일, 이용 안내, 외부 링크, 언어 전환 및 계산된 색상 대비 확인.
- 실제 브라우저 캡처·모바일 검증은 실행 제한으로 미완료. DOM 기반 검사를 실제 시각 검증으로 간주하지 않음.
- 신규 의존성 없음. 기존 레거시 스크립트 및 대형 번들 경고는 별도 과제.
