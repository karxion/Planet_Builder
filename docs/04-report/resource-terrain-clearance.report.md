# 지형·자원 간격 개선 결과

이 문서는 자원 개별 표시를 먼저 적용한 단계의 기록이다. 이후 사용자 지시에 따라 도시·마을·표식까지 개별 표시로 전환했다. 최신 정책과 검수 결과는 [개별 토큰 보고서](individual-map-icons.report.md)를 참조한다.

## 적용 사항

- 자원 토큰을 도시·표식 그룹에서 제외해 지도에 개별 표시한다. 도시·마을·표식의 기존 그룹 기능은 유지한다.
- 지형 아이콘과 자원 토큰 사이에 화면 기준 최소 6px의 여백을 확보한다. 확대 시에는 지도 단위 최소 간격도 적용한다.
- 가까운 빈 공간을 먼저 탐색하고, 숲·산이 빽빽하면 토큰 주변의 장식용 지형 아이콘만 숨긴다. 고도, 생물군계, 셀, 생산량 데이터는 변경하지 않는다.
- 도시 토큰, 표식, 이름표, 다른 자원 토큰도 충돌 회피 대상으로 삼는다.
- 자원은 같은 영지의 육지/해양 조건을 우선 유지한다. 빈 공간이 없으면 같은 국가 안에서만 표시 위치를 탐색한다.
- 실제 자원 좌표·소속은 유지한다. 토큰이 이동한 경우 원래 위치와 얇은 연결선으로 연결한다.
- 토큰 크기 7 지도 단위 및 자원 사이트 선택 간격 21 지도 단위는 유지한다.
- 도시 그룹 배지도 자원 토큰과 6px 간격을 확보하도록 배치한다.
- 곡선 국가명의 큰 사각형 대신 글자별 영역으로 충돌을 판단한다.
- 레이어 전환·화면 크기 변경·지도 갱신 시 다시 배치하며, 이전 이동량이 누적되지 않도록 복구한 다음 계산한다.
- 자원 레이어를 끄면 주변 장식용 지형 아이콘을 복구한다. 표시 규칙은 SVG 안에 포함한다.

## 실제 화면 검수

현재 복구된 테스트 지도에서 DOM 사각형을 측정하고 화면 캡처를 직접 확인했다. 6px 여백의 부동소수점 오차를 고려해 5.8px 미만을 근접 충돌로 집계했다. 수치는 모든 시드에 대한 보증이 아니라 해당 테스트 지도 결과다.

| 항목 | 수정 전 1440×900 | 수정 후 1440×900 | 수정 후 1920×1080 |
|---|---:|---:|---:|
| 선택된 자원 사이트 | 62 | 62 | 62 |
| 그룹에 숨겨진 자원 | 45 | 0 | 0 |
| 지형 아이콘과 근접한 자원 | 62 | 0 | 0 |
| 자원 간 근접 쌍 | 미측정 | 0 | 0 |
| 도시 그룹 배지와 근접한 자원 | 미측정 | 0 | 0 |
| 개별 도시·표식과 근접한 자원 | 미측정 | 2 | 0 |
| 주변 공간 확보를 위해 숨긴 지형 장식 | 미측정 | 207 | 135 |

- 자원 레이어 끄기: 자원 0개, 연결선 0개, 지형 숨김 플래그 0개로 복구됨.
- 자원 레이어 다시 켜기: 자원 62개 복구, 지형·자원 근접 충돌 0건.
- 지형 레이어 끄기/켜기: 자원 개별 표시와 충돌 회피 유지.
- 1920×1080에서 1440×900으로 되돌린 뒤 동일 결과 확인.

## 남은 개선점

1. 1440×900에서는 허용 반경 내 같은 국가에서 빈 공간을 찾지 못한 자원 3개가 원래 위치에 남았다. 이 중 2개는 개별 도시·표식과 6px 미만으로 가깝다. 지형과의 여백은 확보됐다. 대상 셀은 4960, 4967, 5022다. 다음 단계에서는 이런 밀집 구역의 도시 토큰까지 함께 배치하는 방식이 적합하다.
2. 축소 화면의 도시 그룹 배지가 여전히 많고 국가명 주변에 집중된다. 국가명 회피와 확대 단계에 따른 도시 표시 밀도 조절을 권장한다. 자원은 계속 지도에 개별 표시하는 방향을 유지한다.
3. 이동된 자원의 연결선과 기존 도시 그룹 연결선이 많은 구역은 시각적으로 복잡할 수 있다. 연결선 교차 감소와 짧은 연결선 우선 배치를 후속 개선으로 권장한다.

## 코드 검증

- Vitest: 31개 파일, 281개 테스트 통과 (`--maxWorkers=2`). 기본 병렬 실행에서는 기존 동적 import 테스트 2개가 5초 제한으로 시간 초과되어 낮은 병렬도로 재검증했다.
- TypeScript 타입 검사 통과.
- 변경한 코드의 Biome 검사 통과.
- Vite 프로덕션 빌드 통과. 기존 classic script 및 큰 청크 경고는 유지된다.
- 저장소 지침에 따라 자동 Playwright E2E 스위트는 실행하지 않았다. 실제 앱의 화면 검사 및 레이어 클릭 테스트를 수행했다.
- 파일 저장/내보내기 왕복 및 모든 지도 시드의 시각 검수는 이번 작업에서 별도로 수행하지 않았다.
