# 지저 구조 선택 구현 결과

후속: 사용자 제공 언더다크/아가르타 PDF를 검수하고 공동 세계 선택을 보완한 [현재 반영 기록](./subsurface-pdf-review-2026-10-28.md)이 있다. 아래 자료 접근 한계는 최초 구현 당시의 상태다.

## 변경

- 지형·구조에서 거대 터널형(언더다크 모티프)/공동 세계형(아가르타 모티프)을 선택하고 생성한다.
- 사용자 확인에 따라 공동 세계는 지상의 육지·산지를 내부 내해·저지대로, 바다·분지를 내부 육지·고지대로 반전한다. 터널형은 반전 저지대의 공동 확률과 통로 우선도를 높인다.
- 터널형은 3층, 공동 세계는 연속된 단일 화면으로 구분한다. 내부 평원·숲·산지·내해, 육로·내해 항로, 지상 출입구를 제공한다.
- 모드·반전 고도를 FPB에 보존한다. 기존 터널 파일은 그대로 읽고 수동/수정/초안 장소는 모드 변경 시에도 보존한다.
- PNG/SVG 최대 3000px와 지형 붓을 유지한다. 공동 세계에서 새 도시 배치/이동은 육지에 제한한다. 수중 지도 표본화는 공통 읽기 전용 도구로 이동했으며 기존 해양/호수 구분은 유지한다.

## 검증

- Vitest 6개 파일, 59개 테스트 통과: underground-modes, underground, underwater, seabed, 세계 공간 model/renderer.
- 정확한 육해 반전, 높이 관계, 터널의 반전 저지대 선호, 가중 경로 연결, 지상 출입구 좌표, 모드 변경의 편집 보존, 공동 세계 단층 표시/브러시 고도 갱신, FPB 동일 복원, 기존 터널 파일 호환성·손상 데이터 거부를 검증했다.
- 변경 TypeScript 15개 파일 Biome 검사와 프로덕션 빌드 통과. 기존 레거시 스크립트·번들 크기 경고를 유지한다.
- 실제 Chromium: 터널형 생성과 3층 전환, 선택 미리보기에서 저장 지도 미변경, 공동 세계 생성과 지상 표본의 정확한 반대 육해, 내부 경로, 편집한 도시 보존, PNG 3000px, FPB 재열기 시 모드/고도 동일, 숲 붓, 지상 입구에서 공동 세계로 이동, 390px 모바일 패널을 확인했다. 앱 예외는 관측되지 않았다.

## 자료 접근 한계

사용자 제공 Namu Wiki와 FM Korea 링크는 클라우드 접속 정책의 403으로 본문을 읽지 못했다. 구현은 사용자 설명과 확인한 반전 해석을 기준으로 했으며, 링크에만 있는 구체적인 설정을 읽고 재현했다고 주장하지 않는다. 기존 연구용 접근 초안을 보존하면서 두 도메인을 추가한 초안을 저장했다. 실제 접근은 클라우드 환경 설정 검토·저장·게시 후 적용된다.

[설계·사용법 및 링크 확인 상태](../02-design/underground-world-structures.md)에 상세 범위를 정리했다. 2D 지형 설계이며 실제 중력/기후/구형 내부 투영·중앙 광원이나 공식 TRPG 규칙 데이터 구현은 포함하지 않는다. Sites 배포와 실제 Drive 계정 업로드/불러오기는 수행하지 않았다.
