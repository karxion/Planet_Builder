# 해저 지형·수중 세력 구현 결과

## 반영 내용

- 현재 지상 해안선/높이에서 대륙붕·대륙사면·심해평원·해구·해령·산호초 군락과 생성 수심·등심선을 만든다.
- 멀포크·사후아긴·트리톤·바다 엘프·로카타·쿠오토아 기반 창작 세력에 중심도시·교역항과 서로 다른 역할 설명을 부여한다. 세력권은 물을 따라 확장하며, 생성 교역로는 물 셀을 경유한다.
- 지형/정치/결합 보기, 종족/주민 및 외교 관계 편집, 수동/편집/초안 장소 보존, 최대 3000px PNG/SVG 출력을 제공한다.
- 기존 FPB/복구/Drive 프로젝트 구조에 지형·수심·세력권·도시·경로·외교 관계를 저장한다. 지상/지저 데이터를 변경하지 않는다.

[설계와 사용법](../02-design/underwater-map-v1.md)에 격자 해상도와 재생성 범위를 정리했다. 수심은 판타지 세계의 절차적 생성값이며 실측 수심·판구조·전쟁/NPC 시뮬레이션이나 종족별 전투 규칙을 추가하지 않는다.

## 검증

- 관련 Vitest 4개 파일 47개 테스트 통과: `src/generators/underwater.test.ts`, `src/generators/underground.test.ts`, `src/services/world-spaces/model.test.ts`, `src/renderers/world-spaces.test.ts`.
- 재현성/기존 데이터 불변성, 수심 분류, 육지 소유 금지, 연결된 영향권과 물 위 교역로, 세력/관계 삭제 참조 정리, 경로/관계 손상 거부, 압축 FPB 동일 복원, 수정한 도시·종족·외교 관계 보존 및 동일 위치 도시 중복 방지를 확인했다.
- 변경 TypeScript 파일 Biome 검사와 프로덕션 빌드 통과. 기존 레거시 스크립트/번들 크기 경고를 유지한다. 저장소 전체 린트/전체 테스트의 기존 오류는 이번 범위에 포함하지 않았다.
- 실제 Chromium 수동 점검에서 해안 표본 기반 생성, 수중 세력 6종, 지형/정치/결합 전환, 주요 종족/외교 편집, 도시 이름 편집, PNG 3000px, FPB 저장·재열기 시 데이터 동일, 지상 payload에 해저 SVG 제외, 재생성 후 편집 보존, 390px 모바일 편집창을 확인했다. 앱 예외는 관측되지 않았다.
- 실제 Google Drive 계정 업로드/불러오기와 Sites 배포는 수행하지 않았다. 공통 프로젝트 코덱 저장을 검증했다.
