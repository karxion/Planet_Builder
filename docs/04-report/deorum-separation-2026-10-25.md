# Deorum 연동 분리

## 변경

- 인물 조우 생성기에서 외부 iframe을 만들지 않는다.
- 조우 표식 클릭은 현재 국가 안에서 가까운 유효 정착지의 기존 NPC 상세로 연결한다. NPC를 새로 만들거나 이동시키지 않으며 같은 데이터에서 선택 결과를 유지한다.
- NPC가 없거나 인물 조우 유형이 아니면 기존 표식 편집 경로를 보존한다. Shift+클릭은 내부 NPC 열기를 건너뛴다. 기존 던전 클릭 경로는 유지한다.
- 레거시 정보 팝업의 Deorum 홍보 링크만 제거한다. 다른 외부 서비스 및 Azgaar 원작 출처·MIT 고지는 유지한다.
- 기존 노트는 inert HTML template에서 정확한 Deorum 호스트 URL을 판별해 해당 iframe·외부 미디어를 제거하고 링크는 본문을 유지한 채 해제한다. 메모 내용·이름·ID를 교체하지 않는다.
- 지도 로드, 초기화/재생성 및 노트 표시·편집·가져오기 경로에 적용한다. 원본 디스크 파일을 자동으로 다시 쓰지는 않는다.
- 이 필터는 Deorum 통합을 분리하기 위한 제한적 정책이다. 범용 HTML 정화기나 네트워크 차단기를 대체하지 않는다. 기존 최신 작업 소스의 DOMPurify 정화도 유지한다.
- 레거시 JS 쿼리 버전을 갱신해 이전 캐시를 구분한다. 의존성·프로젝트 스키마 변경 없음.

## 검증

- 최신 작업: 69개 파일, 810개 단위 테스트 통과. 새 검사 15개 포함.
- 새 검사: 프레임 제거, 대소문자·상대 프로토콜 URL, 정확한 호스트 경계, 사용자 설명·독립 링크·메타데이터 보존, 반복 적용, 외부 리소스 없는 조우 생성, 국가 경계·유효 정착지 필터, 입력 순서 안정성, 내부 클릭·Shift 편집·폴백.
- 공개용 기존 소스 회귀 291개 통과. 공개 클릭 핸들러 파일을 대상으로 한 검사 2개 통과. 공개 회귀는 기존 외부 호환 테스트 설정을 사용한다.
- 최신 작업 및 공개 소스 타입 검사, 최신 작업 Biome 검사·프로덕션 빌드 통과.
- 실제 브라우저 네트워크 요청과 시각 검증은 미완료. 자동 Playwright 미실행.
- GitHub 푸시 미실행. 공개용 소스에는 이번 분리 관련 변경만 반영한다.
