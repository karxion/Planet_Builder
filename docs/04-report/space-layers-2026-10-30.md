# 해저·지저 레이어 메뉴와 지형 표시

## 변경

기존 메뉴는 지상 SVG 그룹만 제어하고, 해저/지저 전체 오버레이가 그 위를 덮고 있었다. 기존 레이어 메뉴의 클릭·키보드·프리셋·끌어서 순서 변경을 현재 세계의 별도 그룹으로 연결했다. 지상 데이터나 좌표를 수정하지 않는다.

- 고도 등고선, 생물군계/지형 색, 호수, 국가 세력권 색, 영지 영역, 국경, 셀, 격자, 도로/교역로, 지형 아이콘, 자원, 도시 아이콘, 출입구 표식, 이름표를 분리한다. 영역 채움과 경계선, 도시 아이콘과 이름표를 독립적으로 표시한다.
- 기본은 중립 지형 바탕 위에 실제 세력/영역 색과 지형 아이콘을 표시한다. 지형별 색과 등고선은 별도 선택한다. 해저 지도 보기 선택기도 같은 설정을 변경한다.
- 공동형은 기존 지상 relief artwork의 산·나무·초원 아이콘을 실제 산지/숲/평원 셀에 배치한다. 내해에 동굴·석교 장식을 무작위로 깔지 않는다. 지저 자원은 별도 자원 레이어로 유지한다. 터널형은 전용 동굴/균류/용암 에셋을 유지하고, 해저는 산호·켈프·열수 분출공과 해산/해령 표기를 사용한다.
- 기존 surface SVG artwork를 새로 그린 대체 아이콘으로 바꾸지 않고 복사하며, 필요한 정의를 공간 SVG 안에도 포함해 독립 내보내기에 사용한다.
- 해저·지저의 지형 지도 프리셋은 지형 색·등고선·지형 아이콘·도시·이름표·경로를 함께 표시한다. 지상 프리셋은 변경하지 않는다.

## 저장과 범위

`worldSpaces.layers`는 선택 필드이며 공간별 visibility/order를 FPB와 기존 복구 경로에 저장한다. 스키마 1과 구형 파일 호환을 유지하고 잘못된 키·비불리언 값·중복 순서는 검증에서 거부한다. 구형 지도에도 표시 개선이 적용되므로 지형을 재생성할 필요가 없다. 수동 장소, 도시 좌표, NPC/아이템, GM 기록과 초안을 변경하지 않는다.

해저·지저 메뉴를 사용할 때 지상 메뉴 클래스·순서·프리셋을 보관하고 지상 복귀 시 복원한다. 축척 막대/가장자리 음영은 공통 화면 옵션이다. 공간 레이어 설정은 프로젝트에 저장하며, 지상 사용자 프리셋 추가/삭제 버튼은 공간 화면에서 비활성화한다.

강·기온·군사·시장·문장·문화/종교 등 이 공간의 별도 표시 데이터가 없는 레이어는 흐리게 표시하고 지상 명령 실행을 막는다. 지상 강/문화/기온을 공동세계의 실제 값인 것처럼 복사하지 않는다. 이번 변경은 새 강·기후·군사 시뮬레이션 생성이 아니다. 지형/자원 아이콘은 현재의 시드 기반 표시용 배치이며 새 장소 기록이나 영토를 만들지 않는다.

## 검증

- 전체 단위 테스트 122파일 1,257개 통과 (`--maxWorkers=2`, 프로세스에만 긴 TEMP/TMP 경로 적용).
- 후속 프리셋 보완 후 관련 6파일 35개, 어두운 공동형 배경 보존 후 렌더러 2파일 7개 재검사 통과.
- 최종 TypeScript 검사·Vite 빌드 통과. 기존 레거시 스크립트/CSS 및 청크 크기 경고는 남아 있다. Playwright E2E는 실행하지 않았다.
- 독립 4194 localhost 브라우저: 공동형 147개 지형 아이콘, 실제 레이어 메뉴 표시/숨김, 해저 지형 아이콘/세력 영역, 도시·이름표·영역·지형 개별 숨김, 보완된 지형 프리셋, 공간별 독립 설정 및 지상 복귀 UI 복원 확인. 새로고침 후 기존 복구에서 서로 다른 해저/지저 레이어 상태가 유지되는 것도 확인했다. 브라우저 콘솔 오류 없음.
- 단위 검사로 레이어 순서 저장, 지상 핸들러 실행 방지, 미지원 버튼 차단, 압축 FPB 왕복, 지형 아이콘과 실제 셀의 일치, artwork 정의 포함을 확인했다. 실제 OS 파일 선택으로 FPB 재열기나 PNG 이미지 저장은 이번 브라우저 검사에서 반복하지 않았다.
- 증빙: 작업 폴더 `.codex/space-layers/hollow-layers.jpg`, `underwater-layers.jpg`.
- CSS/레거시 레이어/핫키 캐시 키: `space-layers-1`.
