# NPC 초상화 수동 연결

## 범위

- NPC 상세의 `ChatGPT에서 생성`은 현재 폼의 이름·역할·직업·지위·외형으로 요청문을 작성한다. 비밀·목표·성격·GM 메모와 이미지 데이터는 요청문에서 제외한다.
- 사용자가 요청문을 복사하고 별도 ChatGPT 탭에서 생성한 뒤, 결과를 직접 `이미지 등록`으로 첨부한다. 로그인·구독 사용량 연결·이미지 API·자동 결과 회수는 구현하지 않는다. 외부 링크에 NPC 정보를 쿼리로 전달하지 않는다.
- PNG/JPEG/WebP, 최대 10 MiB·40MP 입력. Canvas에서 긴 변 768px 이하 JPEG로 재인코딩하여 메타데이터를 제거한다. 저장된 데이터 URL은 700,000자 이하로 제한하고 외부 URL과 SVG는 거부한다.
- `WorldNpc.portrait?: string`은 기존 프로젝트와 역호환 가능한 선택 필드다. `.fpb` 캠페인에 포함하며, 등록·교체·삭제 시 변경 이벤트를 발생시킨다. 이미지를 첨부한 NPC는 수동 편집으로 취급해 재생성에서 보존한다.
- 이미지 변경은 별도로 적용하되 미적용 텍스트 초안은 보존한다. 텍스트 저장 시 이미지가 되돌아가지 않도록 프리뷰와 저장 NPC를 함께 갱신한다. 삭제된 폼 또는 교체된 캠페인에는 지연된 업로드를 적용하지 않는다.

## 검증

- 최신 작업: 72개 파일·823개 테스트 통과. 타입 검사·프로덕션 빌드 통과.
- 공개 소스: 33개 파일·295개 회귀 테스트 통과. 별도 호환 테스트 환경에서 공개 초상화 편집기·이미지 처리·실제 Campaign 연결 및 기존 티어 편집 15개 테스트 통과. 공개 소스 타입 검사 통과.
- 압축 `.fpb` 왕복, 잘못된 이미지 URL 거부, 비밀·GM 메모 제외, 클립보드 거부, 디코딩 실패, 지연 업로드, 메모 보존 및 재로딩을 검사했다.
- 공개 사이트의 실제 1280×720 화면에서 NPC 상세 진입·생성 요청문 펼치기·요청문 복사 후 `복사됨` 표시와 하단 버튼 배치를 확인했다. 스크린샷: `assets/npc-portrait/manual-handoff-desktop.png`.
- 기존 저장 지도를 변경하지 않기 위해 브라우저에서 실제 이미지 첨부·삭제는 하지 않았다. 해당 경로는 단위·통합 테스트로 검증했다. 모바일 실제 기기와 ChatGPT에서의 실제 이미지 생성은 미검증이다.

## 제한

- ChatGPT에서의 실제 이미지 생성은 사용자 수동 작업이며 해당 서비스의 계정·정책·사용 한도를 따른다.
- 프로젝트를 저장하지 않거나 브라우저 저장 공간을 삭제하면 다른 로컬 데이터와 함께 손실될 수 있다. 다른 기기로 이동할 때 `.fpb` 파일 또는 설정된 클라우드 저장을 사용한다.
- 이미지는 프로젝트 크기를 증가시킨다. 전체 프로젝트의 기존 저장 제한은 그대로 적용된다.
