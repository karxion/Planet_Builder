# 마을·도시 편집창 텍스트 잘림 수정

편집창 폭이 제한돼도 기존 `.dialog > div { width: max-content }`가 본문과 하단 도구의 원래 폭을 유지했다. 상단 문장과 고정 폭 입력 줄도 줄어들지 않아 도시 기록·NPC 이름이 가로 스크롤 밖으로 밀렸다.

- 마을 편집창만 560px 기본 폭과 기존 화면 최대 폭을 함께 사용한다.
- 본문·하단은 창 폭에 맞추고, 상단 문장/입력은 줄어들 수 있는 그리드와 줄바꿈을 사용한다. 600px 이하에서는 문장 위·입력 아래로 배치한다.
- 영토·국가 이름, NPC 이름·직업 설명은 긴 문자열을 줄바꿈한다. 하단 도구도 줄바꿈한다.
- 이 편집창의 제목과 닫기 버튼을 flex로 정렬하고 번역된 닫기 글자에 공간을 확보한다.
- CSS 캐시 키 `settlement-tools.css?v=burg-reflow-2`. 데이터·저장 형식·생성 규칙은 변경하지 않는다.

검증: 관련 기존 테스트 2파일 21개 통과, 타입 검사·프로덕션 빌드 통과. 독립 localhost4192에서 실제 마을 편집창을 열어 1280/390/320px의 scrollWidth=clientWidth, scrollLeft=0을 확인했다. 320px 영어도 동일하게 넘침이 없었으며 도시 기록·NPC 이름·닫기 버튼이 보인다. Playwright E2E는 실행하지 않았다. 화면·빌드 로그는 작업 폴더 `.codex/burg-text-clipping/`에 보존한다.
