# 행정 분류 및 NPC 연동 구현 보고서

검증일: 2026-10-11

## 적용 범위

- 세계 분류를 마을 → 영지 → 지역 → 국가로 통일했다. 원본 FMG의 Burg는 규모와 관계없이 마을 단위로 취급한다.
- 영지는 기존 Province를 활용한다. 같은 국가의 인접 영지를 최대 5개씩 묶어 지역을 구성하며, 소속 영지가 없는 마을에는 직할령을 부여한다.
- 종교·문화 엔티티, 셀별 배정, 임의 Zones, 성지 표식·연결 메모, 관련 경제 배율·군사 제한을 제거했다. 생성·가져오기·저장 경로 모두에 적용한다.
- FMG 엔진이 참조하는 호환 슬롯은 빈 배열 또는 0으로 유지한다. 기존 문화·종교 데이터의 백업이나 숨겨진 복사본은 저장하지 않는다. 관련 레거시 코드 전체를 물리적으로 삭제하는 엔진 재작성은 하지 않았다.
- 세계·NPC 패널에서 국가·지역·영지·마을별 필터, 이름·역할 검색, 페이지 이동, 지도 위치 이동, 지도 구획 전환을 제공한다.

## NPC 규칙

규칙 출처: [공식 SRD 5.2.1](https://www.dndbeyond.com/srd), [PDF](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf).

- 2024 개정 5e 계열의 공개 SRD NPC 블록을 사용한다. 일반인 p.275, 경비병 p.296, 귀족 p.312, 정찰병 p.322.
- 초기에는 마을마다 대표/영주, 경비병, 여관 주인/항구 상인, 길잡이 4명을 생성한다.
- 시드·마을 ID·재생성 회차를 사용하는 독립 Alea 난수로 생성한다. 전역 지도 난수 상태를 변경하지 않는다.
- 능력치, AC, HP, CR, 기술, 장비, 행동, 반응과 원문 링크를 표시한다. 능력치 유형 변경은 저장 전에도 즉시 미리보기에 반영된다.
- 이름·역할·외형·성격·목표·비밀·GM 메모를 편집할 수 있다. 범위 재생성 시 직접 수정한 NPC는 남기고 새 자동 NPC 4명을 추가하므로 마을 인구 목록은 4명을 넘을 수 있다.
- 플레이어 캐릭터 직업·종족·레벨 빌더나 공식 NPC 생성표의 전체 구현은 아니다. 서사 속성은 앱의 창작 규칙이며, 일반인의 선택 숙련은 조사로 고정했다.
- CC BY 4.0 필수 고지를 앱의 라이선스 페이지와 NPC JSON 출력에 포함했다.

## 저장 및 화면 보완

- FPB schemaVersion 1의 선택 필드 `campaign`에 행정 단위·NPC·수정 여부·재생성 회차·지도 구획 상태를 저장한다. 구형 FPB에는 자동으로 새 캠페인을 부여한다.
- 불러오는 캠페인의 엔티티 형식, 중복 ID, 부모 단계와 국가 일치, 규칙 유형을 검사한다.
- NPC 변경은 IndexedDB 자동 저장에 연결했다. 원본 마을이 삭제된 NPC는 메모 손실을 막기 위해 전체 목록에 소속 없음으로 남는다.
- 지역명에서 중복된 '영지 지역' 접미사를 정리하고, 겹치는 행정 라벨을 생략한다.
- 3D 캔버스가 지도 원본 크기를 따라 하단 공백이 생기거나 창 크기 변경 시 화면 밖으로 밀리는 문제를 수정했다. 실제 뷰포트 크기와 카메라 비율을 동기화하며 종료 시 리사이즈 리스너를 해제한다.
- 3D 상태에서 2D 프로젝트를 열 때 보기 모드도 함께 전환되도록 보완했다.

## 남은 범위

- 개인 클라우드 실서버 인증·RLS·파일 권한 검증은 환경 정보가 없어 이번 작업에서 실행하지 않았다. NPC는 기존 FPB 업로드 경로를 통해 함께 저장된다.
- 전체 레거시 E2E 스위트는 실행하지 않았다. 삭제된 Zones 등 옛 제품 정책을 전제로 한 테스트는 새 정책에 맞게 갱신해야 한다.
- 기존 분석 보고서의 나머지 이슈를 모두 해결한 것은 아니다. 전체 생성 결정성, 손상된 FPB 전체 필드 검증, 클라우드 충돌 처리 등은 별도 검증 대상이다.
- 부분 지도는 기존 지리 범위에 따라 구체 일부에 투영되며 나머지는 구름 배경으로 표시된다. 이번 작업은 진짜 구면 지형 생성기를 추가하지 않는다.
- Windows의 `D&D Map` 경로에서 npm 명령 래퍼가 `&`를 잘못 처리할 수 있어 TypeScript와 Vite의 Node 진입점을 직접 실행했다.

## 구현 파일

- `src/generators/campaign-generator.ts`: 순수 행정 체계·NPC 생성
- `src/generators/administration-policy.ts`: 폐기된 데이터 제거
- `src/controllers/campaign-world.ts`: 필터·NPC 편집·지도 연동
- `src/renderers/administration-renderer.ts`: 영지·지역 경계와 라벨
- `src/data/npc-stat-blocks.ts`, `src/data/campaign-validation.ts`: 공개 규칙·불러오기 검증
- `tests/e2e/planet-campaign.spec.ts`: 전용 브라우저 회귀 테스트
