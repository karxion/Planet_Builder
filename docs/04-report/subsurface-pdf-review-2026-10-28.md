2026-10-28 KST. 사용자 제공 PDF 5개를 로컬에서 읽어 기존 구현과 대조했다. 이전 403 기록은 당시의 접속 증거로 유지하며, **아래 5개 자료의 검수에는 더 이상 웹 접속이 필요하지 않다**. PDF 원본은 작업 공간에 보관하고 저장소에는 출처·파일 SHA-256·검토한 페이지와 자체 작성 요약을 남긴다.

## 확인한 내용과 구현 변경

### 해저 주변부와 협곡

2011년 자료의 초록/하이라이트는 활동형 주변부에도 협곡이 많으며, 수동형과 비교해 **짧고 가파르며 가지침이 많고 간격이 좁은 경향**을 설명한다(PDF 1쪽). 서론은 사면에 머리를 둔 협곡과 대륙붕을 절개하는 협곡을 구분하며, 협곡 말단의 퇴적 선상지도 설명한다(2–4쪽).

기존 코드는 협곡 후보를 `!active`로 제한했다. 이를 수정해 **활동형과 수동형 양쪽에서 협곡을 생성**한다. 활동형은 짧은 주축·좁은 머리 간격·더 많은 합류 가지를, 수동형은 상대적으로 긴 주축·넓은 간격을 사용한다. 실제 격자에 연결된 가지를 파고 주변부 종류·주축 셀 수·가지 수를 메타데이터로 저장한다. 선상지는 양쪽에 가능하며 수동형의 합성 로브를 더 넓게 만든다. 해구가 협곡 머리/선상지를 덮어쓰지 않도록 한다.

2014년 초록은 수동형의 평균 대륙붕 폭 88km 대 활동형 31km, 사면 폭은 각각 46km와 36km라는 차이를 제시하고 대륙대 면적도 수동형에서 훨씬 크다고 보고한다(PDF 1쪽). 이를 **수동형 대륙붕은 더 넓게, 활동형 사면은 더 좁고 급하게** 생성하는 경향에 반영했다. 논문의 지구 평균 km를 판타지 격자의 실제 축척으로 대입하지 않았다. 활동형/수동형 구분은 여전히 공간적 대용 규칙이며 판 운동 계산 결과가 아니다.

협곡 수 5849개나 활동형의 15% 차이 등 관측 통계를 이 생성기의 개수 규칙으로 복제하지 않는다. 하천 연계 협곡 여부는 실제 하천 연결을 조사하지 않아 자동 판정하지 않는다. 남극/북극 통계와 빙하 지형도 해저 생성기의 위도·빙하 입력이 없으므로 이번에 임의 구현하지 않는다.

### 해령·해산과 지형 분류

2014년 초록은 느린 확장에서 큰 열곡 구간, 빠른 확장에서 작은 열곡 구간의 연관성을 설명한다(PDF 1쪽). 합성 해령에 느린/빠른 확장 모티프를 나눠 **축부 열곡의 폭과 함몰량**을 달리한다. 확장 속도 수치나 실제 지질사는 추정하지 않는다.

NOAA는 주변 해저 대비 최소 1000m의 기복, 흔한 화산성 기원과 원뿔형/평탄 정상 등 형태, 서식처 역할을 설명한다(PDF 1–2쪽). 기존 해산/평정해산의 높이·정상 수심 분리 및 1000m 이상 기복 규칙이 이에 맞는 것을 확인했다. 검수 기록의 NOAA 출처는 PDF에 표시된 현재 주소인 `https://oceanexplorer.noaa.gov/ocean-fact/seamounts/`로 정리하고 수집 스크립트도 해당 주소로 바꿨다.

2014년 소개 페이지는 기저 지형층·기복 분류층·개별 지형층의 계층을 설명한다(PDF 2–3쪽). 현재 앱은 16개 주 표시 코드와 개별 지형 메타데이터로 단순화한 모델을 유지한다. 표/부록이 없는 상태에서 29개 분류 전체를 정의·구현했다고 하지 않는다. IHO 용어 표준 자체, USGS 자료, 별도 NOAA 협곡 페이지는 이번 첨부에 없어 검수 완료로 바꾸지 않는다.

### 터널형과 공동 세계형

언더다크 자료는 대륙 규모의 공동/통로망, 자연광이 거의 없는 환경, 층별 장소와 호수·교역·출입구 사례를 설명한다(PDF 2–10쪽). 기존 **암반 사이 3층 공동과 좁은 통로** 구조 및 층간 이동이 이 모티프에 맞는 것을 확인하고 UI 설명을 보완했다. 본문의 고유 도시·역사·종족 성향·전투 능력을 앱 기본 세계에 복제하지 않았다. 자동 깊이 300/1500/4000m는 이 앱의 기본값이며 원전의 층별 경계가 아니다. 더 깊은 수동 장소는 기존 깊이 편집으로 다룬다.

아가르타 글은 농작물을 키우는 특이한 광원(6쪽), 빛나는 대기가 있는 내부 구체(9쪽), 극지의 출입구를 상정한 이야기/그림(10–11쪽)을 제시한다. 공동 세계형에 다음 선택을 추가했다.

- **내부 광원:** 특이광원·발광대기 / 어두운 내부 세계. 선택은 저장되고 실제 지형 색조에 반영된다. 중앙 태양을 필수 설정으로 고정하지 않는다.
- **출입구:** 지상 도시 주변 / 극지권 관문. 극지 관문은 현재 지도 위도 범위에 포함된 북위 85°·남위 85°에만 생성한다. 85°와 지도 중앙 경도는 편집 가능한 관문을 배치하기 위한 앱의 설계값이다. 지역 지도 위쪽/아래쪽을 무조건 극지로 간주하지 않는다.
- 광원·출입구 선택은 생성 버튼을 눌러 적용한다. 도시 주변 방식이 기본값이다. 극지 방식은 해당 위도가 없는 지도에서 비활성화하고 생성기에서도 거부한다.

이는 판타지 지형/표현 설정이다. 구형 내부 투영·중앙 광원 천체·다중 동심 구체·중력·일조·농업 생산량을 계산하는 물리 모델을 추가한 것은 아니다. 지상의 육해를 뒤집는 규칙은 이전에 사용자가 승인한 별도 설계를 유지한다.

## 에셋 목록 반영

[64종 검토안](../02-design/subsurface-object-assets.catalog.md)에 자료별 근거 범위와 배치 조건을 추가했다. 협곡 가장자리와 해령 부품은 지형의 연결·분기 표현을 보조하고, 산호/해면은 해산·협곡의 서식처 표현에도 활용할 수 있게 한다. 얕은 산호초 지형과 심해 산호 서식처는 구분한다. 관문은 바닥에 고정된 프레임을 유지하며 극지 표기만으로 거대 구멍 이미지를 강제하지 않는다.

광물 종류별 분포·생산량은 이번 PDF에서 검증된 내용이 아니다. 목록의 광물/환상 자원을 논문으로 검증한 자원 경제로 보고하지 않는다. **종수 64/우선 24는 유지하며 이미지 생성 범위는 기존 목록 검토 단계에 있다.**

## 저장 호환성과 사용법

새 해저는 `geologyVersion: 3`, 기존 지형 코드 0–15를 유지한다. 버전 2와 구버전 파일은 저장된 데이터를 그대로 읽는다. **수중 지도 → 해저·세력 다시 생성**을 눌러 보완 규칙을 적용한다. 수동/수정한 도시·세력·외교 관계의 보존 동작은 유지한다.

지저의 새 선택은 `UndergroundMap.illumination`, `entranceStyle` 선택 필드다. 기존 공동 세계 파일은 기존 밝은 표현으로 읽고 재생성하지 않는다. 모드/수동 장소/층별 고도/경로와 함께 FPB에 보존한다. **지저 지도 → 지형·구조 → 공동 세계형 → 광원·출입구 선택 → 생성**으로 적용한다. PNG 최대 3000px는 유지한다.

## 검증

- 생성기/세계 공간/렌더러 Vitest 6개 파일 **62개 테스트 통과**. 양쪽 주변부 협곡·실제 가지 연결·활동형의 짧은 주축 경향·기존 저장 데이터 보존·잘못된 메타데이터 거부·극지 좌표/지역 지도 제한·FPB 선택값 복원·광원 표시를 확인했다.
- TypeScript 검사와 프로덕션 빌드 통과. 기존 레거시 스크립트 및 번들 크기 경고가 있다.
- 변경 TypeScript 파일 15개 Biome 검사 및 diff 공백 검사 통과. 출처 JSON 파싱/파일 해시/문서 링크와 에셋 목록 64종·우선 24종을 확인했다.
- 실제 Chromium에서 해저 생성/보기 전환/도시·세력·외교 편집/재생성 편집 보존, 터널 3층·반전 공동 세계·내부 경로·지형 붓·공간 이동, 최대 3000px PNG, FPB 동일 복원을 확인했다.
- 새 설정은 터널형에서 숨김, 지역 지도에서 극지 선택 비활성화, 양 극지권 포함 지도에서 정확한 85° 관문 생성, 광원 미리보기/명시적 재생성 구분, 두 선택의 FPB 저장·복원, 390px 모바일 표시를 별도로 확인했다. 앱 예외는 관측되지 않았다.
- 전체 E2E 테스트 모음은 실행하지 않았으며, 위 확인은 별도의 브라우저 점검 스크립트로 수행했다. 공개 사이트 배포와 실제 Drive 계정 업로드/불러오기는 이번 검증 범위에 포함하지 않았다.
