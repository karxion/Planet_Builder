# NPC 및 아이템 데이터 출력

## 구현

- 세계·NPC와 아이템 창의 데이터 출력 버튼에서 전체/검색 결과/선택 항목을 선택한다. 검색 결과는 현재 페이지만이 아닌 필터 전체다.
- JSON: 원본 데이터 및 관련 소속/소유주, NPC 티어 규칙과 SRD 기본 참고 프로필, 아이템 판본·출처를 보존한다. 프로젝트 가져오기 파일 형식은 아니며 전체 지도 복구에는 `.fpb`를 사용한다.
- CSV: UTF-8 BOM, CRLF, 모든 필드 인용, 수식 실행 방어를 적용한다. 이미지는 제외한다.
- 인쇄: 읽기 전용 카드 미리보기, 등록 이미지 옵션, 브라우저의 인쇄/PDF 저장을 제공한다.
- 비밀·GM 메모 기본 제외. 미적용 편집 초안은 출력하지 않고 안내한다. 사용자 작성 이름/설명은 언어 선택으로 변경하지 않는다.
- 순수 데이터 구성기와 출력 UI를 분리하고 지연 로드한다. 신규 의존성과 저장 스키마 변경은 없다.

## 검증

- 주 작업본: 79개 파일, 895개 테스트 통과. 타입 검사 및 Vite 빌드 통과.
- 공개 작업본: 35개 파일, 312개 회귀 테스트와 73개 UI 호환 테스트 통과. 타입 검사 및 빌드 통과.
- 실제 브라우저에서 NPC 선택 항목 JSON의 레벨 6/T2와 비밀·메모 미포함 확인.
- NPC 검색 결과 CSV 773행 및 UTF-8 BOM 확인.
- 아이템 전체 JSON 41개, 국가 소유주·던전 보상 링크·2014/2024 출처·메모 미포함 확인.
- 한국어 출력 창과 선택 NPC 인쇄 미리보기의 실제 화면 확인.
- 개발 서버 갱신 이후 브라우저 자동화가 일시 중단됐으나 연결 복구 후 공개 버전 12에서 한국어 NPC 출력 창과 한국어/영어 아이템 출력 미리보기를 확인했다. 영문 헤더는 양쪽 작업본 단위 테스트도 통과했다. 모바일 실기기는 미검증이다.
- `window.print()` 호출·취소·페이지 클래스 복원은 단위 테스트로 확인. 실제 프린터 출력/PDF 저장은 미검증.

## 범위

- 이 출력물은 데이터 전달/열람용이다. NPC·아이템 출력 JSON 재가져오기 기능과 VTT 전용 형식은 포함하지 않는다.
