# 던전 자동배치·배지 연결·상단 메뉴 수정

사용자 요청의 적용 범위는 세 가지 오류 수정이며 메뉴 체계 개편은 Figma 검토 시안까지만 제작한다.

## 변경

- 실제 지도 셀 인덱스인 Uint16Array/Uint32Array를 일반 배열로 복사한 다음 좌표 객체로 변환한다. TypedArray.map이 객체를 숫자로 강제 변환하여 배치 후보를 잃던 문제를 수정했다. 원래 셀 배열은 변경하지 않는다.
- 장소 배지 목록에 던전 내부 지도 진입 버튼을 추가했다. 상세·편집 버튼은 별도로 유지한다. 동굴 일반 마커는 던전으로 취급하지 않으며 인물 마커는 기존 NPC 진입 경로를 사용한다.
- 데스크톱 상단은 브랜드·보기 전환·작업 버튼·언어 선택기가 각각 폭을 확보하는 flex 배치로 바꿨다. 작업 버튼만 가로 스크롤하며 언어 선택기 영역을 침범하지 않는다. 중간 화면에서는 보기 전환을 하단으로 이동한다. 영어 제목과 버전은 한 줄을 유지한다. 모바일의 기존 2행 배치는 유지한다.
- CSS 캐시 키: `toolbar-isolation-1`.

## 검증

- 타입 검사 및 프로덕션 빌드 통과.
- 전체 Vitest: 115파일, 1,208개 통과 (`--maxWorkers=2`). Windows TEMP/TMP는 해당 검사 프로세스에서만 긴 절대 경로로 정규화했다. 기본 병렬 검사에서는 두 생성기 테스트가 5초 시간 제한을 넘었으며 해당 30개를 단독 재실행해 통과한 후 제한된 병렬도로 전체 재검사를 통과했다.
- 독립 localhost에서 정착지 간격 8/거점 간격 12로 던전 41개 생성, 복구 후 목록 유지 확인. 기본 간격 36에서는 밀집된 테스트 세계에 빈 공간이 없어 0개였으며 공간 부족 안내를 확인했다. 지정한 간격을 임의로 완화하지 않는다.
- 실제 지도 배지 → 장소 목록 → 던전 내부 지도(15방), 별도 상세·편집 버튼 확인.
- 1280px 한국어/영어에서 클라우드 및 언어 선택기 클릭 영역 확인. 1190·1440·1920px 및 390px에서도 실제 클라우드 대화상자 열기/닫기 확인. 넓이가 부족할 때 버튼은 스크롤로 접근하며 언어 선택기와 겹치지 않는다.
- Playwright E2E는 실행하지 않았다. CUA를 통한 수동 UI 검증이며 실제 Google Drive 계정 연결은 수행하지 않았다.

## 메뉴 시안

[Figma 메뉴 개편안](https://www.figma.com/design/ieZzhJvWLAXHAU6ia3zTWU?node-id=24-406)

기존 파일의 `02 · 메뉴 체계 개편안` 페이지, `메뉴 개편안 / Desktop 1280 + Mobile 390` 프레임이다. 지도 보기·세계 콘텐츠·편집·파일의 네 그룹, 빠른 저장, 별도 언어 선택 영역, 데스크톱 1280과 모바일 390을 포함한다. 앱에는 이 메뉴 체계를 적용하지 않았다.

Figma MCP Starter 호출 한도로 데스크톱 앱에서 SVG를 가져왔다. 텍스트 88개와 벡터를 편집할 수 있으며 누락 글꼴은 Noto Sans KR로 교체했다. 자동 레이아웃·컴포넌트 라이브러리·클릭 프로토타입으로 제작된 것은 아니다. 로컬 SVG 원본과 UI 검증 스크린샷은 작업 폴더 `.codex/menu-redesign/`에 보존한다. 기존 디자인 화면은 수정하지 않았다.
