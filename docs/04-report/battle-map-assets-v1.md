# 이미지 모듈 조립과 전투지도 크기 구현 결과

## 결과

이미지 생성 도구로 건물·성채 건물·성벽 구간·성문·우물·축사·포장 타일·나무의 PNG 모듈 8개를 생성했다. 각 파일에는 조감도/탑다운 두 시점이 담겨 있어 총 16개 시점 표현을 사용한다. 완성된 마을 그림을 한 장 배경으로 넣는 방식이 아닌, 개별 모듈 배치 방식이다. 원본 PNG를 변경하지 않고 복사했으며 파일별 치수와 SHA-256을 저장했다. 초기 SVG 프로토타입 에셋은 최종 배포물에서 제거했다.

도시의 기존 시드 배치에 건물·성채·축사를 놓고, 성벽 구간·성문·우물·포장·나무를 조립한다. 조감도와 전투지도는 같은 배치에서 각각의 시점을 표시한다. 던전 바닥도 생성된 포장 타일을 사용한다. SVG 출력은 래스터 PNG를 내부 포함하며 PNG 출력은 이를 합성한다.

크기는 소형 25×14, 중형 48×27, 대형 72×41을 기본으로 한다. 가로·세로·비율·한 칸 이미지 해상도 직접 입력, 72칸을 넘는 전장, 세로형 지도도 지원한다. 정사각형 격자는 유지한다. 이동 턴은 5ft/칸·30ft 이동속도·양 끝 칸 중심 기준이며 실제 장애물 경로 계산은 하지 않는다. 도시 구역과 던전 방 중심의 전투지도 모두 지원한다. 전체 던전의 방·통로·조우를 크기 변경 때문에 다시 생성하지 않는다.

## 검증

- 관련 단위 테스트 88개 통과: 프리셋/이동 턴, 자유 비율, 큰 지도/출력 예산 검증, 원본 PNG 8개의 치수·SHA-256, 뷰포트별 시점, 독립 SVG 내장 및 실패 처리, 도시/던전 렌더러·저장/컨트롤러.
- 전체 실행: 1066개 중 1065개 통과. 기존 `project-codec.test.ts / accepts the inclusive byte limit` 1개 실패는 이전 작업에서 변경 전 코드에서도 재현된 문제다.
- 타입 검사·프로덕션 빌드 통과.
- 실제 Chromium에서 소형/중형/대형 전환, 96×54칸/48px 설정, 4608×2592 SVG·PNG 실제 파일의 치수, FPB 다운로드·다시 열어 설정 복원 확인.
- 던전 방 전투지도 48×27칸, 플레이어 보기의 비공개 조우 제거, 3072×1728 SVG·PNG 실제 출력 확인. 390px 모바일 화면에서 창 가로 넘침 없음 확인.
- Google Drive 인증/서버 통신은 재검증하지 않았다. 저장 설정은 기존 FPB 데이터에 포함되어 동일 코덱을 사용한다.
