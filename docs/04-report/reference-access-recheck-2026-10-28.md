# 해저·지저 참고 자료 재접속 및 검수 상태

확인일: **2026-10-28 19:57~19:58 KST (Asia/Seoul)**. 기존 미열람 자료를 다시 요청했으나 **8개 고유 주소 모두 본문 수신에 실패**했다. 이번 작업은 재접속 결과와 기존 구현의 검수 범위를 점검한 것이며, 원문 내용 검수 완료를 의미하지 않는다.

기존 수집 스크립트로 기관/논문 검색 6건을 재요청했다. 별도 헤더 확인 요청에서는 NOAA 해산과 두 지저 참고 링크가 모두 `CONNECT tunnel failed, response 403`으로 끝났다. 이 3건의 403은 원문 사이트가 보낸 응답으로 해석할 수 없다. 원문 HTTP 응답 코드는 없으며 curl의 `http_code`는 `000`, 종료 코드는 56이다.

[이번 재시도 증거](./reference-access-recheck-2026-10-28.json)와 [이전 해저 수집 기록](./seabed-source-attempt.json)을 구분해 보관한다. TLS 검증과 상속된 환경 프록시를 유지했으며 우회 접속은 하지 않았다. 다운로드에 성공한 본문이나 논문 초록은 없다.

## 환경 설정 확인

- 현재 환경은 연결되어 있으며, 네트워크 관측은 `observations_current: true`, 정책 상태는 `enforced`다.
- **적용된 사용자 지정 허용 호스트는 빈 목록**이다. 현재 유효 목록에도 이번 참고 자료 도메인은 없다.
- 저장된 설정 초안 revision 3에는 `api.crossref.org`, `iho.int`, `m.fmkorea.com`, `namu.wiki`, `oceanexplorer.noaa.gov`, `oceanservice.noaa.gov`, `pubs.usgs.gov`, `www.frontiersin.org` 8개가 있다. 이 초안의 호스트와 현재 환경의 허용 호스트가 다르다.
- 초안 저장과 실제 환경 적용은 구분한다. 클라우드 환경 설정에서 해당 초안을 검토하고 게시/적용한 다음 실제 환경 상태를 다시 확인해야 한다. 이번 작업에서 설정이나 네트워크 허용 범위를 변경하지 않았다.

자료가 열리더라도 **IHO 표준 목록 페이지를 읽는 것만으로 개별 해저 지형 정의 검수가 끝나지 않는다**. 관련 용어 표준의 실제 문서를 확인해야 한다. 마찬가지로 **Crossref 제목 검색 결과는 논문 본문 검수와 다르다**. 제목·DOI·출판 정보가 일치하는 자료를 식별한 뒤 접근 가능한 본문/초록과 검수 범위를 구분해 기록해야 한다.

현재 차단 상태에서는 본문에 근거한 생성 수치 수정이나 신규 설정 추가를 하지 않는다. 기존 설계의 ‘기관/논문 대조 미완료’ 표시는 유지한다. 에셋 목록의 이미지 생성도 이번 재검수 요청에 포함해 실행하지 않았다.

## 검증 및 재개

변경은 이 보고서, 재접속 증거 JSON, 기존 설계 문서의 재확인 링크뿐이다. 애플리케이션 코드와 저장 지도는 변경하지 않았다. 접속 8건의 실패와 3건의 프록시 헤더 증거, JSON 파싱, 문서 링크, diff 공백을 확인했다. 문서 변경이므로 앱 테스트/빌드는 재실행하지 않았다.

현재 차단을 해소한 뒤 기관 자료 → 논문 식별/본문 → 지저 모티프 링크 → 에셋 환경 조건 순서로 대조한다. 성공한 자료만 조회 시각·본문 해시·출처와 함께 기록하고, 검증 결과로 필요한 구현 변경을 별도 수행한다.
