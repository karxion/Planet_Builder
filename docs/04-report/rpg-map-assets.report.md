# RPG 지도 에셋 및 레이어 정리

## 적용 범위

- 방위표, 강수량, 인구, 측정 도구, 빙하를 표시 레이어와 스타일 선택에서 제외했다.
- 프리셋 적용 및 단축키로 해당 레이어가 다시 활성화되는 것도 차단했다.
- 기후 및 인구의 내부 생성 데이터는 유지한다. 강수량 생성 설정도 유지한다.
- 자원은 셀 색칠과 도시 생산량 패널 대신 실제 자원 셀 위치의 개별 SVG 아이콘으로 표시한다.
- 밀집 위치에서는 희귀 자원을 먼저 선택하고 아이콘 간 간격을 확보한다.
- 도시·마을 9종, 명소·표식 19종, 자원 16종의 독자 제작 SVG 에셋을 추가했다.
- 지도 도구의 `지도 에셋` 선택 창, 도시 스타일 선택, 자원 편집기, 표식 편집기 및 생성 설정에 연결했다.
- 기존 사용자 지정 이미지와 심볼은 보존한다. 기본 도시 아이콘과 기본 표식만 새 에셋으로 변환한다.
- SVG 정의를 지도 안에 포함해 저장 파일과 지도 출력에서 외부 이미지 의존성을 만들지 않는다.

## 지형 롤백

사용자 요청에 따라 일반 지형의 RPG 교체를 취소했다.

- `draw-relief-icons.ts`와 `relief-editor.js`는 변경 전 상태다.
- 기존 지형 생성 밀도, 기본·흑백·컬러 세트 및 편집 선택지를 유지한다.
- 새 에셋 창에서 일반 지형 분류를 제외했다.
- 작업 중 임시 RPG 지형으로 저장된 파일은 기존 지형 심볼로 복구한다. 위치와 크기는 유지한다.
- 기존 지형 심볼이 남아 있는 파일과 사용자 지정 지형은 변경하지 않는다.
- 화산은 지형 생성에 적용하지 않고 선택 가능한 명소 표식으로만 제공한다.

## 미완료 검증

브라우저 제어 도구의 CDP 명령이 반복적으로 시간 초과됐다. 다시 연결하고 사용자 화면의 탭에서 재시도했으며 지도 도구 메뉴까지 실제 클릭을 확인했다. 그러나 아래 항목은 이번 작업에서 통과로 간주하지 않는다.

- 에셋 선택 창 내부 선택 및 지도 배치의 전체 클릭 흐름
- 표식 아이콘 변경 및 지형 편집 창의 전체 클릭 흐름
- 2D와 3D 전환 후 텍스처 일치 및 3D 캔버스 검사
- 새 에셋의 실제 파일 저장·불러오기 UI 왕복
- 1920×1080 및 모바일의 새 선택 창 레이아웃 검사

저장 및 렌더링 관련 기존 단위 테스트는 통과했지만 위 UI 검증을 대체하지 않는다. 저장소 지침에 따라 Playwright E2E 실행기는 자동 실행하지 않았다.
