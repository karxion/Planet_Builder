# 정착지 배치 및 RPG 토큰 개선

작성일: 2026-10-11

## 적용 내용

- 일반 마을 생성 시 새 정착지를 quadtree 거리 검사 목록에 등록하지 않던 누락을 수정했다.
- 신규 생성과 일반 마을 재생성에 최소 12 지도 단위 간격을 적용했다. 항구·강변 위치 이동도 인접 정착지와의 거리를 확인한다.
- 같은 셀에 정착지를 다시 추가하면 기존 정착지 ID를 반환한다. 재생성 시 수도를 복원할 때도 기존 셀의 정착지를 재사용한다.
- 수동 마을 추가·이동·신규 수도 배치에서 가까운 위치를 차단하고 한국어/영어 안내를 표시한다.
- 기본 정착지 토큰은 인구에 따라 작은 마을 → 마을 → 장터 마을 → 도시로 변화한다. 수도는 왕성으로 표시하며 크기 변화는 제한한다.
- 사용자가 직접 지정한 아이콘과 요새·항구 같은 특수 목적 아이콘은 자동 분류로 덮어쓰지 않는다.
- 축소 화면의 그룹 대표는 가장 인구가 많은 정착지로 선택한다. 그룹을 열면 개별 엔티티에 접근할 수 있다.
- 축제 표식에 마을 그림을 재사용하던 문제를 시장 표식으로 분리했다.
- 인구 편집 후 지도 토큰을 즉시 다시 그린다. 정착지 편집 중에는 그룹 표시가 편집을 가리지 않도록 한다.

## 새 에셋

Codex 내장 이미지 생성으로 각 토큰을 개별 제작했다. API/CLI 대체 생성은 사용하지 않았다.

- 정착지 9종: 왕성, 성곽 도시, 장터 마을, 마을, 작은 마을, 요새, 감시 초소, 항구, 대상 숙영지.
- 표식 19종: 화산, 광산, 석교, 여관, 등대, 폭포, 전장, 던전, 고대 유적, 마법사의 탑, 야영지, 차원문, 샘, 시장, 도서관, 고분, 괴수 소굴, 난파선, 기념비.
- 모든 원본은 실제 알파 투명 배경을 갖는다. 원본 PNG, 프롬프트, 검증 결과를 `assets/location-tokens/`에 보관했다.
- 배포용은 256×256 WebP 28개, 총 820,164바이트다. 동일 그림을 SVG 심벌에 한 번씩 내장하여 지도 출력이 외부 이미지 주소에 의존하지 않도록 했다.
- 기존 자원 토큰 16종, 절반 크기 설정, 롤백한 지형 아이콘은 변경하지 않았다.
- 기존 RPG 에셋 ID를 유지하며 저장된 지도의 심벌 정의를 버전 5로 교체한다.

## 검증

- TypeScript 검사 통과.
- Vitest 27개 파일, 239개 테스트 통과.
- 동일 시드 생성 결과, 생성된 마을 간 최소 간격, 같은 셀 중복 추가, 항구 이동 시 충돌 방지, 인구별 토큰, 사용자 지정 아이콘 보존을 검증했다.
- 새 토큰 28종의 투명도, 고유한 이미지, 내장 WebP, 안정적인 에셋 ID를 검증했다.
- 프로덕션 빌드 통과. 기존 레거시 스크립트 경고와 에셋 청크 크기 경고는 남아 있다.
- 실제 앱에서 지도 도구 → 도구 → 지도 에셋을 열고 카테고리 전환, 던전 선택, 선택 상태와 미리보기를 확인했다.
- 1440×900에서 정착지·표식 선택 창을 확인했다. 1920×1080에서는 교체가 완료된 정착지 9종의 화면을 확인했다.
- 브라우저 클릭 도구에 간헐적인 CDP 타임아웃이 있었으나 실제 화면 캡처에서 창 열기와 새 에셋 표시를 확인했다. 타임아웃을 기능 실패나 테스트 통과로 임의 해석하지 않았다.
- 저장된 사용자의 지도를 테스트용으로 재생성하거나 시험 표식을 추가하지 않았다. 생성 관련 검증은 회귀 테스트로 수행했다.
- 저장소 지침에 따라 Playwright E2E 스위트는 자동 실행하지 않았다.

## 기존 지도 처리

기존 프로젝트의 정착지, 지리 좌표, 도로, 행정 소속을 임의로 옮기거나 삭제하지 않는다. 이미 가까이 배치된 정착지는 그룹으로 표시하며 가장 큰 정착지를 대표로 사용한다. 실제 지리 배치를 새 거리 규칙으로 변경하려면 마을 재생성이 필요하다. 고정된 정착지와 매우 작은 국가에서 필수 수도를 복원하는 경우는 기존 세계의 제약을 우선하며 화면 그룹으로 겹침을 처리한다.
