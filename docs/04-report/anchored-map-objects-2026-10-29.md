# 지상 오브젝트 소재지와 배지 UI

원인: 기존 개별 아이콘 겹침 회피는 붐비는 지역에서 큰 이동을 허용했고, fallback은 지상/국경 제한 없이 빈 위치를 검색했다. 자원 배치도 별도로 변환돼 실제 소재지가 불분명했다.

도시·장소·자원의 표시용 이동을 제거했다. 기존 변환은 복원한다. 도시와 같은 소재지의 오브젝트는 도시 아래 작은 배지, 독립 장소는 본래 좌표의 작은 표식으로 표시한다. 복수 기록만 개수를 표시하며 같은 이름의 다른 도시도 실제 위치에 유지한다. 선택 시 소재 도시와 전체 이름·에셋 미리보기를 제공하고 기존 상세 편집으로 연결한다. 저장 복제본에서 배지와 이전 표시용 이동을 제거한다. 설계는 `docs/02-design/anchored-map-objects.md`.

관련 Vitest 11파일 123개 통과(후속 갱신 지연 검사는 수정 후 재실행). 좌표·셀·국경에 무관한 원거리 이동 제거, 수동 위치 보존, 같은 소재지 통합, 실제 좌표 중심 확대, 저장 복제본 정리, 지저·해저 격리, 기존 이름/노트·총본산·복구 검사와 TypeScript/Vite 빌드를 확인했다. 독립 localhost에서 원거리 표시용 변환 0개, 41개 원본 마커가 배지와 중복되지 않음, 도시 배지 클릭→원본 에셋/소재 도시/상세 편집 진입 및 재열기를 확인했다. 초기 지도 데이터 준비 전 처리도 회귀 검사한다. 연속적인 복원/확대 변경에도 배지 갱신이 밀리지 않게 지연 시간을 제한했다. 390px 화면에서 목록·편집 버튼·Escape 닫기도 확인했다. Playwright E2E와 전체 lint는 실행하지 않았다.
