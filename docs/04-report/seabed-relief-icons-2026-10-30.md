# 해저 지형 아이콘과 수심 판독

> 2026-10-31 사용자 피드백으로 아래의 큰 PNG/수심 배지 표시 방향은 교체됐다. 현재 로컬 구현은 [작은 지형 기호 방식](seabed-cartography-2026-10-31.md)을 따른다. 이 문서는 이전 제작·검증 이력으로 보존한다.

## 구현

대륙붕, 대륙사면, 심해평원, 해구, 중앙해령, 산호초, 대륙대, 해저 협곡, 해령 열곡, 해산, 평정해산, 해저 선상지, 심해 구릉, 해연, 해양 단열대, 해저 사구의 **16종 개별 PNG**를 제작했다. 기존의 공용 산 아이콘과 특징점 원을 실제 지형별 그림으로 교체한다.

그림은 저장된 `underwater.terrain`의 종류를, 옆의 숫자/색은 해당 셀의 `depths`를 표시한다. 판독용 구간은 1=1–200m / 2=201–2,000m / 3=2,001–6,000m / 4=6,001m 이상이다. 이 구간은 앱의 간단한 판독 척도이며 생태 수층의 공식 분류로 주장하지 않는다. 지도는 판타지 생성값이고 실측 해도가 아니다.

아이콘을 누르거나 Enter/Space로 선택하면 실제 생성 수심과 지형 설명을 읽을 수 있다. 마우스 안내는 짧은 지형명·수심·단계만 표시한다. 지도에 접을 수 있는 수심 키를 제공하고, 그 버튼은 공간 편집의 16종 그림/현재 지도 수심 범례로 연결된다. 레이어의 ‘지형 아이콘’으로 그림·단계·지도 키를 함께 숨긴다. 기존 메뉴나 공간 편집창이 열리면 지도 키는 해당 메뉴를 가리지 않도록 숨긴다. 모바일에서는 기본 접힘이다.

정확한 저장 셀의 중심에만 표시하며 도시/도시 이름표와 겹치는 후보를 피한다. 희귀 지형을 먼저 대표하고 이후 종류별로 분산한다. 표시용 샘플은 별도 시드로 재현하며 32–140개 상한과 간격을 두어 밀집을 줄인다. 도시·수심·영토 좌표를 옮기지 않는다. 자원과 기존 생태 PNG는 자원/생물군계 레이어로 유지한다.

PNG와 SVG 독립 내보내기에도 숫자의 의미를 읽을 수 있는 수심 키를 포함한다. SVG의 PNG 모듈을 모두 데이터 URI로 넣는다. PNG는 기존 최대 3000px 기준을 유지한다.

## 호환과 해저 사구

지질 생성 버전을 4로 확장해 남은 얕은 대륙붕 셀 일부를 해저 사구(코드16)로 분류한다. v3의 수심, 기존 지형 특징과 생성 RNG 결과를 바꾸지 않고 마지막에 별도 모래파형 모티프를 적용한다. 지형/수심을 보고 그림을 고르는 것이며 그림에서 수심을 역산하지 않는다.

구형 무버전/v2/v3 지도의 기존 기록은 그대로 읽는다. 구형 버전에서 새로운 코드16을 가진 손상 데이터는 거부한다. 새 아이콘과 수심 표시는 **재생성 없이** 적용된다. 기존 지도에 새 사구 분류를 추가하려면 사용자가 명시적으로 해저를 다시 생성해야 한다. 자동 변환·재생성은 하지 않는다. FPB 스키마 1, 편집한 장소·주민·아이템·메모·초안 및 복구를 유지한다.

## 에셋과 제작 기록

- 생성 방식: **내장 `image_gen`**, 신규 개별 호출 16회. CLI/API 대체 생성이나 SVG 대체 그림은 사용하지 않았다.
- 원본: `assets/seabed-relief-originals/{id}.png`. 각 파일에 단일 조감도 지형이 들어 있으며 아틀라스에서 잘라 낸 그림이 아니다.
- 원본 기준 2/3 배포 마스터: `public/assets/seabed-relief/{id}.png`.
- 실제 지도·범례용 128px 파생본: `public/assets/seabed-relief/{id}-map.png`. 원본에서 직접 축소하며 16종 합계 **314,077 bytes**다. 마스터를 반복 축소하지 않는다.
- 최종 프롬프트: `assets/seabed-relief-originals/generation-spec.json`. 원본/마스터/지도본 SHA·크기: `src/data/seabed-relief-images.json`. 실제 알파 검수: `assets/seabed-relief-originals/qa.json`.
- 재현 도구: `node assets/seabed-relief-originals/prepare.ts <로컬 경로 목록.json> <검수표.png>`. Python/Pillow는 원본 복사·정적 리샘플·검수표 작성에만 사용하며 그림을 합성/재해석하지 않는다. 실제 생성 알파(상한254 또는255)를 그대로 보존한다. 개인 로컬 입력 경로 목록은 저장소에 넣지 않는다.
- 16종 전체를 4×4 검수표에서 확인했다. 투명 배경, 각 지형의 서로 다른 형태, 문자/프레임 부재 및 파일별 고유 SHA를 확인했다. 이 그림은 형상 판독용이며 지형의 축척이나 경사 각도를 정밀 측정하는 자료가 아니다.

## 분류 근거

[NOAA Ocean floor features](https://www.noaa.gov/education/resource-collections/ocean-coasts/ocean-floor-features)는 주요 해저 지형의 형상과 여러 수심 범위에 나타나는 특징을 설명한다. 따라서 지형 그림과 실제 생성 수심 단계를 분리했다. [USGS의 Georges Bank sand waves 연구](https://www.usgs.gov/publications/large-submarine-sand-waves-and-gravel-lag-substrates-georges-bank-atlantic-canada)는 얕은 대륙붕에서 조류 등에 의해 이동하는 모래파형을 설명한다. 사구는 이 모티프를 사용한 창작 지형이며, 실제 저질/해류를 추정하는 시뮬레이션은 추가하지 않았다.
