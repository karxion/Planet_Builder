# 생성 언어 적용 결과

선택 언어와 무관하게 한국어로 고정되어 있던 NPC/서사/세계 공간 생성기를 수정하고, 새 지도 이후 지명을 무조건 한국어로 바꾸던 처리도 제거했다. 한국어 기본값과 영어 설정을 실제 생성 데이터에 전달한다. 데이터 파일 스키마/기술 식별자는 유지한다.

독립된 localhost 포트에서 새 프로젝트로 검증했다. English 선택 → 행성 생성 후 영문 지도 지명, NPC 편집 필드의 이름/역할/외형/성격/목표/비밀, 보물과 교단/신격/교리를 확인했다. 한국어 선택 → 다시 생성 후 한글 지명과 한글 NPC를 확인했다. 사용자의 기존 공개 사이트 작업은 재생성하거나 새로고침하지 않았다.

관련 단위 테스트 27개 파일의 376개 검사를 통과했다. 양 언어 생성 어휘의 누락, 고정 표식 설명의 한국어 변환, 같은 시드의 NPC 능력치/아이템 등급·출전/수중·지저 지형 유지, 직접 쓴 장소·세력·NPC와 저장된 보물 보존, 수동 지명 유지, 기존 저장/출력 동작을 포함한다. 타입 검사·Vite 빌드도 통과했다. 저장소 지침에 따라 Playwright E2E는 실행하지 않았다. 기존 비모듈 스크립트 및 큰 chunk 경고는 남아 있다.

배포 준비 중 원격 main의 `ca1a965`·`fc7e841` 변경을 보존하며 rebase했다. 새 공동 세계 극지 관문의 이름과 내부 출구도 생성 언어에 연결했고 양 언어 회귀 검사를 추가했다. 병합된 해저·공동 세계 및 렌더러 검사를 포함해 위 376개 테스트와 빌드를 다시 통과했다.
