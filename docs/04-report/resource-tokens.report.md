# 자원 토큰 교체 결과

## 적용 범위

- 자원 16종을 내장 이미지 생성 기능으로 각각 제작했다. 기존 게임의 에셋은 사용하지 않았다.
- 공통 금속 테두리, 소재별 중심 그림과 배경색, 투명한 외곽을 적용했다.
- 목재, 석재, 광석, 귀금속, 곡물, 어류, 가축, 보석, 약초·향신료, 직물, 소금, 제작품, 탈것, 꿀·포도주, 석탄, 석유·타르를 포함한다.
- 기존 자원 ID와 자원 종류별 매핑, 사용자의 표시 여부 및 직접 지정한 아이콘을 유지한다.
- 지형, 도시, 명소 에셋과 생성 알고리즘은 변경하지 않았다.

## 파일과 연결

- 원본: `assets/resource-tokens/originals/*.png`, 1254 x 1254, 16종 모두 실제 알파 채널 포함.
- 표시용: `../../public/assets/rpg-map/resource-tokens/*.webp`, 256 x 256, 전체 572,534바이트.
- 생성 프롬프트: `assets/resource-tokens/prompts.json`. 첫 목재 토큰을 나머지 15종의 스타일 참조로 사용했다.
- 미리보기: `assets/resource-tokens/contact-sheet.png`.
- 기존 `rpg-*` 심볼 안에 이미지 데이터를 한 번씩 포함해 외부 이미지 URL에 의존하지 않는다.
- 정의 버전을 4로 올려 이전 지도에 포함된 자원 그림도 새 토큰으로 갱신한다.
- 자원 선택 창은 100px 미리보기와 어두운 전용 배경을 사용한다. 기존 기본 자원 크기 6/9는 한 번만 14로 이전하며, 다른 사용자 지정 크기는 유지한다.

## 검증

| 항목 | 결과 |
|---|---|
| 생성 이미지 | 16종 모두 직접 확인, 서로 다른 소재와 통일된 테두리 |
| 투명도 | 16종 모두 알파 채널 및 투명 외곽 검사 통과 |
| 타입 검사 | 통과 |
| 단위 테스트 | 21개 파일, 204개 테스트 통과 |
| 변경 TypeScript Biome 검사 | 통과 |
| 프로덕션 빌드 | 통과, 레거시 스크립트와 큰 청크 경고는 남아 있음 |
| 실제 지도 | 새 목재 토큰 표시, 자원 크기 14 및 정의 버전 4 확인 |
| 화면 확인 | 1440 x 900, 1920 x 1080 캡처 확인. 헤더와 지도가 정상 배치됨 |
| 지형 유지 | 기존 지형이 그대로 표시됨 |

실제 지도 캡처는 `assets/resource-tokens/map-desktop-1440.jpg`와 `map-desktop-1920.jpg`에 보관했다. 현재 프로젝트의 표시 설정에 따라 목재 자원만 켜진 상태로 검사했다.

## 검증 한계

브라우저의 화면 캡처와 일부 DOM 조회는 성공했지만, 클릭·포커스 명령에서 CDP 시간 초과와 접근성 요소 만료가 반복됐다. 에셋 선택 창에서 자원 변경·직접 배치, 파일 저장/열기와 3D 화면 전환의 전체 클릭 흐름은 완료하지 못했다. 이미지 포함 방식과 기존 저장/출력 경로는 코드 및 단위 테스트로 점검했으며, 해당 UI 흐름을 실제 통과한 것으로 기록하지 않는다.

보고 중 일시적인 좌표 레이어의 초기화 오류도 관찰했지만 이후 지도는 렌더링됐다. 이 자원 교체와 관계없는 좌표 코드에는 변경을 가하지 않았다.
