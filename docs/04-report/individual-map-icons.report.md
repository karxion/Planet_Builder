# 개별 토큰 기본 표시 및 정착지 중복 정리

## 변경 정책

- 도시·마을·던전·표식·자원은 지도 위 개별 표시를 기본으로 한다. 숫자가 붙은 자동 그룹 배지와 그룹 목록 팝업은 더 이상 생성하지 않는다.
- 기존 지도에 남은 그룹 표시와 숨김 속성은 화면 갱신 때 제거한다.
- 같은 정착지 ID의 반복 표시는 하나만 유지한다.
- 같은 국가에서 정규화한 이름이 같고, 같은 셀이거나 원래 좌표 간 거리가 24 지도 단위 미만이면 중복 표시로 판단한다.
- 중복 대표는 수도를 우선하고, 그다음 인구가 큰 정착지를 선택한다. 동률이면 낮은 ID를 사용한다.
- 중복 토큰에 딸린 이름표·항구 아이콘도 함께 숨겨 이중 표시하지 않는다.
- 서로 멀리 떨어졌거나 국가가 다른 동명 정착지는 별개 장소로 보존한다. 이름이 다르면 같은 좌표여도 별개로 유지하고 토큰 간격을 조정한다.
- 표시만 정리하며 정착지 데이터, 셀 소속, 인구, NPC 연결 및 메모는 삭제하지 않는다. 이름이나 위치가 변경되면 중복 판단을 다시 수행한다.

## 개별 배치

- 도시·마을·표식끼리 화면 기준 최소 3px 간격으로 가까운 여백에 배치한다. 수도와 큰 정착지를 먼저 배치한다.
- 자원 원래 위치 주변은 도시·표식 배치 시부터 6px 여백을 예약한다. 자원끼리도 서로의 원래 위치를 침범하지 않도록 보호한다.
- 같은 국가와 육지/해양 조건을 우선한다. 협소한 국경 구역에서 빈 공간이 없으면 지도 안의 가까운 여백으로 표시 위치만 이동하고 원래 위치와 연결선으로 잇는다.
- 실제 정착지/표식 좌표는 변경하지 않는다. 연결선은 클릭을 가로채지 않는다.
- 도시 이름표는 토큰 아래에 배치하되 자원과 가까우면 위나 옆으로 이동한다. 항구 아이콘도 해당 토큰의 이동량을 따른다.
- 지도 편집 중에는 자동 위치 보정을 복구해 기존 편집 좌표와 충돌하지 않도록 한다.
- 자원·지형 간 6px 여백, 기존 인구별 토큰 크기, 검은 글자의 흰 외곽선은 유지한다.

## 실제 화면 검증

복구된 현재 지도에서 1440×900, 1920×1080 화면을 직접 확인하고 DOM 사각형 간 간격을 측정했다. 전체 시드에 대한 보증은 아니다.

| 항목 | 1440×900 | 1920×1080 |
|---|---:|---:|
| 표시 도시·마을 | 823 | 823 |
| 표시 표식 (테스트 중 레이어 활성화) | 65 | 65 |
| 표시 자원 | 62 | 62 |
| 자동 그룹 배지 | 0 | 0 |
| 도시·표식 토큰 겹침 | 0 | 0 |
| 도시·표식 간 3px 미만 근접 | 0 | 0 |
| 자원 간 근접 | 0 | 0 |
| 도시·표식과 자원 근접 | 0 | 0 |
| 지형과 자원 근접 | 0 | 0 |

- 정착지 원본 824개 중 가까운 동명 `하에니아` 한 쌍을 대표 1개로 표시했다. `burg122` 대신 인구가 더 큰 `burg436`과 해당 이름표를 표시한다.
- 대표 토큰을 실제 클릭했을 때 `하에니아` 마을·도시 편집창이 정상적으로 열렸다. 편집창을 닫은 뒤 개별 배치가 다시 적용됐다.
- 표식 레이어 켜기/끄기와 해상도 변경 후에도 자동 그룹 배지가 다시 생성되지 않았다.
- 새로고침 후 자동 저장 지도 복구도 확인했다. 저장된 `draggable` 편집 속성이 824개 남은 지도에서도 실제 편집창의 표시 여부로 판단해, 도시·마을 823개/중복 대표 1쌍/토큰 겹침 0건이 유지됐다.
- 검수 후 표식 레이어는 테스트 전 상태인 꺼짐으로 복원했다.
- 토큰 사각형은 겹치지 않지만 국가명·이름표와 표식의 글자별 충돌을 모두 해결한 것은 아니다. 엄격한 자원 배치 조건에 맞는 여백을 찾지 못한 일부 자원은 원위치를 유지한다. 이 경우에도 위 표의 지형/다른 토큰 간 간격은 확보됐다.

## 검증 및 남은 개선

- Vitest 32개 파일, 291개 테스트 통과 (`--maxWorkers=2`).
- TypeScript 타입 검사, 변경 파일 Biome 검사, Vite 빌드 통과.
- 기존 classic script 및 큰 청크 빌드 경고는 유지된다.
- 저장소 지침에 따라 자동 Playwright E2E 스위트는 실행하지 않았다. 실제 앱 화면 검사 및 클릭 검증을 수행했다.
- 저장/불러오기 전체 왕복, 모든 시드, 모든 확대 단계는 별도 검증하지 않았다.
- 후속 개선은 국가명 주변의 표식 회피, 인접 이름표 간 간격, 표시용 연결선의 교차 최소화다. 개별 표시 원칙은 유지한다.
