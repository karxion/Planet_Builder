# Wikidot 참고 출처 반영

작성일: 2026-10-18

## 결과

사용자가 지정한 https://dnd5e.wikidot.com/ 를 캐릭터 메이킹·아이템·주문 조사 출처로 등록했다. 해당 홈페이지가 안내하는 https://dnd2024.wikidot.com/ 를 2024 자료용으로 별도 등록했다. 공식 자료와 UA·홈브루가 혼재할 수 있으므로 판본·원출판물·자료 상태를 분리한다는 원칙을 CONTEXT와 설계 문서에 기록했다.

NPC 상세에는 기존 12개 직업의 판본별 페이지, 종족, 배경·특기 목차, 주문, 장비·마법 아이템 목록을 연결했다. 보물 상세에는 선택한 SRD 원본 판본에 맞는 아이템·장비·주문 목록을 연결했다. 참고 경로는 공통 데이터 모듈로 관리한다. 2014의 배경·특기는 검증된 홈페이지 목차로 연결한다.

외부 참고 판본 선택은 탐색 전용이다. 저장된 NPC 직업·수치, 아이템 효과, 생성 판본과 프로젝트 데이터를 변경하지 않는다. 링크는 새 탭에서 열며 noopener/noreferrer를 적용했다. 링크를 보기만 해도 위키 내용을 자동 다운로드하지 않으며 위키 HTML·본문을 앱에 삽입하지 않는다.

기존 SRD 카탈로그와 생성 규칙은 유지했다. 상용 확장책 전체 자동 수집, 클래스/서브클래스·특기·주문 전체 DB 가져오기, 완전한 플레이어 캐릭터 생성 및 주문 엔진은 이번 반영에 포함하지 않았다. 위키의 공개 여부나 기여물 라이선스만으로 제삼자의 원문 전체 배포 권한을 가정하지 않는다.

## 확인한 출처

- [2014 홈페이지](https://dnd5e.wikidot.com/): 2024 사이트 안내와 커뮤니티·UA·홈브루 설명.
- [2024 홈페이지](https://dnd2024.wikidot.com/): 2024 직업·특기·장비·주문 분류.
- 양 판본의 기존 12개 NPC 직업 페이지와 주요 목록 경로를 웹 도구로 확인했다. 개별 확장 옵션 전체의 규칙·권리·최신성을 검증한 것은 아니다.
- [Wikidot 이용약관](https://dnd5e.wikidot.com/legal:terms-of-use) 및 [공식 SRD 안내](https://www.dndbeyond.com/srd).

## 검증

- Vitest 전체: 48개 파일, 590개 테스트 통과.
- TypeScript `--noEmit`: 통과.
- 변경 TypeScript Biome 검사: 통과.
- Vite 프로덕션 빌드: 통과. 기존 레거시 script/public CSS 및 대형 청크 경고는 유지된다.
- 판본 도메인 분리, 전체 지원 직업 경로, 잘못된 클래스 키, 비모험가 처리, 다국어 문구, 외부 링크 속성, 생성 데이터 불변, NPC 직업 변경과 보물 판본 변경의 경로 동기화를 테스트했다.
- 앱 UI는 jsdom 상호작용 테스트로 검증했다. 실제 화면·모바일 검증과 Playwright E2E는 수행하지 않았다.

로컬 코드와 빌드만 반영했다. GitHub push 및 공개 사이트 재배포는 하지 않았다.
