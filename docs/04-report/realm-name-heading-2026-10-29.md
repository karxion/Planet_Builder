# 렐름 이름 / 지도 상단 표시 적용

선택 언어에 맞는 독립 시드 기반 이름 생성과 상단 중앙 제목, 표시 여부 저장을 추가했다. 행성 설정에서 이름만 적용하거나 무작위 재추첨할 수 있으며 다른 설정 초안과 지형은 보존한다. 기존 지도 이름 필드 및 재추첨과 동기화하며 `.map` 가져오기에서 해당 파일의 실제 이름을 사용한다. 구형 FPB의 이름과 수동 입력은 보존한다.

관련 단위 테스트 7개 파일 149개 통과. 생성 언어/시드/다양성, 초안 보존, 이름 동기화, 텍스트 안전성, 표시 설정의 저장/복원, 구형 FPB·MAP 호환성과 로컬 복구 검사를 포함한다. 타입 검사·Vite 빌드 통과. 기존 비모듈 스크립트 및 큰 chunk 경고는 유지된다. Playwright E2E는 실행하지 않았다.

독립 localhost 프로젝트에서 한국어·영어 이름 재추첨, 이름만 적용, 지도 이름→행성 이름/제목 동기화, 표시/숨김, 기본 화면과 390px 상단 중앙 표시를 직접 확인했다. 테스트 중 새 행성 교체 확인창 뒤 브라우저 제어 응답이 중단되어 테스트 탭만 닫았다. 다시 연 독립 테스트 프로젝트에서 저장된 영문 지도/이름 복원과 나머지 화면 검증을 마쳤다. 사용자 공개 프로젝트를 재생성하지 않았다.

제목은 확대/이동에 영향받지 않는 화면 UI이며 SVG/PNG 지도 본문에 삽입하지 않는다. 설계는 `docs/02-design/realm-name-heading.md`.
