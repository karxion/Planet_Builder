# 유니크 효과 및 언어 선택기 수정 결과

2026-10-28 요청을 반영했다.

- 세계와 NPC 헤더 select의 높이/여백 충돌을 해소했다. 데스크톱 및 390px iframe의 한국어·영어 표시를 실제 브라우저에서 확인했다. select 실측은 약96×44px이다.
- FPB 창작 추가 효과 48종을 카테고리·국가 성향·제작 배경·지형·등급에 연결했다. 레어2 / 베리 레어3 / 레젠더리4개를 서로 다른 기준에서 선택하고 등급에 따라 수치를 조정한다.
- 장비·소모품의 행동·사용 횟수·지속시간, 피해 저항과 내성 보정의 차이를 명시했다. 보물 상세의 효과 설명은 전체 너비로 배치한다.
- 기존 v1 추가 특성을 불러올 수 있으며 목록 동기화에서 v2로 갱신한다. 사용자 작성 본문·이미지·소유/던전 연결·삭제 기록을 보존한다. 출신 지형/성향은 최초 기록 후 소유주 이전에 따라 변하지 않는다.
- 보물 상세, 매직 아이템 목록, JSON/CSV/인쇄 출력에 동일 생성·표시 로직을 적용했다. 국보 원본과 목록 복사본의 독립 수동 편집 정책은 유지했다.

검증: 관련 Vitest 7개 파일, 96개 테스트 통과. 전체 카테고리×성향×지형×등급 조합의 개수·적합성·중복 방지, 저장 왕복, 레거시 갱신·수동 기록 보존, 출력의 한/영 표현을 포함한다. 타입 검사 및 Vite 빌드 통과. 저장소 지침에 따라 Playwright E2E는 실행하지 않았다. 기존 비모듈 script 및 큰 chunk 경고는 남아 있다.
