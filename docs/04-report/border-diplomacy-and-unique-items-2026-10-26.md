# 국경 외교 토큰과 유니크 아이템 추가 특성

## 반영 범위

- 국경을 공유하는 국가 쌍마다 가장 긴 연속 국경의 길이 기준 중앙에 관계 토큰을 한 개 표시한다. 해안, 중립지, 점으로만 접한 국가는 제외한다.
- 전쟁, 적대, 중립, 우호, 동맹, 혈맹, 종속의 7종 투명 PNG를 이미지 생성으로 제작했다. 클릭 또는 키보드로 관계 편집창을 열고 종속국 방향도 선택할 수 있다.
- 관계를 양국에 함께 기록하며 순환 종속을 막는다. 혈맹은 `BloodAlly`로 저장하고 기존 편집창과 군사 경계도 계산에서도 인식한다.
- 국가 관계 레이어 표시 여부를 저장한다. 관계가 미지정된 레거시 값은 원본을 유지하면서 중립 토큰으로 표시한다.
- 토큰의 중앙 좌표는 바꾸지 않고 밀집 구간에서 크기를 축소한다. 다른 지형·도시·이름표와의 전역 충돌 회피까지 구현한 기능은 아니다.

## 유니크 아이템 알고리즘

`unique`가 켜진 아이템에 `uniqueBonus` 버전 1을 추가한다. 세계 시드와 아이템 ID로 유형별 기술 하나를 고정하므로 이름·소유주 변경과 체크 해제/재선택으로 다시 추첨되지 않는다. 기존 유니크 아이템은 아이템 창을 열 때 보강하며 이름, 효능, 이미지, 메모는 유지한다.

| 희귀도 | 기술 판정 보정 | 무기: 추가 역장 피해 / 물약: 추가 회복 | 기타: 임시 HP |
| --- | --- | --- | --- |
| 커먼 | +1 | 1d6 | 3 |
| 언커먼 | +1 | 1d6 | 4 |
| 레어 | +1 | 1d6 | 5 |
| 베리 레어 | +2 | 2d6 | 10 |
| 레젠더리 | +3 | 3d6 | 15 |
| 아티팩트 | +3 | 3d6 | 15 |

- 신규 기본 아이템은 기존처럼 레어 이상이다. 직접 지정한 낮은 희귀도는 자동으로 올리지 않으며 낮은 예산으로 처리한다. 아티팩트도 이 추가 특성만으로 상한을 넘기지 않는다.
- 비소모품은 조율 상태에서 보정이 활성화되며 기본 조율과 같은 슬롯을 사용한다. 추가 효과는 긴 휴식당 한 번이다. 무기는 선택한 적중 한 번, 임시 HP는 보너스 행동으로 발동한다.
- 물약·두루마리는 원래 소모 시 효과가 한 번 발동하며 기술 보정은 한 시간 지속된다. 임시 HP는 한 시간이고 중첩되지 않는다. 회복은 최대 HP를 넘지 않는다.
- 여러 유니크 아이템의 기술 보정은 최고값만 적용한다. 기본 명중, AC, 주문 DC를 올리지 않아 SRD 아이템의 강화 보너스와 중복 합산하지 않는다.
- 상징을 알아보는 인물에게 권위·전승의 증거로 인정되는 RP 특성을 함께 표시한다. 자동 설득 성공은 아니다.
- **공식 D&D 규칙이 아닌 FPB 창작 특성**으로 표시한다. 실전 밸런스는 GM 승인이 필요하다. 착용 슬롯, 조율 수, 사용 횟수, HP 및 피해를 실제 전투 엔진에서 자동 집행하는 기능은 포함하지 않는다.
- 체크 해제 시 추가 특성만 제거하며 원본 효능은 유지한다. 희귀도·유형 변경을 미리 보고 저장할 수 있고 한·영 UI, `.fpb`, JSON, CSV, 인쇄 출력에 반영한다.
- 같은 편집 경로에서 발견한 새 아이템의 페이지 선택 오류와 해제된 레퍼런스·던전 보상 연결이 저장 후 남는 오류를 수정했다.

## 검증

- 주 작업본 Vitest: 83개 파일, 949개 테스트 통과 (`--maxWorkers=4`). 처음 과도한 동시 실행과 타입 검사를 함께 돌렸을 때 기존 4개 테스트가 타임아웃됐으며, 작업 수를 제한한 전체 재검사에서 통과했다.
- 공개판 회귀: 37개 파일 355개 테스트, 공개 UI 호환: 11개 파일 92개 테스트 통과.
- 양쪽 TypeScript 검사와 Vite 빌드 통과. 기존 레거시 script 및 큰 번들 경고는 남아 있다. 저장소 지침에 따라 Playwright E2E 명령은 실행하지 않고 CUA로 브라우저를 직접 조작했다.
- 실제 지도에서 국가 관계 29쌍, 모든 에셋 로딩, 혈맹 변경, `.fpb` 관계 저장을 확인했다. 데스크톱에서 토큰끼리의 바운딩 박스 겹침은 0개였다. 다른 시드와 극단적 밀집 지도 모두에 대한 보장은 아니다.
- 실제 `.fpb` 다운로드에서 `uniqueBonus` 수치가 저장되는 것을 확인했다. 자동 테스트에서 프로젝트 왕복과 해제·재계산·잘못된 수치 검증·한/영 데이터 출력을 검사했다.
- 실제 아이템 창에서 레젠더리 무기 `+3` 기술 판정, `3d6` 피해, 체크 해제 후 제거, 재체크 결과 동일, 영어 전환을 확인했다.
- 국경 이미지 포함 SVG 다운로드: 29개 `use`, 7개 내장 이미지 정의. 최적화 전 107,486,445바이트에서 3,104,775바이트로 감소했다. PNG 다운로드도 직접 열어 토큰 렌더링을 확인했다.
- 모바일 실기기, 3D 행성 텍스처의 이번 토큰 표현, 실제 프린터 및 장기 세션 성능은 별도 검증 대상이다.
