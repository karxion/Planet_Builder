# 던전 내부 지도 구현 결과

## 반영 내용

- 던전·적대 거점 표식 클릭 시 내부 지도 생성 및 열기. 일반 표식 편집은 유지하고 던전에서도 별도 표식 편집 버튼을 제공한다.
- 승인받은 rot-js 2.2.1을 추가하고 BSD 라이선스를 배포물에 포함했다.
- CR 기반 지도 크기, 연결된 방·통로, 안전한 입구, 가장 먼 보스 방, 필수 경로를 막지 않는 비밀방을 생성한다.
- 방 안에 테마별 몬스터 무리, 함정, 보상 상자와 동일 판본 SRD 아이템을 배치한다. 표식 위치가 서로 겹치지 않는다.
- 일반 / 도전적 / 헬조선 난이도, 목표 CR·원본 CR 구분, 비공식 정예 보정, 함정 DC·피해·대응, 14개 유형별 보스 전술을 제공한다.
- 헬조선의 수호 수정·위험 지대는 보스 방에, 경보는 별도 방에 배치한다. 추가 보스 행동을 자동 부여하지 않는다.
- 방 선택·키보드 접근·확대·화면 맞춤·GM/플레이어 보기·현재 보기 SVG 출력을 지원한다. 플레이어 출력에는 비밀방·보스 이름·적·함정·보상 정보가 포함되지 않는다.
- `.map` 표식 JSON 및 `.fpb` 압축 저장 왕복으로 내부 지도·난이도·보상을 보존한다. 원본 시드가 바뀌거나 표식이 재식별돼도 저장된 내부 시드로 난이도 변경 지형을 유지한다.
- 생성 실패 시 기존 내부 지도 보존, 손상된 내부 데이터만 제거, 세계 지도 전환 시 창 닫기, 내부 생성 거점 자동 잠금을 적용했다.

## 검증

- Vitest: **53개 파일 / 686개 테스트 통과** (`run --maxWorkers=2`). 신규 테스트 49개.
- 기본 병렬 재검증에서 기존 `burgs-generator`와 `korean-world-names` 테스트가 5초 제한에 걸렸다. 제한을 늘리거나 테스트를 수정하지 않고 워커 2개로 전체 재실행해 통과했다.
- TypeScript `tsc --noEmit` 통과.
- 신규·변경 TypeScript 13개 파일 Biome 검사 통과.
- Vite 프로덕션 빌드 통과. 기존 레거시 스크립트 번들 및 대형 청크 경고는 남아 있다. 메인 청크 약 1,160KB / gzip 375KB.
- 실제 레거시 클릭 디스패처를 jsdom에서 실행해 던전 자동 열기와 일반 표식 편집 유지를 검사했다. 생성 실패·손상 파일·내부 시드 유지·키보드 포커스·플레이어 SVG 출력 및 Blob URL 해제도 검사했다.
- 실제 브라우저 화면·모바일 화면·3D 연동 화면 검증은 브라우저 접근 제한으로 수행하지 못했다. 저장소 지침에 따라 Playwright E2E를 자동 실행하지 않았다.
- `npm audit --omit=dev`: 취약점 0건. 전체 개발 도구 감사에는 기존 8건(critical 3, high 4, moderate 1)이 남아 있으며 이 요청에서 의존성 전체 업데이트는 수행하지 않았다.

## 제약 및 권고

- 도전적의 목표 CR은 XP 비율에서 유도한 HP·피해 정예 보정이며, 공식 CR 재계산이나 파티별 조우 난이도 보증이 아니다. 파티 인원·레벨·장비·휴식에 따른 GM 검토가 필요하다.
- 현재 몬스터 카탈로그는 기존 31종의 SRD 레퍼런스다. 모든 공식 몬스터·스탯·주문·전투 시뮬레이션 엔진을 포함하지 않는다.
- 몬스터 무리는 한 표식과 개체 수로 표현한다. 대형 몬스터의 통로 폭·점유 격자와 가구·엄폐물 자동 배치는 후속 개선 범위다.
- 플레이어 보기는 비밀 데이터 없는 지도 출력이며 자동 시야, 탐험 기록, 전투 턴 진행 기능은 아니다.
- 후속 우선순위: 실제 데스크톱·모바일 화면 검사 → 파티 기반 난이도 계산 → 전체 SRD 몬스터 색인과 실점유 크기 → 수동 내부 편집·다층 지도.
- 이번 변경은 로컬 작업 공간에 반영했다. GitHub push 및 공개 사이트 재배포는 하지 않았다.

설계와 공식 출처 링크는 `docs/02-design/dungeon-interior.design.md`에 정리했다.
