# 한글 지명 및 국가 정치 체계 적용

## 변경 사항

- 기본 마을·도시·국가·영지·강·호수 이름을 한글 판타지 지명으로 생성한다.
- 국가 정식 명칭은 `지명 + 정치 체계` 형식으로 구성한다. 왕국, 제국, 교국, 공국, 공화국, 대공국, 연합국 등을 지원한다.
- 교국 생성은 정치 체계 선택이며 종교 데이터나 종교 구획을 복구하지 않는다.
- 영지는 `○○ 영지`, 지역은 `○○ 지역`으로 표시한다.
- 기존 지도를 열 때 영어 지명을 결정적인 한글 이름으로 변환한다. 동일한 원래 지명은 동일한 이름으로 바뀌며 지형·좌표·엔티티 ID는 변경하지 않는다.
- 한글 이름과 잠긴 항목은 보존한다. 기존 영어 이름의 음역이 아니라 새 판타지 이름을 부여하는 방식이다.
- 세계·NPC 창의 `지명 한글화` 버튼으로 변환을 다시 실행할 수 있다.
- 자동 생성 NPC 목표의 마을명도 동기화한다. 직접 편집한 NPC는 변경하지 않는다.
- UI 언어를 영어로 전환해도 한글 지명은 유지된다.
- 한글 글자 폭을 기준으로 국가 라벨 크기를 계산한다.
- 국가 체계 선택의 번역된 표시명과 내부 식별자를 분리해 세금 등의 기존 동작을 보존한다.

## 검증

- TypeScript 타입 검사 통과.
- Vitest 28개 파일, 254개 테스트 통과.
- Vite 프로덕션 빌드 통과. 기존 classic script 및 청크 크기 경고는 남아 있다.
- 실제 브라우저 지도와 세계·NPC 창에서 한글 지명, 국가 수식어, 지역·영지 분류 및 NPC 목표를 확인했다.
- UI를 영어로 전환해도 `네다도르 제국`, `유네르 공국` 등 세계 이름이 한글로 유지되는 것을 확인했다.
- 새 한글 지명의 시드 재현성, 기존 지도 변환의 재현성과 멱등성, 잠금·한글 이름 보존, .fpb 한글 데이터 압축 왕복을 테스트했다.
- 저장된 지도 복구 후 한글 지명 유지도 화면에서 확인했다.
- 자동 Playwright E2E 스위트는 저장소 지침에 따라 실행하지 않았다.
