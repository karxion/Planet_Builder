# 지저·해저 배치 오브젝트 에셋 목록 — 검토안

상태: **목록 검토 대기. 아직 이미지를 생성하지 않음.**

2026-10-28 사용자 첨부 PDF 5개를 대조해 [자료 근거와 환경 조건](../04-report/subsurface-pdf-review-2026-10-28.md)을 보완했다. 64종/우선 24종의 범위는 유지한다.

사용자 요청의 순서인 ‘에셋 목록 작성 → 목록 검토 → 생성’을 따른다. 완성 지도 한 장 대신 재사용 가능한 개별 부품을 만든다. 현재 지저의 거대 터널형/공동 세계형과 해저 지형/수중 세력 지도에 사용하고, 조감도·전투지도에서도 가능한 부품을 재사용한다.

## 범위와 생성 규격

- 신규 **64종**: 해저 28종, 지저 28종, 공용 8종. **1차 우선 생성 24종**, 확장 40종을 제안한다.
- 이미지 생성 도구로 만든 **투명 배경 PNG**를 사용한다. 기존 요청대로 생성 원본 가로·세로의 약 **2/3**를 배포하며 원본은 보관한다. 완성 지도 PNG의 최대 3000px는 별도로 유지한다.
- `D`는 조감도(비스듬한 위 시점)와 전투지도(수직 탑다운)의 두 시점이다. 기존 모듈과 같이 **같은 오브젝트만 두 시점으로 담은 마스터**를 만들고 각각의 뷰포트를 지정한다. 서로 다른 에셋을 한 장에 모아 생성하지 않는다.
- `R`은 지역지도용 입체 표식이다. 해산처럼 규모가 큰 지형은 전투지도의 실물 크기로 축소하지 않는다. 전투지도용은 해당 지형의 바위/가장자리 등 별도 작은 부품을 사용한다.
- 60종은 D, 4종은 R로 총 **124개 시점 뷰**다. 생성 파일은 64개 마스터를 기준으로 하며, 배포 형식은 기존 두 시점 모듈 파이프라인에 맞춘다.
- 조감도는 기존 판타지 지도 모듈과 어울리는 수작업 일러스트 질감으로 맞춘다. 해저는 청록·남청/산호색, 지저는 석회암·현무암/균류·수정의 약한 발광, 공동 세계는 자연스러운 녹색·황토색을 사용한다.
- 원형 배지·장식 테두리·지면 받침대·글자·격자·완성 배경을 넣지 않는다. 지면이나 해저면 위에 실제 놓이는 부품으로 보이게 한다. 발광과 그림자는 짧게 제한한다.
- `S`는 대략 1~2칸, `M`은 2~4칸, `L`은 4~8칸 배치를 검토하는 부품이다. 이는 제작 시 가독성/바닥 면적 기준이며 실제 게임상 크기·충돌 판정은 별도 데이터로 정한다. 벽·다리 등 연결 부품은 행에 적힌 길이를 우선한다.
- 환경/수심 조건은 배치 연출의 기준이다. 이미지 생성만으로 광물 생성 확률, 생산량, 종족 능력치나 환경 피해 규칙을 추가하지 않는다.

| 지저 자연 지형 | UT01, UT02, UT05, UT09, UT10, UT11 | 6 |
| 지저 자원 | UR01, UR04, UR06 | 3 |
| 지저 시설 | US01, US05, US06 | 3 |
| 공용 연결 | C01, C02, C04 | 3 |

목록 검토 후 우선 ST01(가지산호), UT05(거대 버섯), UR01(철광맥)으로 표현 기준을 맞추고 나머지 1차 에셋을 생성·검수한다. 이 3종은 24종에 포함되며 별도 추가분이 아니다. 확장 40종은 동일 규격으로 이어서 생성할 수 있다. 기본 권고는 **1차 24종부터 생성**이다.

## 생성 후 검수·통합 기준

### 첨부 자료를 반영한 배치·형태 조건

- ST08/ST09는 NOAA의 주변 해저 대비 1000m 이상 기복과 원뿔형/평탄 정상 구분을 따른다. 지역 표식의 이미지 높이로 실제 수심을 정하지 않는다.
- ST11 협곡 가장자리는 양쪽 주변부에 사용할 수 있다. 활동형의 짧고 촘촘한 분기, 수동형의 긴 주축은 지형 생성기가 결정하며 가장자리 부품은 이를 보강한다. ST10/ST11은 해령 축부 폭과 가지 구조를 가리지 않도록 연결한다.
- ST01/ST02 산호와 ST05 해면을 수심만으로 모두 얕은 산호초와 동일시하지 않는다. 2011년 PDF는 일부 해산 정상·협곡 머리의 냉수성 산호 서식처도 언급한다. 얕은 산호초 지형 코드와 깊은 곳의 개별 서식처는 별도로 다루며, 모든 산호종에 동일 조건을 부여하지 않는다. ST03/ST04는 얕은 광합성 식생 용도로 유지한다.
- UT05–UT07 균류, UT11 용수, US 시설은 터널형 공동·호수·교역 거주지의 모티프로 사용한다. 어두운 공동 세계의 식생 유지 방식은 사용자가 정하는 판타지 설정이며 광원 색조만으로 생산량을 계산하지 않는다.
- C04 관문은 도시 주변/선택한 극지권 출입구에 재사용한다. 극지 설정을 이유로 지상 전체에 거대 구멍 이미지를 자동 배치하지 않는다. 광원은 표현 선택이며 중앙 태양 에셋을 신규 필수 항목으로 추가하지 않는다.
- SR/UR 광물의 분포와 채굴 생산량은 이번 PDF에서 검증한 내용이 아니다. 명세의 자연 자원 예시와 별도 선택 환상 자원은 그 상태로 구분한다.

### 이미지 및 통합 검수

- 32/64px 지역 표식과 확대 시점에서 종류가 구분되는지 확인한다. 조감도와 탑다운의 오브젝트 종류·재질·형태는 같아야 한다.
- 투명도, 시점별 여백/겹침, 벽·문·다리 연결 단면, 바닥 앵커, 축소 후 잘림을 확인한다. 지저/해저의 어두운 배경과 공동 세계의 밝은 배경에서 모두 점검한다.
- 큰 지형 영역은 현행 생성기/경계선을 유지하고 에셋 밀도로 지도를 덮지 않는다. 지역용 표식과 전투용 실물 부품의 크기를 혼동하지 않는다.
- 환상 자원은 선택 배치 항목으로 구분한다. 자원/경제 대응 ID·점유 칸·통행 정보는 그림의 색에서 추측하지 않고 데이터로 연결한다.
- 현재 세계 공간에는 전용 자원 오브젝트 분류가 없으므로, **이미지 생성 완료**와 **지도 자동 배치/경제 연결 완료**를 구분해서 보고한다. 해당 통합은 에셋 검수 뒤 진행할 별도 구현 범위다.
- 파일별 원본/배포 크기·SHA-256·시점 범위·앵커·권장 크기·태그를 기록한다. 생성 원본은 유지하고 배포본에만 약 2/3 축소를 적용한다. 완성 지도 PNG의 상한 3000px는 바꾸지 않는다.

## 검토할 결정

1. 우선 24종 생성으로 진행할지, 64종 전체를 생성할지.
2. 목록에서 추가/제외할 오브젝트와 우선순위 변경.
3. SR08/UR08의 마정석 등 환상 자원 포함 여부. 일반 광물/자연 자원과 독립적으로 생성/배치 가능하게 준비한다.
