# 해저 지형과 수중 세력

지형 분류·수심 형상은 후속 [해저 지형학 보완](./seabed-geomorphology-v2.md)에서 확장했다. 아래는 최초 해저/수중 세력 구현 기록이다.

## 사용

1. **수중 지도 → 공간 편집 → 해저·세력 → 해저·세력 생성**. 지형이 없는 첫 수중 진입에서는 생성 패널을 연다. 시드와 현재 지상 높이/해안선을 사용한다.
2. **지형 + 세력권 / 해저 지형 / 세력권**을 전환한다. 대륙붕(200m 이하), 대륙사면, 심해평원, 해구, 해령, 산호초를 서로 다른 색으로 표시하며 200/1000/3200/6000m 등심선을 제공한다.
3. 생성 세력은 멀포크·사후아긴·트리톤·바다 엘프·로카타·쿠오토아를 초기 주민 구성으로 갖는다. 고유 세력명·색·주민 구성·메모를 자유롭게 바꾸거나 기존 세력 탭에서 새 세력을 추가할 수 있다. 지도 범례의 세력 버튼은 해당 편집 화면을 연다.
4. **외교 관계**에서 동맹·교역·중립·경쟁·전쟁을 변경한다. 관계는 양방향이며 즉시 적용한다. 초기 관계는 이 세계를 위한 수정 가능한 설정이며 종족 전체의 고정 행동이나 능력치 규칙이 아니다.
5. 도시를 선택해 이름·주민·인구·깊이·소속을 편집하거나 수동 도시/영역을 추가한다. 생성 지도에서 새 수중 장소의 기본 깊이는 해당 위치 해저 수심이다. 새 장소 배치/이동은 육지를 거부한다. 기존 파일의 수동 장소는 자동 이동하지 않고 보존한다.
6. PNG/SVG 내보내기는 선택한 보기의 지도 전체를 최대 3000px로 출력한다. FPB 저장과 Drive 사본에는 수심·지형·세력권·교역로·주민과 외교 관계를 모두 저장한다.

## 지형 생성

현재 판타지 세계의 지상 격자를 160×96으로 표본화한다. 담수호는 해양 지도에서 제외하고, 높이 20 미만의 해양 셀에 양의 해저 수심을 부여한다. 육지와의 거리로 대륙붕·사면을 만들고, 바다 안쪽은 원래 바다 높이와 시드 기반 변화로 심해평원을 형성한다. 심해 쪽에 해구/해령 축을 더하고 얕은 연안에 산호초 군락을 만든다. 수심은 해수면 아래 미터값으로 저장한다.

수심은 이 세계의 해안선에 대응하는 절차적 생성값이다. 지구의 실측 수심이나 판구조·조류·수압 시뮬레이션을 사용하지 않는다. 격자보다 작은 섬·해협은 단순화될 수 있다. 렌더러는 저장된 수심/분류로 경계를 그리며 표시할 때 무작위 지형을 다시 만들지 않는다.

## 세력과 연결

- 6개 초기 세력의 중심도시는 서식 수심 선호와 세력 사이 거리로 분산한다. 깊이는 선호이며 특정 종족의 규칙적 생존 한계로 강제하지 않는다.
- 각 중심도시에서 물 셀만 따라 다중 시작점 탐색을 수행해 연결된 영향권을 만든다. 육지는 소유하지 않으며, 시작점이 없는 고립 수역은 미점유로 남는다.
- 가능한 영향권 안에 교역항을 두고, 탐색 경로를 따라 교역로를 저장한다. 자동 교역로는 육지를 돌아가는 실제 좌표열을 갖는다. 기존 수동 연결은 사용자가 만든 개념적 연결선이다. 도시 이동 시 오래된 자동 경로 좌표를 해제하므로 새 이동로는 연결 탭에서 다시 설정할 수 있다.
- 세력 삭제 시 도시를 보존하고 소속을 해제하며, 관련 외교 관계와 지도 영향권을 정리한다. 새 수동 세력은 장소 소속·수동 영지 도구로 지도에 반영할 수 있다.
- 세력권은 생성 당시의 지리적 영향권이다. 주민 구성이나 도시 소속 변경이 국경을 자동 확장하거나 전쟁 시뮬레이션을 실행하지 않는다. 능력치·몬스터 데이터나 NPC 자동 생성은 추가하지 않는다.

## 저장·재생성

`WorldSpacesData.version: 1`에 선택 필드 `underwater`와 `relations`, 세력의 `people`, 연결의 `path`, 자동 생성 출처 `underwater`를 추가한다. 기존 수동 지도/지저 파일을 그대로 읽는다. 격자 크기·배열 길이·수심·지형 분류·육지 소유 금지·세력 참조·중복 관계·경로 좌표와 끝점을 검증한다.

명시적인 **해저·세력 다시 생성**은 지형·자동 영향권·미편집 자동 도시·자동 교역로를 교체한다. 수동 장소, 직접 수정했거나 초안 작성 중인 자동 장소, 기존 세력의 이름/종족/색/메모, 편집한 외교 관계는 유지한다. 수동 연결은 양 끝 장소가 남아 있을 때 보존한다. 삭제한 초기 세력이나 자동 거주지는 재생성하면 다시 만들어질 수 있다.

지상 새 지도 생성은 추가 공간 데이터를 유지한다. 따라서 지상 지형을 바꾼 후 새 해안선에 맞추려면 해저를 다시 생성한다. 기존 수동/수정 도시가 새 육지 위치에 남을 경우 사용자가 바다로 옮긴다. 지저 지도 데이터는 수중 재생성의 영향을 받지 않는다.

FPB·로컬 복구·Drive는 기존 공통 프로젝트 코덱을 사용한다. 해저 SVG는 지상 `mapPayload`에서 제외한다. 공간 기록 보존에는 FPB 저장을 사용하며 레거시 `.map`에는 추가 공간 데이터가 포함되지 않는다.
