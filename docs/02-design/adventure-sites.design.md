# 국가별 던전·적대 거점

작성일: 2026-10-18

## 범위

국가 소유의 육지 셀 중 정착지·다른 표식과 거리가 확보된 곳에 시드 기반 던전과 적대 세력 거점을 배치한다. 기존 FMG 표식·노트·편집기를 사용하며 새 지도 생성에 연결한다. 기존 지도는 던전 창의 공백지 자동 배치로 보완한다. 기존 수동/레거시 표식은 자동 이동하거나 삭제하지 않는다.

17개 테마와 14개 몬스터 유형의 31종 대표 레퍼런스를 사용한다. 오크 약탈단·고블린 적대 취락, 마법사의 탑, 언더월드 통로, 용의 둥지, 언데드 납골성, 정령 균열 등을 포함한다. 특정 종족 전체의 성향을 적대적으로 지정하지 않고 해당 거점 세력의 행동·위험을 창작한다.

## 배치

- `AdventureSnapshot`은 국가, 육지 셀, 전 세계 정착지 및 표식 위치만 담는다. 생성기는 DOM과 전역 상태를 사용하지 않는다.
- 국가 ID와 셀 ID를 정렬하고 국가별 Alea 스트림으로 후보를 섞어 입력 순서와 전역 난수의 영향을 제거한다.
- D3 quadtree로 모든 정착지와 기존/신규 표식에 대한 여백을 검사한다. 가장 가까운 마을 밖이라도 더 큰 도시의 배제 반경 안이면 배치하지 않는다.
- 정착지 중심 간격 기본값은 지도의 짧은 변 6% (최소 16 지도 단위), 도시·수도는 그 1.5배다. 도시 판정은 수도 또는 population > 5로 기존 토큰/NPC 기준과 같다.
- 표식 중심 간격은 짧은 변 4.5% (최소 20 지도 단위)다. 테두리에서는 토큰이 잘리지 않도록 여백을 둔다. 지도 단위는 화면 픽셀이나 km가 아니다.
- 국가별 자동 거점 목표는 `ceil(sqrt(육지 후보 수) / 8)`, 기본 상한 6, 최소 1이다. UI에서 간격과 상한을 조정한다. 자동 거점 메타데이터가 있는 기존 기록을 목표 수에서 차감하고 수동/레거시 표식은 장애물로만 보존한다.
- 물·무소속 땅·정착지 셀은 제외한다. 공간이 부족하면 거리를 완화하거나 정착지를 옮기지 않고 부족 국가를 결과에 표시한다.

## 테마와 위협

적대 취락 선택 가중치는 30%, 나머지는 던전 테마다. 테마에 연결된 몬스터 중 낮은 CR에 더 높은 가중치를 주고 고위험 개체는 드물게 선택한다. 같은 시드·설정·재생성 번호에서 동일 결과를 얻는다.

CR은 대표 몬스터 한 개체의 공식 레퍼런스 값이다. 개체 수는 거점 전체의 추정치이고 혼합 세력이 있을 수 있다. 특히 언더월드 통로는 20~80개체의 출몰지로 설정한다. CR과 개체 수를 합산해 전투 난이도로 표시하지 않는다. 파티 규모·자원·웨이브·지형을 고려하는 조우 밸런스 엔진은 포함하지 않는다. NPC 서사 레벨·티어와 몬스터 CR은 별개다.

대표 이름·유형·CR·페이지는 공식 SRD 5.2.1에서 확인했다. 오크와 고블린의 휴머노이드 레퍼런스는 SRD 5.1 (2014)로 명시하고 판본을 표시한다. 두 판본의 스탯을 합치지 않으며 스탯 블록 원문은 복제하지 않는다. 테마, 번역 이름, 배치·개체 수·적대 행동은 앱의 창작 설정이다.

## 저장과 편집

선택적 `Marker.adventure`에 version/themeId/monsterId/inhabitants/cleared/edited/generation을 저장한다. 위치·국가 소유는 기존 marker.cell/x/y와 셀 데이터가 원본이다. 이름·설명·원본 PDF/Watabou 링크는 기존 노트로 연결한다.

표식 JSON이 기존 `.map` 저장에 포함되므로 `.fpb`의 mapPayload에도 같은 메타데이터가 들어간다. 불러오기에서 잘못된 추가 메타데이터는 제거하되 원래 표식은 유지한다. 메타데이터 없는 이전 던전에 CR을 임의로 부여하지 않는다.

던전 목록은 30개씩 표시하고 테마·유형·대표 개체·CR·추정 수·상태·출처를 보여준다. 공략 완료 또는 던전 창에서 편집한 거점은 수정 표시와 잠금으로 보존한다. 재생성 버튼은 미수정·미잠금 자동 거점만 교체하며 수동·레거시 표식과 노트는 유지한다. 기존 FMG 전체 표식 재생성에는 기존 잠금 정책이 적용된다. 간격 설정은 현재 세션의 생성 설정이며, 생성된 위치와 상태는 파일에 저장한다.

Watabou 링크는 기존 외부 구조 생성기 연결이다. 실제 실내 지도·층·방·몬스터 조우 구성을 앱 내부에서 생성한 것으로 표시하지 않는다.
