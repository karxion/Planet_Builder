# 렐름 이름과 지도 제목

새 프로젝트 및 자동 이름 모드의 행성 재생성 시 한국어/영어 생성 설정에 맞는 렐름 이름을 만든다. 이름 생성은 지형 RNG를 소비하지 않는 별도 Alea 시드를 사용한다. 명시적인 행성 생성 시 입력한 시드가 있으면 같은 시드/언어에서 같은 이름을 만든다. 구형 기본 이름은 새로 생성할 때 자동 이름으로 바꾸며, 저장 데이터를 열 때 기존 이름을 일괄 변경하지 않는다.

지도 이름과 행성 설정의 적용된 이름은 같은 값이다. 지도 설정의 이름 변경/재추첨도 행성 이름에 반영한다. 행성 설정의 이름 입력은 기존 편집 초안 정책을 유지하며 ‘이름 적용’ 또는 ‘행성 생성’으로 적용한다. ‘이름 무작위 생성’은 이름만 즉시 적용한다. 이름만 적용할 때 지형과 다른 설정 초안은 보존한다.

상단 중앙 제목은 화면 좌표의 고정 DOM 레이어로 렌더링하여 지도 확대/이동과 무관하게 유지한다. 지도 클릭을 가로채지 않고 사용자 이름은 textContent로 출력한다. 이 제목은 화면 UI이며 지도 SVG/PNG 자체의 지형 데이터에는 삽입하지 않는다. 표시 체크박스는 즉시 적용한다.

`PlanetSettings`의 선택 필드 `nameGenerated?: boolean`, `showName?: boolean`을 FPB 스키마 1에 추가한다. 누락된 구형 파일은 제목 표시를 기본으로 하며, 이름은 보존한다. 자동 이름만 재생성 시 새 이름을 받고 수동/파일 이름은 유지한다. `.map` 가져오기는 해당 파일의 저장된 지도 이름을 사용한다. `showName`은 미적용 편집 초안에 섞지 않고 프로젝트 설정으로 저장한다.

검증 범위: 생성 이름의 시드·언어·다양성, 지도·행성·제목 동기화, 이름만 적용할 때 지형 및 다른 초안 보존, 안전한 텍스트 출력, 숨김 및 FPB 왕복/복원, 구형 파일·복구 동작을 관련 단위 검사로 확인한다. Playwright E2E는 자동 실행하지 않는다.
