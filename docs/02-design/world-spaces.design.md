# 지상·수중·지저 지도 1차 구현

## 범위

상단에서 지상/수중/지저를 전환한다. 3D 행성은 추가 보기로 이동하며 기존 globe 저장 파일과 카메라 복원은 유지한다. D&D/Pathfinder는 세계관 예시이며 새 규칙·능력치 데이터는 도입하지 않는다.

첫 버전은 수동 작도 도구다. 도시, 영지·세력권, 타원형 지형 영역, 연결 지점을 클릭해 배치하고 이름·깊이·주민·인구·소속 세력·메모를 편집한다. 산호초·해구·공동·지하호수·암반은 사용자가 지정하는 영역이며 자동 생성된 해저/동굴 지형이 아니다. 다음 단계의 자동 생성기는 이 데이터를 유지하며 비어 있는 부분을 채우도록 별도 설계한다.

수중 배경은 청색, 지저는 자색이다. 옅은 지상 실루엣은 현재 지상과의 위치 대응만 보여 주며 수심이나 공동을 의미하지 않는다. 지상 레이어는 CSS로 가려져 공간 전환 시 원래 상태로 돌아오고, 수동 데이터의 렌더링은 별도 SVG 그룹으로 분리된다. 배경·그룹은 기존 지형/국가/도시 데이터를 변경하지 않는다.

## 데이터와 연결

`PlanetProject.worldSpaces`는 선택 필드다. 기존 schemaVersion 1 파일에 필드가 없으면 빈 공간 기록으로 연다. 현재 지상 지도와 campaign은 유지한다. 신기능 데이터를 모르는 이전 앱에서 파일을 다시 저장하면 추가 기록이 누락될 수 있으므로 최신 앱을 사용한다.

- 모든 공간은 같은 지도 범위의 정규화된 x/y(0~1)를 공유한다. 지도 크기가 달라져도 상대 위치는 유지된다. 전환 시 현재 확대/이동을 유지한다.
- 장소는 독립 UUID를 가지며 지상 Burg/State 번호를 재사용하지 않는다. 같은 위치, 다른 공간/깊이에 도시를 둘 수 있다. 첫 버전은 공간당 한 화면으로, 깊이는 기록·표시 정보이며 깊이별 필터나 다층 지형 생성은 후속 범위다.
- 수중 깊이는 해수면 아래, 지저 깊이는 해당 위치 지표면 아래의 미터값이다. 현실 지질이나 압력 계산은 하지 않는다.
- 세력은 이름·색·메모를 가지며 공간을 넘는 장소의 소속으로 지정할 수 있다. 영지 영역은 수동 표시이며 셀 점유/국경 계산이나 NPC 자동 소속 변경을 수행하지 않는다.
- 동일 공간의 연결은 점선 이동로, 다른 공간의 연결은 전환 가능한 통로다. 실제 터널 고도/거리/보행 가능성은 계산하지 않는다.
- 장소 삭제 시 관련 연결도 삭제한다. 세력 삭제 시 장소는 유지하고 소속만 해제한다. 데이터 검증은 ID 중복, 없는 대상 참조, 자기 연결, 비정상 좌표/깊이/색/수치 및 과도한 크기를 거부한다.

## 저장과 재생성

`.fpb`에 확정된 장소·세력·연결과 활성 공간을 저장하며 기존 로컬 복구 및 Drive 사본 저장도 같은 코덱을 사용한다. SVG 렌더링 그룹은 기반 mapPayload에서 제거해 중복 저장하지 않는다. 레거시 `.map` 내보내기에는 추가 공간 기록이 포함되지 않는다. 공간 기록을 보존하려면 상단 FPB 저장/클라우드 저장을 사용한다.

기존 지상의 새 지도 생성은 수동 공간 기록과 공간 편집 초안을 보존한다. 새 지상과 맞지 않는 위치는 사용자가 이동/삭제한다. 다른 파일 또는 레거시 지도를 열면 그 파일의 공간 기록으로 교체하며, 없는 필드는 빈 상태로 초기화한다. 장소·세력 편집과 새 연결 폼은 기존 초안 경고·로컬 복구에 포함된다. 초안은 적용 전까지 FPB/Drive 파일에는 포함하지 않는다.

## 사용 순서

1. 수중/지저 지도 → 공간 편집 → 도시/영지/지형/연결 지점 중 하나 → 지도 위치 클릭.
2. 이름·깊이·주민 등을 편집하고 변경 적용. 위치 옮기기는 다시 지도 클릭, Esc는 배치 취소.
3. 세력 탭에서 세력을 만들고 장소의 소속 세력으로 지정.
4. 연결 탭에서 출발/도착 장소 지정. 지도상의 화살표는 다른 공간의 도착지로 이동한다. 지상에도 항구·동굴 입구를 추가해 연결할 수 있다.
5. 상단 저장으로 FPB를 보관하거나 클라우드의 Google Drive 저장 사용.

모바일은 배치 중 편집창을 안내문 크기로 접어 지도를 누를 수 있게 한다. 한국어/영어 UI를 제공하고 사용자 지명·메모는 번역하지 않는다.
