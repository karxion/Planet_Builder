# 교단 총본산 지도 표시 개선안

현재 렌더러는 도시·표식·지명과 겹치지 않도록 총본산 아이콘과 이름표 전체를 빈 공간으로 이동시킨다. 후보 지점이 실제 육지나 해당 도시 위인지 확인하지 않아 바다로 밀려날 수 있고, 원래 위치와 이동된 아이콘 사이 선이 누적된다. 이름도 8자 단축과 textLength 강제 압축으로 작아지고 읽기 어려워진다.

## 추천안: 실제 소재 도시의 배지

- 총본산을 독립 도시 아이콘처럼 분리하지 않고 소재 도시 아이콘의 작은 배지/링으로 표시한다. 앵커 좌표를 도시 좌표로 고정하고 배치 충돌 때문에 다른 지점으로 이동시키지 않는다.
- 연결선은 기본적으로 없앤다. 사용자 선택 강조가 필요하면 이동선 대신 해당 도시의 테두리/링을 잠시 강조한다.
- 전 세계/대륙 축척에서는 총본산 배지를 숨기고, 지역/도시 수준에서 배지만 보인다. 세부 내용은 클릭·키보드 선택·터치로 표시해 모바일에서도 마우스 호버에 의존하지 않는다.
- 긴 교단명은 선택 패널에서 줄바꿈해 전체 표시한다. 지도에는 짧은 배지만 두고 글자를 강제로 압축하지 않는다. 패널에는 교단명·소재 도시·국가를 함께 표시한다.
- 한 도시에 여러 총본산이 있으면 여러 아이콘을 흩뿌리지 않고 배지 하나와 개수로 합친다. 선택하면 교단 목록을 보여 준다.
- 기존 총본산 표시 토글은 유지한다. 나중에 수중/지저 교단이 추가되더라도 공간 데이터에 명시된 경우에만 그 공간에 표시하며, 육상 총본산을 시각적 여백을 찾아 바다로 옮기지 않는다.

## 대안 비교

| 방식 | 장점 | 한계 |
|---|---|---|
| 도시 배지 + 선택 패널 | 실제 위치 보존, 선 없음, 도시와 교단 관계가 명확 | 확대 축척/도시 아이콘 크기에 따른 배지 조정 필요 |
| 실제 위치의 작은 핀 | 구현 단순, 좌표 정확 | 도시가 밀집하면 핀 중첩 |
| 별도 종교 전용 보기 | 교단 분포 비교에 좋음 | 일상 세계 지도에서 추가 전환 필요 |

우선 도시 배지와 선택 패널을 적용하고, 이후 필요할 때 종교 전용 보기를 추가하는 순서를 권장한다.

## 적용 결과

- 총본산을 기록된 소재지 좌표의 링과 작은 배지로 표시한다. 배치 충돌 회피, 독립 기념탑, 연결선과 압축 이름표를 제거했다.
- 같은 `headquartersId`의 교단은 하나의 배지로 묶는다. 한 교단은 별, 여러 교단은 개수로 표시한다.
- 지도 전체를 맞춘 축척의 1.8배 이상 확대하면 표시한다. 화면 기준 링 반경 10px·터치 영역 지름 44px를 유지한다. 축소 시 키보드 탭 대상에서도 제외한다.
- 클릭·Enter·Space로 읽기 전용 패널을 열어 전체 교단명·신격명·소재 도시·국가를 표시한다. Escape/닫기로 선택을 해제하고, 교단 상세 버튼은 기존 편집 화면으로 연결한다.
- 기존 `country:*` 지정은 국가 중심으로 명확히 표시한다. 임의 도시로 재지정하거나 종교 저장 데이터를 변경하지 않는다. 수중·지저 보기에서는 육상 표식과 패널을 숨긴다.
- 표시 토글을 유지하고 종교 화면에 확대 안내를 추가했다. 지도 새 생성·프로젝트 복원·기존 세계 편집 화면 진입 시 패널을 닫아 이전 선택을 남기지 않는다.

검증: 관련 단위 테스트 47개, TypeScript 검사와 프로덕션 빌드 통과. 실제 Chromium에서 도시 좌표 고정·연결선 제거·축척에 따른 표시·동일 소재지 교단 묶기·키보드 선택·교단 상세 연결·표시 토글·390px 모바일 패널 및 선택 전후 종교 데이터 동일성을 확인했다.
