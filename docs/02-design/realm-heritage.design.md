# 렐름 보물과 신앙

작성일: 2026-10-18

## 범위와 규칙

최신 요청에 따라 종교를 캠페인의 서사 데이터로 다시 도입한다. 기존 FMG 종교/문화 셀 구획은 복구하지 않는다. 행정 분류는 마을→영지→지역→국가 그대로다.

- 모든 실제 국가(stateId > 0)에 최소 1개 국가 보물. 희귀도는 Very Rare 또는 Legendary다.
- 보물 목표 수 = min(12, 1 + floor(영토 비중 × 8) + floor(건국 경과 연수 / 400)). 영토 비중은 지도 내 유소속 국가 육지 면적의 합을 기준으로 계산한다. 역사 기본값은 시드로 50~1800년을 생성하며 편집할 수 있다.
- 수도 및 시드 확률 25%에 선택된 도시(population > 5)에 상징품 1개. 희귀도는 Rare~Legendary이고 별도 unique 태그를 항상 갖는다.
- Unique는 D&D 공식 희귀도 단계가 아닌 세계관의 유일성·상징성 태그다. 효능보다 소유권, 정통성, 시민의 신뢰, 의례 등 RP 효과를 우선 기록한다.
- 아이템과 신격은 고유 창작 서사 프리셋이다. 공식 D&D 아이템의 완성된 전투 규칙이나 신격 스탯 블록을 제공하는 기능이 아니다.
- 국가별 최소 한 종교를 생성한다. 오래된 큰 국가는 최대 3개다. 종교명·상징 설명·9성향·신격명·소/중/대신격·교리·총본산을 기록한다.
- 총본산은 기본적으로 해당 국가의 도시/마을에 배치한다. 정착지가 없는 국가는 국가 중심을 임시 총본산 위치로 사용한다. 문화·종교 영토 레이어는 추가하지 않는다.

## 저장과 수명

CampaignWorld v1에 선택적 heritage 객체(version=1, nations, treasures, religions)를 추가한다. 옛 FPB에는 첫 복원 시 생성한다. 같은 seed/국가/정착지/슬롯의 생성 결과는 동일하다. 종교와 아이템 편집은 자동 갱신으로 덮어쓰지 않는다. 확장된 영토나 역사는 부족한 국가 보물만 보충하며 역사가 줄어도 기존 보물은 삭제하지 않는다.

새 국가·도시에 데이터를 보완하되 삭제된 지도 엔티티의 기록은 삭제하지 않고 목록에서 소속 없음으로 남긴다. 위치가 사라진 총본산은 지도에 그리지 않으며 목록에서 재지정한다. 일시적으로 사라진 지도 참조를 파일 검증에서 데이터 손실의 이유로 삼지 않는다.

## UI

세계·NPC 창에 NPC/보물/종교 탭을 둔다. 기존 행정 필터를 공유하며 목록 검색, 항목 선택, 상세 편집, 지도 위치 보기, JSON 내보내기를 제공한다. 국가 역사 연수는 별도 숫자 입력/저장으로 수정한다. 종교 총본산의 지도 표시 토글과 클릭하여 상세 열기를 제공한다. 화면 텍스트는 한국어/영어를 지원한다.

총본산은 기존 RPG 기념물 에셋을 사용한 개별 표식으로 표시한다. 정확한 정착지 좌표는 연결선으로 남기고 토큰/지형/자원/라벨과 겹치지 않도록 표시 위치를 오프셋한다. DOM 렌더러는 데이터를 변경하지 않는다. 파생 지도 오버레이는 .map payload에 저장하지 않고 FPB heritage에서 재구성한다. SVG/PNG 출력에는 현재 표식을 포함한다.

## 검증

국가 보물 하한/등급, 면적·역사별 단조 증가, 도시 unique/등급, 결정성, 모든 9성향/신격 등급, 총본산 참조, 편집 보존, 구형 파일 보완, 잘못된 입력 거부, FPB 왕복, UI 상호작용, 지도 SVG 표식 및 XSS 방어를 단위 테스트한다. 실제 화면 검증과 자동 Playwright 테스트는 별도로 구분한다.
