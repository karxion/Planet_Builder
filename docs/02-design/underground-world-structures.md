# 지저 세계 구조 선택과 지상 반전 지형

## 확인한 요구

사용자는 지하 공동 세계와 대륙 규모 땅굴 세계를 구분하고 둘 중 원하는 구조로 생성할 수 있도록 요청했다. 반전 방식은 질문에 답변한 다음 해석을 사용한다.

- 공동 세계형: 지상의 육지·산지를 내부의 내해·저지대로, 바다·분지를 내부의 육지·고지대로 바꾼다.
- 터널형: 반전된 저지대를 따라 공동과 통로가 발달한다.

지상 x/y를 좌우로 뒤집지 않는다. 모든 공간의 좌표는 공유하고 높낮이와 공동 세계의 육해 관계를 바꾼다. 실제 지질/행성 물리 모델이 아닌 사용자가 선택한 판타지 지형 설계다.

## 사용법

**지저 지도 → 공간 편집 → 지형·구조 → 지저 세계 구조**에서 선택하고 생성한다. 구조 선택만으로 저장된 지도는 바뀌지 않는다. 다시 생성할 때 확인을 받고 지형·자동 장소/연결을 교체한다.

| 항목 | 거대 터널형 | 공동 세계형 |
| --- | --- | --- |
| 모티프 | 언더다크형 대륙 규모 공동·터널 | 아가르타형 넓은 내부 공간 |
| 화면 구조 | 얕은 지저/중층/심층 | 연속된 내부 세계 한 화면 |
| 지형 | 암반·공동·좁은 통로·호수·용암 | 내부 대륙·내해·평원·산지·숲 |
| 지상 반영 | 지상 산지에 대응하는 반전 저지대에 공동 배치 확률이 높고 통로 비용이 낮음 | 지상 육지/산지는 내해, 바다는 육지/고지대 |
| 연결 | 낮은 반전 지형을 우선하는 터널 | 육지를 선호하는 육로, 필요한 구간은 내해 항로 |
| 편집 | 기존 지형 붓과 깊이별 장소 | 평원·산지·숲·내해 붓과 장소/영역 |

공동 세계 생성 거주지는 내부 육지에 놓는다. 새 도시 배치/이동도 육지를 확인한다. 지상 출입구는 원래 도시 좌표를 유지하며, 반전된 내부 쪽 출구가 바다라면 **내해 관문**으로 표시한다. 관문은 도시와 구분하며 통행 방법·압력·호흡 규칙을 자동 판정하지 않는다.

## 반전과 경로

현재 지상 높이를 128×80으로 표본화한다. 바다 높이 `h < 20`은 내부 양의 고도 `(20-h)/20 × 3000m`로, 지상 높이 `h ≥ 20`은 음의 고도 `-(h-20)/80 × 5000m`로 바꾼다. 경계값 h=20은 -1m로 처리해 육해 반전이 일관되게 유지된다. 값은 내부 해수면 기준 고도이며 외부 지표에서 아래로 잰 깊이와 별개다.

터널형은 이 고도를 기반으로 공동 후보를 가중 선택하고, 반전 고도가 낮은 셀의 비용을 낮춰 A* 경로를 판다. 기존 파일이나 테스트에서 지상 표본 없이 터널을 생성할 때는 이전 독립 생성 방식을 지원하지만 실제 UI 생성은 현재 지상 표본을 제공한다.

공동 세계형은 고도로 내해/평원/산지를 구분하고 숲을 더한다. 길을 만들기 위해 내해를 땅으로 메우지 않는다. 육지 비용을 낮추고 바다 비용을 높인 경로를 저장하여, 바다를 지나는 연결은 항로로 표시한다. 지형 붓은 내부 고도도 함께 갱신하며 초기 반전 결과를 수동으로 수정할 수 있다.

## 저장·기존 기록

`UndergroundMap`의 선택 필드 `mode`(`tunnels`/`hollow`), `surfaceInverted` 및 층별 `elevations`를 저장한다. 모드가 없는 기존 파일은 3층 터널형으로 읽고 데이터를 다시 만들지 않는다. 공동 세계는 `upper` 슬롯 하나에 저장하며, 깊이에 상관없이 모든 지저 수동 장소를 한 화면에 보여 준다. 존재하지 않는 층으로 전환하지 않도록 출입구 이동과 편집도 이 규칙을 따른다.

공동 세계 장소의 기본 깊이 40000m는 편집 가능한 추상적 기준값이다. 지도는 내부 지형의 2D 도해이며 구형 내부 표면, 중앙 광원·행성 반경/껍질 두께·중력·기후 물리 계산을 구현한 것은 아니다.

수동/직접 수정한/초안 작성 중인 장소와 세력 메모는 구조를 바꿔 재생성해도 유지한다. 기존 장소가 새 내해나 암반 위치에 남을 수 있으므로 사용자가 위치를 조정한다. 수동 연결은 끝 장소가 모두 남으면 유지한다. 자동 생성은 초기 지형 위 경로를 만들며, 이후 지형 붓이나 장소 이동으로 경로를 바꾸면 자동 재계산하지 않는다. FPB/복구/Drive는 기존 공통 코덱을 사용하고 PNG/SVG 출력은 최대 3000px다.
