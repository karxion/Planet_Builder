# 던전 내부 지도 설계

## 범위와 데이터

- 지도 표식 클릭 및 던전 위치 목록의 지도 버튼으로 내부 지도를 연다. 일반 표식은 기존 편집 동작을 유지한다.
- `Marker.interior?: DungeonInterior`에 v1 시드, 재생성 횟수, 테마·대표 몬스터, 난이도·목표 CR, 바닥 문자열, 방·문·배치를 저장한다.
- 기존 `.map`의 35번 행에 있는 표식 JSON을 그대로 사용한다. `.fpb`의 mapPayload와 자동 저장에도 포함된다. 기존 파일은 필드가 없어도 정상 동작한다.
- 내부 지도를 생성한 거점은 잠가 거점 재생성으로 제거되지 않게 한다. 직접 내부 재생성은 확인 후 실행한다.
- 수동·레거시 던전의 첫 기본값은 고블린 거점 / CR 1/4이며, 창에서 테마·대표 몬스터를 변경할 수 있다. 원본 자동 거점은 자신의 테마·CR을 사용한다.

## 생성 알고리즘

1. 사용자 승인으로 추가한 rot-js 2.2.1(BSD-3-Clause)의 Digger를 사용한다. RNG 시드와 상태를 try/finally로 복구한다. `Math.random`이나 행성 생성 난수에는 영향을 주지 않는다.
2. 세계 시드·표식 ID·셀 ID·재생성 횟수로 내부 시드를 고정한다. CR에 따라 58~76 × 42~54 격자를 사용한다. 한 칸은 5ft, 방 크기는 5~9 × 5~7칸이다.
3. 시간 제한 대신 유한한 벽 후보 탐색으로 종료해 시드 결과가 기기 속도에 좌우되지 않게 한다. 최소 8개 방을 확보하지 못하면 최대 8회 재시도한다.
4. BFS로 모든 바닥이 연결됐는지 검증한다. 첫 방을 안전한 입구로, 입구에서 가장 먼 방을 보스 방으로 선택한다.
5. 보스·입구를 제외한 후보를 비밀방으로 시험한다. 방과 문을 감춘 상태에서도 나머지 모든 방에 도달할 때만 채택한다(최대 2개).
6. 입구에는 적·함정·보상을 배치하지 않는다. 모든 배치물은 방 안의 서로 다른 타일을 사용하며 방 번호 위치는 피한다. 한 몬스터 표식은 한 개체가 아니라 표시된 수의 무리를 나타낸다.
7. 경비는 같은 테마의 상대적으로 낮은 CR 레퍼런스를 우선한다. 하위 CR이 없으면 가장 낮은 원본을 사용한다. 각 방의 전투는 별개이며 던전 전체 XP를 단일 조우로 취급하지 않는다.
8. 보스 방과 비밀방에 보상 상자를 배치한다. 목표 CR에 따라 uncommon/rare/veryRare/legendary의 동일 판본 SRD 아이템과 하위형을 선택하고 원본 규칙 링크를 제공한다. 금화·희귀도 배분은 앱의 창작 규칙이다.

## 난이도 계약

| 설정 | 목표와 변화 |
| --- | --- |
| 일반 | 대표 몬스터 원본 CR, HP·피해 배율 1, 함정 1개 |
| 도전적 | 시드로 +1 또는 +2 정수 CR 선택, 함정 2개, 공격 예고·HP 50% 이후 전술·유형별 대응 |
| 헬조선 | 도전적과 같은 목표 CR, 최대 7개 함정, 경보·수호 수정·위험 지대, 3라운드 보스 주기 |

- 분수 CR의 상향 대상은 정수 CR 1 또는 2다. CR 30을 넘지 않으며 상한을 화면에 표시한다.
- 보스 HP·평균 피해 배율은 `round(sqrt(XP(targetCR) / XP(sourceCR)) * 100) / 100`이다. 계산값을 GM이 원본에 적용한다. 스탯 블록 자체를 복제하거나 추가 공격·행동·주문·면역·전설 행동을 자동 부여하지 않는다.
- 이는 **창작 정예 템플릿의 목표 CR**이지, 공식 검증 CR 또는 파티별 조우 등급이 아니다. 파티 인원·레벨·장비·휴식·원본 특수 능력에 따른 검토가 필요하다. 공식 몬스터 CR은 별도로 유지한다.
- 함정은 징후·발동·내성·피해·발견/해제/우회 방법을 제공한다. 구덩이는 고정 10ft 추락, 다른 함정은 CR 기반 d6 피해다. DC는 10~22로 제한한다.
- 헬조선 보스 방에는 수호 수정과 산성 위험 지대를 실제 배치한다. 경보는 새로운 적을 무한 생성하지 않고 기존 경비 이동만 지시한다.
- 보스 유형 14종별 전술은 원본 능력이 있을 때만 사용한다. 추가 라운드 주기는 수정·밸브 해제와 안전 타일 이동으로 대응할 수 있다. 자동 전투 실행기는 아니다.

## UI와 보존

- 방 번호·몬스터·보스·함정·상자·수정·문·비밀방을 SVG로 표시한다. 클릭·키보드·방 선택 메뉴로 상세 정보를 연다.
- 확대 1~4배와 화면 맞춤을 지원하며 방 선택 후 스크롤 위치를 유지한다. 좁은 화면은 상세를 지도 아래로 배치한다.
- GM 보기는 모든 배치를 표시한다. 플레이어 보기는 비밀방 바닥·문·선택 메뉴·보스 이름·적·함정·상자를 제외한다. 현재 보기 SVG 출력에도 같은 숨김 규칙을 적용한다. 이것은 탐험 중 자동 시야/Fog of War 기능은 아니다.
- 난이도 변경은 지형을 유지하되 전투·함정·보상을 재결정한다. 내부 재생성은 지형까지 변경한다.
- 로드 시 크기·정수 범위·바닥 연결성·방 중첩·필수 동선·배치물 중복·원본 ID·보정값·아이템 하위형을 검증한다. 손상된 내부 지도만 제거하고 세계 표식·거점 메타데이터는 유지한다.
- 생성 실패는 기존 내부 지도를 변경하지 않는다. `.fpb` 압축 왕복 후 내부 데이터 보존을 단위 테스트한다.

## 검증과 남은 범위

- 17개 테마 × 복수 시드의 연결성·비밀방·도달 가능성, 난수 복구, 세 난이도 관계, 중복 없는 배치, 잘못된 파일 및 FPB 왕복을 검사한다.
- jsdom으로 실제 레거시 클릭 디스패처, 일반 표식 편집 유지, 난이도·방·GM 보기·재생성 실패 흐름을 검증한다.
- 이 작업에서는 브라우저 접근 제한 때문에 실제 화면 검증을 수행하지 못했다. 저장소 지침에 따라 Playwright E2E는 자동 실행하지 않는다.
- 후속: 파티 기반 XP 예산, 전체 SRD 몬스터 레퍼런스, 대형 몬스터 통로 폭·실제 전투 토큰, 가구/엄폐물·다층 던전·수동 방 편집, 플레이어별 탐험 공개 상태.
