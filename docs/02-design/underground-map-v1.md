# 지저 지역지도 1차 구현

두 가지 세계 구조 선택과 지상 반전 지형은 후속 [지저 세계 구조](./underground-world-structures.md)에 추가되었다. 아래는 최초 터널형 구현 기록이다.

## 사용 방법

1. 상단 **지저 지도 → 공간 편집 → 지형·층**에서 시드와 공동 밀도(낮음/보통/높음)를 선택하고 **지저 지도 생성**을 누른다.
2. 얕은 지저(0~749m), 중층(750~2499m), 심층(2500~100000m)을 전환한다. 생성 장소의 기본 깊이는 각각 300/1500/4000m다. 깊이는 현지 지표면 아래 거리이며 현실 지질 시뮬레이션이 아니다.
3. 공동과 터널은 밝은 자색, 암반은 어두운 자색, 물은 파랑, 용암은 주황이다. 세력권은 공동 바닥에만 반투명 색과 점선 경계로 표시한다. 배경의 옅은 육지 형태는 지상 위치 참고용이다.
4. **장소** 탭에서 도시·공동 이름, 주민·인구·소속 세력·메모를 편집한다. 새 장소는 현재 깊이에 배치된다. 깊이를 다른 층 범위로 바꾸면 그 층으로 전환한다. 장소/영역 표기는 기록이며 실제 공동 모양은 **지형 붓**으로 바꾼다.
5. 지형 붓에서 공동·암반·호수·용암과 반경을 선택하고 지도를 클릭해 칠한다. 클릭마다 적용하며 Esc로 종료한다. 사용자가 지형을 바꾸면 기존 이동로를 끊거나 거주지를 물/암반 위에 둘 수도 있다. 자동 연결 보장은 생성 직후의 건조 이동로에 한정한다.
6. 마름모 옆 화살표를 클릭·키보드 선택하면 연결된 지상/다른 지저 층으로 이동한다. 지상 입구는 현재 지상 도시 중 분산된 최대 4곳에 만들며, 층간 통로는 각 인접 층을 잇는다. 깊이를 바꿔도 지도 범위와 좌표 체계는 공유한다.
7. **지형·층**의 SVG/PNG 내보내기는 현재 층 전체를 출력한다. PNG/SVG의 긴 변은 3000px 이내다. FPB 저장/Drive에는 세 층을 모두 저장한다. 레거시 `.map`만으로는 지저 기록을 보존할 수 없다.

## 생성과 편집 보존

- 생성기는 `src/generators/underground.ts`의 순수 함수다. 시드·공동 수(12/24/36)와 지상 입구 후보 및 보존할 수동 데이터가 같으면 같은 결과가 나온다. 각 층은 128×80 분류 격자를 사용한다.
- 불규칙한 공동과 물/용암 영역을 만든 뒤 최소 신장 트리와 우회 터널로 연결한다. 거주지·입구까지 건조 통로를 판다. 지상 Burg/State/Campaign/NPC를 변경하지 않으며, 새 규칙 데이터도 추가하지 않는다.
- 수동 장소 및 직접 편집한 생성 장소는 지저 재생성에서 유지한다. 적용 전 장소 초안이 있는 생성 장소도 보존한다. 기존 세력의 이름·색·메모는 덮어쓰지 않는다. 보존된 장소에도 공동과 통로를 연결한다.
- 지저 **다시 생성**은 생성 지형과 미편집 자동 장소·자동 통로를 교체한다. 지형 붓 작업은 초기화하므로 화면에서 확인을 받는다. 사용자가 만든 연결은 양 끝 장소가 모두 남아 있을 때 보존한다. 자동 장소 삭제나 이동 기록은 별도 억제 목록으로 기억하지 않으며 재생성 시 기본 도시/입구가 다시 생길 수 있다.
- 지상의 **새 지도**는 기존 추가 공간 전체를 유지한다. 새로운 지상 도시와 기존 지저 출입구는 자동 동기화하지 않으며, 지저 다시 생성 또는 수동 편집으로 맞춘다.

## 저장과 검증

기존 `WorldSpacesData.version: 1`에 선택 필드 `underground`를 추가한다. 지저 자동 생성 전 파일에는 이 필드가 없으며, 기존 수동 지저 장소도 그대로 불러온다. 필드가 있는 경우 `activeLevel`에 맞는 장소만 표시한다. 모델은 세 층의 고유 ID, 격자 크기/길이/셀 분류, 시드·세대·밀도를 검증하고 잘못된 저장 데이터를 거부한다.

`PlanetProject.worldSpaces`를 그대로 사용하는 FPB 압축 파일, 로컬 복구, Drive 사본에 지형이 포함된다. 렌더러가 격자의 경계선을 계산해 그리며 무작위 데이터를 새로 만들지 않는다. 지상 SVG payload에 추가 공간 렌더링을 넣지 않아 중복 저장을 방지한다.

## 현재 범위

지저 지역의 연결 관계와 위치를 편집하는 지도다. 공동 내부 전투지도, 지저 도시 조감도 자동 배치, 경사/고도 기반 이동 비용, 지질·수문 시뮬레이션, NPC·전투 조우 자동 생성은 포함하지 않는다. 영역 색은 수동 표기이며 별도 국가 셀 점유 시뮬레이션이 아니다.
