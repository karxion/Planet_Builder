# 조감도 에셋과 전투지도 크기

## 크기 기준

| 프리셋 | 가로×세로 칸 | 일반 이동 | 전력 질주 |
|---|---|---|---|
| 소형 | 25×14 | 4턴 | 2턴 |
| 중형 | 48×27 | 8턴 | 4턴 |
| 대형 | 72×41 | 12턴 | 6턴 |

기본 비율 16:9에서 가장 가까운 정수 세로 칸 수를 사용하므로 소형/대형은 약 16:9다. 한 칸은 정사각형 5ft다. 표의 이동은 이동속도 30ft, 첫 칸 중심부터 마지막 칸 중심까지 장애물 없는 직선 이동을 가정한다. 이동 거리는 `(가로 칸 수 - 1) × 5ft`, 일반 이동은 거리/30ft 올림, 전력 질주는 거리/60ft 올림이다. 실제 도로/방/엄폐물·지형·이동속도 차이에 따른 경로 탐색은 아니다.

## 수동 조절

- 가로·세로 8~256칸. 72칸보다 큰 전장도 수동으로 설정한다.
- 16:9 / 4:3 / 1:1 비율 또는 자유 비율. 세로 칸을 직접 수정하면 자유 비율로 전환한다. 세로가 긴 지도도 허용한다.
- 한 칸 출력 해상도 16~128px(기본 64px)는 지도 범위/이동 거리와 별개다. 예: 96×54칸, 48px/칸 → 4608×2592px.
- PNG 출력은 한 변 최대 **5460px**, 총 약 **1490만 픽셀**로 제한한다. 큰 설정은 칸 수·지도 비율을 유지하면서 PNG 출력 해상도만 자동으로 낮춘다. 현재 예상 PNG 크기를 설정 창에 표시한다.
- 기존 프로젝트와 SVG 설정은 한 변 8192px·총 32Mpx 범위를 계속 읽고 저장한다. 이 설정 범위를 넘으면 적용하지 않고 안내한다. 개별 PNG 에셋 파일과 지도 칸 수·이동 거리는 PNG 출력 축소의 영향을 받지 않는다.
- 값 변경 후 **크기 적용**을 눌러 확정한다. 잘못된 설정은 기존 지도에 반영되지 않는다.

도시 전투지도는 선택 구역(시장/주거지/성문)의 중심을 기준으로 표시 범위를 바꾼다. 건물·거리 자체를 늘이거나 줄이지 않고, 격자 시작점도 완전한 칸에 맞춘다. 넓은 범위가 원래 도시 경계 밖으로 나가면 배경 지형이 표시되며 다른 도시나 외부 세계를 자동 생성하지 않는다.

던전은 기존 전체도와 **방 전투지도**를 구분한다. 방 전투지도는 선택한 방의 중심에서 설정한 칸 수만큼 보여 주며, 기존 던전의 생성 크기·방·통로·보상 배치를 변경하지 않는다. 플레이어 보기의 비밀방/몬스터/함정/보상 비공개 처리를 동일하게 적용한다. SVG 출력도 선택 방, 설정 크기 및 현재 GM/플레이어 보기를 따른다.

도시 설정은 `burg.settlement.battleMap`, 던전 설정은 `marker.interior.battleMap`에 저장한다. 따라서 FPB와 기존 Drive 저장·복구가 동일한 값을 보존한다. 설정이 없는 기존 파일은 소형 설정으로 열며, 난이도 변경/던전 재생성에서도 설정은 유지한다.

## 이미지 생성 기반 조립 에셋

이미지 생성 도구로 건물·성채 건물·성벽 구간·성문·우물·축사·포장 타일·나무의 **8종 PNG 모듈**을 각각 생성했다. 완성된 도시 배경 이미지를 한 장 넣는 방식이 아니다. 각 파일은 같은 부품의 왼쪽 조감도와 오른쪽 탑다운 시점을 담는다. 렌더러는 각 절반을 별도 viewport로 선택하므로 원본 PNG를 편집·변형하지 않고 재사용한다.

도시 건물의 배치점·구획에 건물/성채/축사 모듈을 놓고, 성벽 구간을 연결하고 성문을 배치한다. 우물·포장 타일·나무도 독립 부품으로 배치한다. 전투지도에서는 같은 위치에 탑다운 모듈을 사용한다. 그림의 문·가구·울타리는 시각적 정보이며 자동 충돌/통행 가능 칸 계산을 제공하는 것은 아니다. 조감도의 입체 표현은 수학적으로 정확한 3D 건축 모델이 아니다.

- 원본 이미지: `public/assets/scene-maps/{house,keep,wall,gate,well,barn,paving,tree}.png`
- 이미지 크기·SHA-256: `src/data/scene-image-manifest.json`
- 시점 선택·배치·내보내기: `src/renderers/scene-assets.ts`

도시 지도 창에서 각 PNG를 내려받을 수 있다. 에셋은 SVG로 그린 대체 그림이 아닌 실제 생성된 래스터 이미지다. SVG 지도 출력에서는 PNG 원본 바이트를 내부에 포함하고 PNG 지도 출력에서는 해당 부품을 합성한다. 서버 경로가 끊겨도 이미 내보낸 지도는 독립적으로 열린다. 새 지도 출력 시 로컬 이미지가 없거나 손상됐으면 오류로 알리며 깨진 경로를 저장하지 않는다.

지도 위의 개별 소품 수동 배치/회전 편집기는 이번 범위에 포함하지 않는다. AI 이미지 요청문은 조감도와 전투지도 시점·칸 수를 구분하며, 외부 AI 서비스로 사용자 메모를 자동 전송하지 않는다.
