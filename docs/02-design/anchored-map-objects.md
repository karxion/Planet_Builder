# 소재지에 고정된 지상 오브젝트

겹침 회피용 빈자리 검색과 지상/국경 제한 없는 fallback 때문에 오브젝트와 도시 표식이 실제 소재지에서 멀리 이동했다. 지도 가독성은 좌표 이동 대신 표시 크기와 같은 소재지의 목록화로 해결한다.

- 지상 도시·장소·자원은 저장한 좌표에서 이동시키지 않는다. 구형 `data-fpb-individual-transform`, `data-fpb-resource-transform`의 표시용 변환은 원래 변환으로 복원하며 긴 연결선을 제거한다. 같은 이름인 다른 도시를 묶어 숨기지 않는다. 중복 SVG 인스턴스만 숨긴다.
- 장소 마커가 기록한 셀의 실제 도시 좌표와 일치할 때 도시 하단 배지로 표시한다(부동소수/반올림 허용 범위 0.5 지도 단위). 같은 셀이라도 직접 다른 좌표에 배치한 장소는 독립 장소로 보존한다. 다른 도시나 가까운 도시로 옮겨 묶지 않는다.
- 독립 장소는 실제 좌표 중심의 작은 아이콘으로 표시한다. 정확히 같은 좌표의 여러 장소만 개수 배지로 묶는다. 도시 소재지도 복수일 때만 개수를 표시하고 단일 오브젝트는 아이콘만 표시한다. 확대·이동 시 실제 앵커는 고정하며 표식의 화면 크기만 유지한다.
- 클릭/탭 또는 Enter/Space는 소재 도시·전체 이름·원본 에셋 미리보기 목록을 연다. 상세·편집은 기존 마커 편집기로 연결해 이름·노트·이미지·수동 위치를 계속 편집한다. 닫기·Escape·키보드 초점·모바일 폭을 지원한다.
- 이 UI는 지상 장소 마커의 표시 계층이다. 지저/해저 전용 레이어 및 총본산 UI와 분리한다. 마커 숨김/고정 표시 설정을 존중하고 편집 중에는 기존 원본 표식을 사용한다. 새로운 장소·소유 관계·경제 규칙을 생성하지 않는다.
- FPB/MAP 저장용 SVG 복제본에서는 배지와 숨김 속성 및 구형 표시용 변환을 제거해 실제 위치의 원본을 보존한다. 전체 지도/라벨 제외 내보내기도 같은 처리를 사용한다. 현재 화면 내보내기는 표시 중인 배지를 보존한다. 저장 데이터의 마커·도시·노트·이력·복구는 변경하지 않는다.
