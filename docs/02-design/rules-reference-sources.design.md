# 캐릭터·아이템·주문 참고 출처

작성일 및 링크 확인일: 2026-10-18

## 사용자 지정 출처

캐릭터 메이킹, 직업·하위직업, 종족·배경, 특기, 일반 장비·마법 아이템, 주문을 조사할 때 [D&D 5e Wikidot](https://dnd5e.wikidot.com/)를 참고 색인으로 사용한다. 이 사이트가 별도로 안내하는 [2024 Wikidot](https://dnd2024.wikidot.com/)는 2024 자료용으로 분리한다.

두 사이트는 커뮤니티 자료이며 UA, 홈브루, 특정 세계관·출판물의 선택지가 함께 있을 수 있다. 페이지 존재 또는 Published 분류만으로 배포 권한이나 모든 캠페인의 호환성을 보증하지 않는다. 판본, 원래 출판물, 개정 여부를 따로 확인한다.

## 적용 원칙

1. Wikidot에서 자료를 찾고 원출판물과 공식 문서로 규칙·판본을 확인한다. 항목별 source URL과 검증일을 기록한다.
2. 판본은 2014/2024를 분리하며 같은 이름의 옵션을 덮어쓰지 않는다. 2014 서브클래스·특기·종족을 2024에 암묵적으로 섞지 않는다.
3. UA·홈브루·출처 불명 자료는 기본 생성에서 제외한다. 특정 세계관의 옵션은 해당 캠페인의 채택 여부를 별도로 확인한다.
4. 배포되는 전체 설명·번역은 이용 범위를 확인한다. 위키에 공개되어 있거나 이용약관에 기여물 라이선스가 있어도 제삼자의 상용 원문 전체를 자유 배포할 수 있다고 가정하지 않는다.
5. 현재 번들 데이터의 전체 아이템 원문과 SRD NPC 블록은 고정된 공식 CC BY 4.0 SRD를 유지한다. 공식 SRD의 라이선스·범위는 [공식 안내](https://www.dndbeyond.com/srd), 위키 이용약관은 [해당 사이트](https://dnd5e.wikidot.com/legal:terms-of-use)를 참고한다.

## 이번에 반영한 기능

- `src/data/rules-references.ts`에 판본별 외부 경로를 중앙 관리한다. NPC의 기존 12개 직업 페이지는 양 판본에서 확인한 경로를 사용한다.
- NPC 상세에 선택한 직업, 종족, 배경·특기 목차, 주문, 일반 장비, 마법 아이템의 외부 참고를 추가한다. 비모험가는 가짜 직업 페이지를 만들지 않는다.
- 보물 상세에는 마법 아이템·일반 장비·주문 색인을 연결하고 선택한 SRD 원본의 판본에 맞춰 외부 링크를 갱신한다.
- 외부 참고 판본 선택은 탐색용이다. NPC 수치·클래스·보물 효과·프로젝트 판본을 바꾸거나 저장하지 않는다. 2014의 배경·특기는 검증된 홈페이지 목차로 연결하며 없는 별도 URL을 추측하지 않는다.
- 외부 페이지는 새 탭에서 열며 `noopener noreferrer`를 사용한다. 앱 로딩이나 생성 시 위키를 자동 요청하거나 iframe·스크래핑으로 내용을 삽입하지 않는다.

## 데이터 확장 시 계약

전체 데이터 확장은 이번 참고 출처 등록과 별개의 구현이다. 각 레코드에는 안정적인 ID, 종류(class/subclass/species/background/feat/item/spell), 판본, 원출판물, 상태(published/UA/homebrew/unknown), 참고 URL, 검증일과 배포 가능한 필드 범위를 둔다. 링크만 검증된 레코드는 자동 생성 가능한 규칙 데이터로 취급하지 않는다.

캐릭터 메이킹에는 능력치·종족·배경·클래스/서브클래스·숙련·레벨·특기 선행 조건의 검증이 필요하다. 주문 데이터에는 클래스 목록, 주문 레벨, 시전 시간, 집중·의식, 구성 요소, 슬롯/회복, 준비·습득 및 판본별 차이가 필요하다. 이런 데이터 모델과 엔진을 검증하기 전 현재 간이 NPC 프로필을 완전한 PC 생성기로 표시하지 않는다.

## 검증 범위

판본 도메인 분리, 지원 직업 경로, 비모험가/잘못된 키 처리, 외부 링크 보안 속성, 다국어 표기, 참고 판본 변경 시 저장 데이터 불변, 원본 판본과 보물 참고 경로의 동기화를 단위·jsdom 테스트한다. 실제 사이트의 향후 변경은 로컬 테스트만으로 보증하지 않는다.
