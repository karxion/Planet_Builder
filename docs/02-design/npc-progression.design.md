# NPC 성장 및 국가 성향

작성일: 2026-10-18

## 규칙과 제품 정책

사용자가 정정한 앱 전용 티어 기준을 적용한다. 이는 공식 D&D 티어 구분이나 NPC 배치 규칙이 아닌 이 앱의 세계관 정책이다. NPC CR과 캐릭터 레벨은 환산하지 않는다.

| 분류 | 레벨 | 기본 생성 범위 |
|---|---|---|
| 1티어 | 1~4 | 마을 |
| 2티어 | 5~8 | 도시 주요 인물 |
| 3티어 | 9~12 | 국가 핵심 인재 |
| 4티어 | 13~16 | 대륙 대표 인물 |
| 5티어 | 17~20 | 수동 지정 |
| 에픽 | 21 이상 | 수동 지정 |

- 평민은 도시에서도 비모험가다. 내부 호환용 level=1을 유지하되 화면에는 레벨/티어 대신 CR을 표시한다. 기본 커머너 CR 0과 앱 변형 CR 1/8, 1/4, 1/2를 지원한다. 일반 경비병과 길잡이는 1티어에 머문다.
- 기존 정착지 토큰의 도시 판정(수도 또는 population > 5)과 같은 기준을 사용한다. 작은 정착지의 주요 인물은 최대 4레벨, 도시 귀족·전문가는 5~8레벨이다.
- 국가마다 수도에 9~12레벨 핵심 귀족과 전문가를 추가한다. 무소속 정착지에는 국가 인재를 추가하지 않는다.
- FMG가 `continent`로 분류한 육지마다 가장 큰 도시 한 곳에 13~16레벨 대표 인물 한 명을 배치한다. 동률이면 정착지 ID로 결정한다. 대륙은 활동 범위일 뿐 새 지도 행정 분류가 아니다.
- 5티어와 에픽은 자동 생성·재생성하지 않는다. 사용자가 NPC 상세에서 직접 레벨을 지정한다.
- 국가 성향은 균형·군사·마법·신정·자연·상업이다. 초기값은 정부 이름의 명시적 키워드에서 추론하며 사용자가 변경할 수 있다. 별도의 종교·문화 데이터는 추가하지 않는다.
- 성향별 직업 가중치와 귀족/전문가 역할로 직업을 선택한다. 기사는 직책이며 실제 클래스는 전사 또는 팔라딘이다. 모두 같은 직업이 되지 않도록 다른 직업의 확률도 남긴다.

## 저장 및 호환성

기존 CampaignWorld v1을 유지하고 선택적 `npcProfiles`, `npcGenerationVersion`, NPC `progression`을 추가한다. 옛 파일은 유효하며, 불러온 뒤 기존 NPC의 이름·서사·메모·수정 여부를 보존하면서 성장 정보를 채운다. 국가/대륙 주요 NPC는 최초 보완 시에만 추가하여 삭제한 NPC가 매번 되살아나지 않게 한다.

티어는 레벨에서 계산하며 별도로 저장하지 않는다. 이번 기준 변경만으로 기존 NPC의 레벨·이름·메모를 재추첨하지 않는다. 예를 들어 기존 10레벨은 3티어, 기존 17레벨은 5티어로 표시한다. 신규 생성 또는 명시적 재생성은 새 범위를 따른다. 수동 편집한 NPC는 기존 보존 정책을 유지한다.

레벨은 1 이상의 안전한 정수이며 21 이상의 에픽 레벨도 `.fpb`에 저장한다. 소수·음수·무한대·안전한 정수 범위 초과는 거부한다. 비모험가는 기존 호환용 level=1과 별도 CR을 유지한다. JSON 내보내기는 `tierScheme.id = fpb-five-tier-v1`, 티어 범위·에픽 시작점과 NPC별 `narrativeTier`를 포함해 SRD 기본 스탯과 구분한다.

시드는 NPC ID와 별도 성장 난수 스트림을 사용한다. 정착지 추가와 입력 순서 변경이 기존 개별 NPC의 이름·성장 결과에 영향을 주지 않는다. 대륙 대표의 거주지는 도시 규모 변경 시 달라질 수 있으므로 기존 생성 결과는 자동 이동시키지 않고 재생성 시 반영한다.

## UI와 전투 수치

세계·NPC의 국가 선택 아래 성향 선택기를 둔다. 선택 시 해당 국가의 자동 생성 NPC 직업/직책만 재계산하고 직접 편집한 NPC는 보존한다. 상세에서 직업·레벨·지위·활동 범위를 편집할 수 있고 목록 및 JSON 내보내기에 반영한다.

레벨 기반 간이 프로필은 클래스 히트 다이스, 고정 HP 증가, 숙련 보너스 및 기본 능력치로 HP·AC·명중·주문 DC를 산출한다. 이는 공식 NPC 스탯 블록이나 완성된 PC 시트가 아니다. 주문 목록, 서브클래스, 특기, 장비 선택과 완전한 액션 경제는 구현하지 않는다. UI와 내보내기에서 간이 프로필과 SRD 기본 참고 능력치를 구분한다.

간이 전투 수치는 20레벨까지만 계산한다. 에픽은 서사 레벨만 기록하고 HP·명중·숙련·주문 DC를 임의로 외삽하지 않는다. 화면에는 에픽 안내와 접힌 SRD 기본 참고 능력치(레벨 미반영)를 제공하며, 내보내기에도 허구의 에픽 전투 프로필을 넣지 않는다.

## 검증

### 커머너 세분화 (2026-10-18 추가)

[공식 2024 커머너](https://www.dndbeyond.com/sources/dnd/br-2024/creature-stat-blocks/#Commoner)는 CR 0이다. 분수 값은 캐릭터 레벨이 아닌 CR이며, 이 앱의 1/8·1/4·1/2 커머너는 공식 스탯 블록이 아닌 간이 변형이다. 지정 CR은 추정치이고 전투 균형의 공식 인증을 의미하지 않는다.

`progression.commonerCr`는 선택적 문자열이며 비모험가에게만 허용한다. 신규 자동 생성 분포는 CR 0: 70%, 1/8: 20%, 1/4: 8%, 1/2: 2%다. NPC ID에 독립적으로 시드되어 국가 성향 변경이나 다른 NPC 추가의 영향을 받지 않는다. 이전 자동 생성 비모험가는 같은 방식으로 보완하며, 직접 수정한 이전 NPC는 CR 0으로 보완한다. 이름·서사·메모는 변경하지 않는다. CR 수동 설정은 NPC 수정 상태로 저장한다.

커머너 변형은 등급별 HP·AC·명중·평균 근접 타격 피해를 제공한다. 기본 SRD 참고 능력치는 별도로 유지한다. 레벨과 CR을 환산하지 않는다. 기존 `statBlock` 내보내기는 유지하고 `combatProfile`에 실제 선택한 커머너 변형을 기록한다.

티어 경계, 평민 상한, 국가/대륙 인물 수, 성향별 직업 분포, 결정성, 편집 NPC 보존, 중복 없는 재생성, 구형 파일 보완, 런타임 검증, FPB 왕복을 단위 테스트한다. Playwright는 저장소 지침에 따라 자동 실행하지 않는다.
