# 2014/2024 아이템 레퍼런스 생성기

작성일: 2026-10-18

## 출처 범위

공식 CC BY 4.0 SRD 5.1과 SRD 5.2.1의 Magic Items A-Z 및 아티팩트 항목을 기준으로 항목 색인을 생성한다. 고정 PDF 기준으로 2014는 240개, 2024는 258개 항목·계열이며 동일 명칭도 판본별로 별개이다. 상용 규칙서/확장책 전체나 일반 장비·모든 물품의 데이터베이스라는 뜻은 아니다. 추가 자료는 제공받거나 적절한 배포 권한을 확보한 별도 데이터 소스로 추가해야 한다.

빌드 시 공식 PDF의 SHA-256을 검증하고, 양단 편집/폰트/텍스트 기준선을 사용해 항목 제목·장비 분류·희귀도·조율·원문·페이지를 추출한다. 2014와 2024의 동일 명칭은 별개 레코드로 유지한다. 개정판 명칭과 수치 차이를 합쳐 덮어쓰지 않는다. 라이선스와 원본 PDF 링크를 제품에 유지한다.

## 생성 정책

- 국가 보물/도시 상징품의 기존 희귀도 하한과 유니크/RP 정책은 유지한다.
- 판본은 2014, 2024, 혼합 중 선택한다. 혼합은 항목 수의 차이로 한 판본이 편향되지 않도록 먼저 판본을 선택한다.
- 선택된 희귀도에 정확히 맞는 원본을 국가 성향과 장비 분류 가중치로 고른다. 하위형이 많은 계열은 하위형 수로 가중치를 나눠 과도한 선택 편향을 피한다.
- 기본 생성은 한 원본의 핵심 규칙·조율·충전/재충전·행동 비용·저주·제약을 그대로 참고하는 리스킨이다. 새 이름, 유래, 외형, 국가/도시 상징성 및 RP만 덧입힌다. RP가 추가 전투 보너스를 자동 부여하지 않는다.
- 여러 원본이나 두 판본의 수치를 합산하지 않는다. 원본 효과 개요를 그대로 유지하면 외형·서사 창작, 효능을 직접 편집하면 참고 기반 창작으로 표시하여 공식 스탯과 구분한다.
- 희귀도가 가변인 가족은 하위형을 구분해야 한다. 추출/명시적 매핑으로 확인하지 못한 가족은 색인에는 포함하지만 자동 생성에서 제외한다. 임의로 강도를 올리거나 전체 가족의 모든 효과를 동시에 주지 않는다.

## 저장과 편집

RealmTreasure에 선택적 design(version, referenceId, edition, method, variant)을 추가한다. RealmHeritage에 선택적 itemReferenceEdition을 저장한다. 원문 전체는 공유 카탈로그에 두고 각 보물에는 출처 ID만 저장한다. 파일 검증은 출처, 판본과 희귀도의 일치를 확인한다.

기존 자동 생성 보물은 레퍼런스를 보완하면서 이름·상징성·RP·유래·메모를 유지한다. 직접 편집한 보물은 자동 변경하지 않는다. 상세에서 원본 선택과 원문/조율/출처 확인을 제공한다. 출처 없는 이전 창작품도 계속 읽고 저장할 수 있다.

새 보물의 이름은 선택된 분류(영약·반지·갑주 등)에 맞추고 RP는 성능과 독립된 전통·책임을 부여한다. 전체 판본 변경은 확인 후 저장되지 않은 상세 편집을 취소하며, 자동 생성 보물의 장비 분류는 유지한다. 직접 선택한 원본은 수동 편집으로 저장되므로 이후 자동 변경하지 않는다. 국가 보물은 베리 레어 이상, 도시 상징품은 레어 이상이라는 기존 하한을 유지한다. 낮은 희귀도와 아티팩트도 색인에는 있지만 현재 국가/도시 생성 범위에서 제외한다.

## 카탈로그 재생성

앱 실행과 일반 빌드는 생성된 TypeScript 색인을 사용하므로 PDF·Python·네트워크 연결이 필요 없다. 재생성에만 Python과 pdfplumber가 필요하다. 저장소 루트에서 공식 PDF를 각각 `tmp/item-catalog/srd51.pdf`, `tmp/item-catalog/srd521.pdf`에 준비하고 실행한다. PDF는 Git에서 제외한다.

- 2014: https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf
- 2024: https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf
- SHA-256은 `scripts/build-magic-item-catalog.ts`에 고정한다. 해시나 항목 수가 바뀌면 자동으로 수용하지 않고 실패시킨다.

```powershell
$env:FPB_PYTHON = "C:\path\to\python.exe"
node scripts/build-magic-item-catalog.ts
```
