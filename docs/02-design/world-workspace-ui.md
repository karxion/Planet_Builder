# 세계와 NPC 3영역 UI

Figma 승인 시안: https://www.figma.com/design/ieZzhJvWLAXHAU6ia3zTWU?node-id=2-41

- 왼쪽은 국가·지역·영지·마을 탐색 범위와 지도 표시, 위는 NPC·보물·종교 목차, 본문은 목록과 선택 항목의 상세다.
- 상세는 읽기 전용 요약으로 시작하며 편집 버튼으로 기존 폼에 진입한다. 적용은 기존 검증·초안·저장 경로를 사용한다. 취소는 해당 항목의 초안만 명시적으로 버린다. 다른 항목의 초안은 유지한다.
- 기존 초안이 있는 항목은 편집 상태로 복원한다. 이미지 업로드·규칙 참고·능력치·삭제·내보내기는 기존 기능을 유지한다.
- 국가 성향, 건국 경과, 자동 생성 판본은 세계 설정 패널에서 임시로 변경하고 설정 적용 시에만 원래 처리 경로를 호출한다. 취소/닫기/ESC는 임시 값을 버린다. 재생성·지명 한글화·티어 재분배는 별도 관리 작업이다.
- 작은 화면은 탐색 범위를 접고 목록과 상세 중 하나만 표시한다. 항목 선택, 목록 복귀, 카테고리 펼치기를 제공한다.
- 디자인의 예시 인물·교단을 앱 데이터에 추가하지 않는다. 기존 테마 변수와 아이콘/글꼴 체계를 사용하고, 새 런타임 의존성은 추가하지 않는다.

표시만 변경하며 FPB 데이터 모델, Drive 저장 구조, 생성 규칙은 변경하지 않는다.
