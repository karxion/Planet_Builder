# 해저 지형학 보완

2026-10-28 첨부 PDF 검수 후 주변부 폭·양쪽 주변부 협곡·확장 모티프별 열곡을 보완했다. 현재 생성 규칙은 **geologyVersion 3**이며 [자료별 검수 범위와 변경 근거](../04-report/subsurface-pdf-review-2026-10-28.md)를 따른다.

## 기준과 구현

사용자가 제공한 대륙 주변부/심해저 분류를 생성 규칙으로 반영했다. 아래 수치는 이 판타지 지도 생성기의 기본값이며 지구 전체에 적용되는 엄격한 지형 정의로 취급하지 않는다.

| 지형 | 생성 형태와 수심/기복 |
| --- | --- |
| 대륙붕 | 해안의 완만한 띠, 기본 수심 200m 이하. 수동형에서 더 넓게 생성. 현실의 깊이는 지역별로 다를 수 있다. |
| 대륙사면 | 대륙붕 끝에서 약 2600m까지 내려가는 경사면. 활동형에서 더 좁고 급하게 생성. |
| 대륙대 | 수동형 주변부의 사면 기슭에서 약 2600~4000m로 완만해지는 퇴적성 구역. |
| 해저 협곡 | 양쪽 주변부에 배치. 활동형은 더 짧고 촘촘하게 가지침. 하단에 퇴적성 선상지 배치. |
| 심해평원 | 기본 약 4400m, 낮은 기복. 일반적인 분류 범위 3000~6000m 안에 둔다. |
| 중앙해령 | 대양 내부의 넓은 해저 산맥. 주변 바닥 대비 약 2200~3200m 높이의 어깨를 생성. |
| 해령 열곡 | 느린 확장 모티프는 넓고 약 650m, 빠른 모티프는 좁고 약 160m 패인 축부. 모든 실제 해령에 같은 열곡이 있는 것은 아니다. |
| 해구·해연 | 활동성 주변부를 따라 좁은 해구(약 6700~8000m)를 두고 일부에 더 깊은 함몰부(약 10000~10900m)를 둔다. |
| 해산 | 심해평원에 고립된 원뿔형 지형. 주변 바닥 대비 1200~2800m 높이. |
| 평정해산 | 평평한 정상과 경사진 측면을 가진 해산. 평탄면은 격자에 실제 동일 수심으로 저장. |
| 해저 선상지 | 협곡 하단의 바다 방향으로 펼쳐지는 낮은 퇴적성 로브. |
| 심해 구릉 | 심해평원 일부에 수백 미터 기복의 구릉군. |
| 해양 단열대 | 해령 바깥 심해저까지 이어지는 낮은 선형 단층 지형. |

산호초는 기존 얕은 연안 군락을 유지한다. 육지와 함께 전체 범례는 16개 코드다. 해령/해산의 **높이**는 해수면 아래 **수심**과 구분해 `baseDepth - summitDepth = relief`로 저장한다.

현재 지상 해안선/표본 격자에 맞추어 형태를 합성한다. 실제 지구 수심을 가져오거나 퇴적물 이동·맨틀 대류·판 경계 진화를 계산하지 않는다. 활동성/수동형 주변부는 공간적으로 연속된 대용 규칙이며, 해양판-해양판 섭입 같은 모든 지질 환경을 재현하지 않는다. 작은 지형은 160×96 격자보다 상세하게 표현하지 못한다.

## 표시·저장

- 해저·세력 탭은 현재 지도에 존재하는 분류의 색 범례를 보여 준다. 접이식 분류 안내에서 정의를 읽을 수 있다.
- 주요 해산·평정해산·해령·협곡·해연은 점 표식과 툴팁을 제공한다. 거주지를 선택하면 해당 위치의 해저 분류와 바닥 수심을 확인한다.
- 기존 코드 0~6과 추가 코드 7~15를 유지한다. 새 지도는 `geologyVersion: 3`이며 버전 2도 저장된 상태로 읽는다. `features`에는 기복 및 선택적인 협곡 주변부/주축 셀 수/가지 수, 해령 확장 모티프가 있다.
- 기존 파일은 저장된 지형을 바꾸지 않고 읽는다. **해저·세력 다시 생성**할 때 새 규칙을 적용하며 수동 도시·수정한 세력·외교 관계 보존 동작은 유지한다.

## 웹 자료 확인 상태

2026-10-28 사용자가 제공한 **NOAA 해산 설명과 해양 지형학/해저 협곡 논문 소개 페이지 PDF**를 읽어 대조했다. [검수 결과와 출처 명세](../04-report/subsurface-pdf-review-2026-10-28.md)에 확인한 페이지와 구현 근거를 기록했다. 논문 소개 페이지에는 초록·서론·일부 절이 있으며, 논문 전문·전체 표/부록을 읽은 것으로 확대하지 않는다.

협곡·선상지와 활동형/수동형 차이는 첨부 PDF의 초록·서론을 대조했다. 2014년 소개 페이지에서 기저/기복 분류/개별 지형의 계층과 심해 구릉을 확인했으나 전체 29개 정의를 검수한 것은 아니다. **IHO 용어 표준 자체·USGS 자료·별도 NOAA 협곡 페이지는 미열람이며, 단열대 등의 상세 정의와 전체 방법 검수도 남아 있다.**

직전 웹 [재접속 기록](../04-report/reference-access-recheck-2026-10-28.md)은 당시 8개 주소가 403으로 실패한 증거로 유지한다. 이번 DOI·초록 내용은 Crossref 검색 성공이 아니라 사용자가 제공한 PDF에서 확인했다. NOAA 해산의 PDF 표시 주소는 `https://oceanexplorer.noaa.gov/ocean-fact/seamounts/`다.

시도 결과는 [수집 기록](../04-report/seabed-source-attempt.json)에 남겼다. `node scripts/collect-seabed-sources.ts <새 출력 폴더>`는 환경 프록시/접속 정책을 그대로 사용해 자료와 조회 시각·SHA-256·Crossref 메타데이터를 기록한다. 다운로드 HTML/원문은 로컬에만 두고 저장소에 재배포하지 않는다.

남은 웹 자료의 직접 열람은 현재 환경 접속 상태를 확인한 뒤 진행한다. 저장된 접근 허용 초안만으로 접속 권한이 바뀌지는 않는다. 이미 제공된 PDF의 검수에는 네트워크 설정 변경이 필요하지 않다.
