# 해저 지형학 보완

## 기준과 구현

사용자가 제공한 대륙 주변부/심해저 분류를 생성 규칙으로 반영했다. 아래 수치는 이 판타지 지도 생성기의 기본값이며 지구 전체에 적용되는 엄격한 지형 정의로 취급하지 않는다.

| 지형 | 생성 형태와 수심/기복 |
| --- | --- |
| 대륙붕 | 해안의 완만한 띠, 기본 수심 200m 이하. 현실 대륙붕의 깊이는 지역별로 다를 수 있다. |
| 대륙사면 | 대륙붕 끝에서 약 2600m까지 빠르게 내려가는 경사면. |
| 대륙대 | 수동형 주변부의 사면 기슭에서 약 2600~4000m로 완만해지는 퇴적성 구역. |
| 해저 협곡 | 사면을 바다 쪽으로 절개하며, 하단 바깥으로 퇴적성 선상지를 배치. |
| 심해평원 | 기본 약 4400m, 낮은 기복. 일반적인 분류 범위 3000~6000m 안에 둔다. |
| 중앙해령 | 대양 내부의 넓은 해저 산맥. 주변 바닥 대비 약 2200~3200m 높이의 어깨를 생성. |
| 해령 열곡 | 해령 양쪽 어깨보다 약 650m 깊은 축부 골짜기. 모든 실제 해령에 같은 열곡이 있는 것은 아니다. |
| 해구·해연 | 활동성 주변부를 따라 좁은 해구(약 6700~8000m)를 두고 일부에 더 깊은 함몰부(약 10000~10900m)를 둔다. |
| 해산 | 심해평원에 고립된 원뿔형 지형. 주변 바닥 대비 1200~2800m 높이. |
| 평정해산 | 평평한 정상과 경사진 측면을 가진 해산. 평탄면은 격자에 실제 동일 수심으로 저장. |
| 해저 선상지 | 협곡 하단의 바다 방향으로 펼쳐지는 낮은 퇴적성 로브. |
| 심해 구릉 | 심해평원 일부에 수백 미터 기복의 구릉군. |
| 해양 단열대 | 해령 바깥 심해저까지 이어지는 낮은 선형 단층 지형. |

산호초는 기존 얕은 연안 군락을 유지한다. 육지와 함께 전체 범례는 16개 코드다. 해령/해산의 **높이**는 해수면 아래 **수심**과 구분해 `baseDepth - summitDepth = relief`로 저장한다.

현재 지상 해안선/표본 격자에 맞추어 형태를 합성한다. 실제 지구 수심을 가져오거나 퇴적물 이동·맨틀 대류·판 경계 진화를 계산하지 않는다. 활동성/수동형 주변부는 공간적으로 연속된 대용 규칙이며, 해양판-해양판 섭입 같은 모든 지질 환경을 재현하지 않는다. 작은 지형은 160×96 격자보다 상세하게 표현하지 못한다.

## 표시·저장

- 해저·세력 탭은 현재 지도에 존재하는 분류의 색 범례를 보여 준다. 접이식 분류 안내에서 정의를 읽을 수 있다.
- 주요 해산·평정해산·해령·협곡·해연은 점 표식과 툴팁을 제공한다. 거주지를 선택하면 해당 위치의 해저 분류와 바닥 수심을 확인한다.
- 기존 코드 0~6은 유지하고 새 코드는 7~15에 추가했다. `geologyVersion: 2`와 선택 지형 메타데이터 `features`로 구분한다.
- 기존 파일은 저장된 지형을 바꾸지 않고 읽는다. **해저·세력 다시 생성**할 때 새 규칙을 적용하며 수동 도시·수정한 세력·외교 관계 보존 동작은 유지한다.

## 웹 자료 확인 상태

사용자가 요청한 논문·기관 자료 조회를 시도했으나, 현재 클라우드 HTTP 정책이 대상 도메인을 허용하지 않아 모두 403으로 차단되었다. **이 문서의 지형학 설명은 사용자 제공 기준과 일반 지형학 지식에 기반하며, 아래 자료를 읽고 검증했다고 주장하지 않는다.** 추가 지형인 선상지·구릉·단열대의 논문 대조도 미완료다.

조회 대상(미열람): NOAA Ocean Exploration의 해산/협곡 설명, IHO 표준 목록, USGS *This Dynamic Earth*, Crossref의 `Geomorphology of the oceans` 및 `Global distribution of large submarine canyons` 제목 검색. 검색 결과나 논문 초록을 실제 수신하지 못했으므로 DOI·논문 결론을 검증된 인용으로 기재하지 않았다.

시도 결과는 [수집 기록](../04-report/seabed-source-attempt.json)에 남겼다. `node scripts/collect-seabed-sources.ts <새 출력 폴더>`는 환경 프록시/접속 정책을 그대로 사용해 자료와 조회 시각·SHA-256·Crossref 메타데이터를 기록한다. 다운로드 HTML/원문은 로컬에만 두고 저장소에 재배포하지 않는다.

NOAA 2개 도메인, Crossref, IHO, USGS Publications, Frontiers 도메인의 접근 허용 초안을 저장했다. 환경 설정에서 검토·저장 후 게시해야 적용되며, 저장된 초안만으로 현재 환경의 접근 권한이 바뀌지는 않는다. 실제 자료 열람·논문 대조는 접근 적용 후 이어서 해야 한다.
