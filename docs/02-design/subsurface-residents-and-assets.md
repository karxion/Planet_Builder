# 지저·해저 에셋, 도시와 주민 목록

현재 지역 지도는 지상 데이터와 분리된 `worldSpaces`를 사용한다. 설계 목록에만 있던 전용 PNG의 1차 24종을 제작·연결하며, 40종 확장은 이번 배포 범위에 포함하지 않는다. 오브젝트의 개별 원본과 배포본, 두 시점, 해시를 manifest와 제작 보고서에 남긴다. 지역 지도는 조감도 절반을 선택하고, 내보내기에는 로컬 PNG를 인라인한다. 자연물·자원은 해당 공간의 유효 수중/바닥 셀에 배치하는 장식이며, 새 경제 자원·채굴량 규칙을 도입하지 않는다. 도시에는 주택·벽·문, 연결 지점에는 관문을 사용한다.

도시 이름은 세력명/번호와 구분되는 한국어/영어 고유 이름이다. 시드 기반 이름 생성은 지형 RNG를 소비하지 않는다. 누락된 기존 자동 도시 이름만 보완하며 수동/수정 도시 이름은 유지한다. 도시 텍스트를 우선 배치하고, 도시와 같은 위치의 영역명 및 지형명이 덮어쓰지 않도록 분리·충돌 처리한다.

`WorldSpacesData.content?: {version:1, npcs, items}`에 도시별 NPC 4명과 아이템 3종을 저장한다. NPC는 상인·길잡이·의뢰인·기록관 등의 역할, 종족, 인사말, 교류·의뢰 내용을 가진다. 상인 교류는 같은 도시의 아이템 목록을 연다. 성장 정보는 기존 NPC 생성기를 사용하며 일반인 CR은 별도, 도시 인물은 기본 T2 범위다. 자동 생성에 T5/Epic을 넣지 않는다.

아이템은 환경에 맞는 창작 명칭·효과·유래다. 공식 SRD 원문/출전 데이터로 표시하지 않는다. 레어 2 / 베리 레어 3 / 레젠더리 4개의 중복 없는 효과를 부여한다. 소유·거래 담당 NPC는 같은 도시의 상인으로 연결한다.

현재 공간이 수중/지저일 때 상단 ‘세계·NPC’와 ‘아이템’이 공간 전용 목록을 연다. 도시 선택·검색과 상세 편집, 지도 위치 이동을 제공한다. 지상에서는 기존 지상 목록을 사용하고 전용 기록은 표시하지 않는다. 지도에는 NPC 개별 표식을 추가하지 않는다. 도시 편집에서도 해당 도시의 NPC·아이템을 열 수 있다.

지역 지도에 표시한 자연물·자원 PNG는 클릭/탭과 Enter/Space로 선택한다. 공간 편집의 ‘오브젝트’에서 에셋 이름과 해당 위치의 지역·세력·지형을 확인한다. 선택은 세계 데이터를 변경하지 않는다. 클릭 영역은 영토 채움 위·도시/관문 아래에 배치하고 키보드 초점을 표시한다. 이 에셋들은 지역 지도 배치 오브젝트이며 새 채굴·경제 규칙을 추가하지 않는다.

마우스 위치 안내는 현재 공간의 저장 기록만 조회한다. 해저 세력명은 보기 모드와 무관하게 수심 셀의 실제 소유 세력에서 얻으며 육지는 수중 세력권으로 주장하지 않는다. 지저는 현재 깊이 층에 속한 영토·지형 이름과 세력을 사용하며 공동 세계의 내해·암반은 육지 영토 표시에서 제외한다. 이름 없는 위치에는 현재 공간의 지형·수심/층 이름을 표시한다. 지저·해저에서는 지상 셀/지역/도시 노트 조회를 건너뛰며 지상으로 돌아가면 기존 안내 경로를 사용한다. 저장한 이름은 HTML을 이스케이프하여 표시한다.

기존 파일을 열면 누락된 기록만 보완한다. 저장한 텍스트를 언어 전환으로 다시 번역하지 않는다. 편집한 NPC/아이템의 도시를 재생성 중에도 보존하고, 삭제된 도시에 연결된 자동 기록은 제거한다. 미적용 메모·이름·교류 초안은 기존 EditorDrafts 및 로컬 복구를 사용한다. FPB 저장/검증은 기존 스키마 1의 선택 필드로 호환한다.
