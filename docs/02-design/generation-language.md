# 생성 데이터의 언어

사용자가 선택한 앱 언어로 **새 데이터의 실제 저장 문자열**을 생성한다. 기본은 한국어이며 영어 선택 후 새로 생성하면 영어 지명·인물·서사가 만들어진다. 언어를 바꾸는 행위 자체는 기존 세계의 번역/재생성을 의미하지 않는다.

## 언어 전달

`services/generation-language.ts`는 DOM에 의존하지 않는 생성 언어 접근자다. 초기 로드 시 저장된 `fpb-ui-language`를 읽고, UI 설정 변경 시 `setUiLanguage`가 이를 동기화한다. 저장소 접근 실패 시 한국어를 사용한다. 순수 생성기는 UI/DOM을 직접 읽지 않는다.

`utils/generation-text.ts`는 UI의 기존 정적 어휘와 `data/generated-translations.ts`의 창작 어휘를 함께 사용한다. 완성 문장을 사후 번역하는 대신, 작성된 문장 템플릿과 어휘를 생성 지점에서 선택한다. 템플릿의 사용자 지명/이름 값은 번역하지 않고 그대로 삽입한다. 공식 규칙의 참조 ID, 원문 출전명, URL 및 수치/enum은 언어와 무관하게 보존한다.

## 적용 범위

- 지도/도시/국가/영지/강/호수의 이름 생성기와 명시적 이름 재생성. 지도 제목에 한국어와 영문 접미사를 섞지 않는다.
- NPC 이름·직업 표현·외형·성격·목표·비밀, 보물의 이름·상징·RP 영향·유래·규칙 개요, 교단·신격·상징·교리.
- 모험 거점의 이름·도입부·대표 개체 설명 및 레거시 표식의 새 메모. 링크/HTML 속성은 유지하고 텍스트만 생성 언어로 기록한다.
- 지저 터널·공동 세계 및 수중의 장소·주민·세력·이동로·설명. 신규 항목만 번역한다. 자동 세력의 이름/설명이 양 언어 기본값과 정확히 일치할 때만 재생성에 맞춰 갱신한다. 직접 쓴 세력 설정과 수정된 장소는 유지한다.
- 정착지 역사, 자원 기본 명칭·수량 단위, 군사/전투 기록, 날짜·시대의 자동 문구, NPC/아이템 일러스트 요청문.
- 내부 던전의 방·기믹은 기존 이중 언어 데이터를 유지하며, 대표 몬스터/테마 표시도 선택 언어를 사용한다.

## 호환성

저장 스키마는 바꾸지 않는다. 기존 FPB·복구·Drive 자료 및 편집 초안의 본문을 일괄 번역하지 않는다. `Campaign`의 초기화·불러오기 경로에서 자동 `koreanizeWorldNames` 호출을 제거한다. 명시적인 한글 지명 변환 버튼은 그대로 사용한다. 수치·배치·참조 ID에 언어 문자열을 끼워 넣지 않으며, 주요 시드 기반 생성기의 능력치·등급·지형 일치와 저장 검증을 테스트한다.
