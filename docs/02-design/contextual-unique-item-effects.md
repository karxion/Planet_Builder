# 배경에 맞는 유니크 효과

사용자 요청: 기존 기술 보정 + 피해/회복/임시 HP 반복을 대체하고 다섯 기준에서 레어 2개, 베리 레어 3개, 레젠더리 4개 효과를 부여한다.

## 생성

- `unique-item-effects.ts`의 FPB 창작 효과 후보에서 카테고리 1개를 필수로 고른다. 국가 성향, 제작 배경, 지형, 등급 후보를 시드로 정렬해 나머지를 고른다. 동일 기준·효과를 중복 선택하지 않는다. 등급은 모든 효과의 개수·수치 예산에도 영향을 준다.
- Common/Uncommon은 1개, Artifact는 4개로 명시한다. 요청한 세 등급의 2/3/4개 규칙은 엄격히 검증한다.
- 국가 성향은 생성 당시 NPC 국가 프로필 또는 정부 유형에서 가져온다. 지형은 실제 소재지/던전 셀의 해안, 고도, 생물군계에서 가져온다. 추론할 지도 정보가 없으면 unknown으로 기록하고 지형 효과를 제외한다.
- 제작 배경은 유래의 구원·전쟁·의식·여정·맹세 표현을 인식하고, 그 외에는 계승으로 분류한다. 새 자동 생성 보물의 유래도 국가 성향에 따라 구분한다. 기존 글은 고치지 않는다.
- 출신 성향·지형은 `origin`으로 최초 1회 저장한다. 이름·소유주 변경, 유니크 체크 해제/재선택으로 다시 추첨하지 않는다. 카테고리·등급·유래를 직접 바꾸면 해당 조건에 맞춰 재계산한다.

## 규칙과 호환성

- 각 항목은 실제 효과 하나다. 상징성 문장을 효과 개수에 넣지 않는다. 수치, 행동, 대상, 거리와 지속시간은 각 설명에 적는다.
- 원본 SRD 아이템의 핵심 효능·명중·AC·주문 DC를 덮어쓰지 않는다. FPB 창작 추가 특성임을 별도 표시한다. 개별 추가 효과의 DC는 레어13 / 베리 레어14 / 레젠더리15다.
- 장비는 기존 슬롯으로 조율 중 각 효과를 긴 휴식당 1회 사용한다. 소모품은 소모 시 각 효과를 1회 발동한다. 반응형 효과는 1시간 동안 조건을 기다리고 미사용 시 만료한다.
- `uniqueBonus.version=1`은 불러오기에서 계속 허용한다. 아이템 목록 동기화 시 version2로 갱신한다. 이름·직접 작성한 효능·유래·메모·이미지·소유주·던전 링크·삭제 기록은 유지한다. 새 구조와 origin은 FPB/JSON으로 직렬화된다.
- 보물 상세와 아이템 목록, 데이터 출력은 동일 생성기·표시기를 사용한다. 아이템 목록에 복사된 보물의 후속 수동 편집은 기존 독립 편집 정책을 유지한다.

## UI 수정

세계와 NPC 헤더의 기존 select 32px 제한과 새 공통 padding의 조합으로 한국어가 잘렸다. 헤더 전용으로 높이44px, padding6px 8px, line-height1.5, 폭96px을 지정한다. 모바일에서도 해당 헤더 규칙이 우선한다.
